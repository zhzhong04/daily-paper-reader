## 摘要
近期，多智能体LLM系统越来越多地结合异构模型以承担专门的智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。复用发送方的键值（KV）缓存可避免这种冗余，但跨模型家族的免预填充传输必须处理分词、模型深度和KV表示方面的差异。为解决这些问题，我们提出HeteroFold，一种免预填充的跨模型家族KV缓存传输方法，其保持发送方和接收方均冻结。HeteroFold对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold在所有四个长上下文基准和大多数短上下文设置上取得了最佳的缓存传输性能。它在多智能体基准上也与基于文本的通信相当。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B传输比Native Prefill快10.7倍，比最先进的免预填充基线Dense Latent和KV Ridge快1.18–1.47倍。这些结果表明，HeteroFold能够实现高效的跨模型家族KV复用，且无需接收方预填充。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

# 论文总结：Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs

## 1. 核心问题与整体含义

- **研究背景**：多智能体LLM系统（MAS）越来越多地采用异构模型组合，将不同家族或规模的模型分配给求解器、评估器、聚合器等专门角色（如X-MAS）。异构智能体之间常需交换共享上下文。
- **核心痛点**：基于文本的通信（TextMas）要求每个接收方对发送方已处理过的共享上下文重新预填充（prefill），并重建自己的KV缓存，随着上下文增长带来大量冗余计算与延迟。
- **关键挑战**：直接复用发送方的KV缓存可消除冗余，但跨模型家族的免预填充传输必须处理三类不匹配：
  - **分词差异**：不同模型家族使用不同tokenizer，token边界不一致。
  - **模型深度差异**：层数不同，层间对应关系不明确。
  - **KV表示差异**：KV特征分布、头数、隐藏维度不同。
- **核心洞察**：仅最小化KV重建误差并不足以保持接收方行为——KV Ridge的重建误差低于HeteroFold，但其注意力模式却被扭曲（图2）。因此有效迁移必须保持缓存所诱导的下游接收方计算。
- **整体含义**：HeteroFold是（据作者称）首个具有显式跨tokenizer对齐的、接收方免预填充的跨家族KV缓存传输方法，保持发送方与接收方模型均冻结，无需额外推理模块即可直接解码。

## 2. 方法论

### 2.1 核心思想
在冻结发送方 $\mathcal{S}$ 和接收方 $\mathcal{R}$ 的前提下，将发送方缓存 $C_{\mathcal{S}}(x)$ 映射为接收方兼容缓存 $\hat{C}_{\mathcal{R}}(x)$，无需接收方预填充。方法由三部分组成：**Token与Layer对齐 → Recolor KV映射 → 输出感知校准**，最终将学习到的修正折叠为固定仿射映射。

### 2.2 关键技术细节

**(1) Token Alignment (TA)——跨tokenizer对齐**
- 通过**共享字符结尾边界**建立发送方token与接收方token的对应关系。
- 对于接收方无匹配的边界，使用最近的前一个共享边界处的发送方状态；首个匹配之前使用第一个发送方token。
- 多对一情况下发送方状态**不平均**，而是使用匹配字符边界处的发送方token。
- 映射后接收方使用自己的位置索引应用RoPE。
- 示例：Qwen3 → Ministral-3 时，接收方字符9和12处复用Qwen结束于字符3的状态；反向时使用结束于相同边界的Ministral状态，匹配同一因果前缀端点。

**(2) Layer Alignment (LA)——比例深度对齐**
- 跨家族时接收方相关信息可能分布在多个发送方层。采用比例深度对齐，取匹配层周围偏移 $(-4, 0, +4)$ 的三层：
$$\pi(\ell) = 1 + \text{round}\left(\frac{(\ell-1)(L_{\mathcal{S}}-1)}{L_{\mathcal{R}}-1}\right), \quad \mathcal{N}(\ell) = \text{clip}_{[1,L_{\mathcal{S}}]}(\pi(\ell)-4, \pi(\ell), \pi(\ell)+4)$$
- 将选中的发送方特征拼接：$x_{\ell,c}^n = [c^{t_1}_{\mathcal{S},i_n} \| c^{t_2}_{\mathcal{S},i_n} \| c^{t_3}_{\mathcal{S},i_n}]$，展平以支持跨头映射（即使头数不同）。

**(3) Recolor——矩匹配的KV映射**
- 不采用token级重建目标（可能保持低重建误差却改变注意力），而是匹配接收方特征的均值与协方差。
- 对每个接收方层和角色 $c \in \{K, V\}$：
  - 计算全局标量RMS：$r = \sqrt{\frac{\sum_n w_n \|x_n\|_2^2}{\tilde{d}_S \sum_n w_n}}$，$Z = X/r$
  - 白化两个特征空间，用Procrustes对齐配对特征：
    $$\Sigma_Z^{-1/2}\Sigma_{ZY}\Sigma_Y^{-1/2} = U\Lambda Q^\top, \quad R^\star = UQ^\top$$
  - 恢复接收方协方差与均值：
    $$A = \Sigma_Z^{-1/2}R^\star\Sigma_Y^{1/2}, \quad b = \mu_Y - \mu_Z A, \quad y^{(0)} = (x/r)A + b$$
- 无正则化映射满足 $\mu_Z A + b = \mu_Y$ 且 $A^\top\Sigma_Z A = \Sigma_Y$（数值稳定化使协方差匹配近似成立）。
- K在key normalization和RoPE之前映射，V在投影之后映射；接收方随后应用原生key normalization和RoPE。

**(4) 输出感知校准（Output-Aware Calibration）**
- Recolor对齐全局统计结构，但不保证复现原生接收方注意力模式与输出。将KV量化中的输出感知校准适配到跨家族缓存传输。
- 注意力输出差异分解为：
$$\hat{O} - O^* = \underbrace{[(\hat{P}-P^*)V^*]W_O^\top}_{\text{key-induced}} + \underbrace{[\hat{P}(\hat{V}-V^*)]W_O^\top}_{\text{value-induced}}$$
- 对每个接收方层 $\ell$ 和角色 $c$，在Recolor输出上添加秩 $\rho_c$ 修正：
$$\hat{y}_{\ell,c} = y^{(0)}_{\ell,c} + (y^{(0)}_{\ell,c}B_{\ell,c})G_{\ell,c}, \quad B \in \mathbb{R}^{d_R \times \rho_c}, G \in \mathbb{R}^{\rho_c \times d_R}$$
- 损失函数：
  - **Key目标**（匹配注意力模式及其输出投影后效应）：
    $$\mathcal{L}_{\ell,K} = \mathbb{E}_{x,h,p}\left[D_{KL}(P^*_{\ell,h,p} \| \hat{P}_{\ell,h,p}) + \frac{\|\Delta O_{K,\ell,h,p}\|_2^2}{d_{\text{model}}^{\mathcal{R}}}\right]$$
  - **Value目标**（固定注意力模式，优化映射值）：
    $$\mathcal{L}_{\ell,V} = \mathbb{E}_x\left[\frac{\|\hat{O}_\ell - O^*_\ell\|_F^2}{\max(\|O^*_\ell\|_F^2, \epsilon)}\right]$$
- 仅优化 $B$ 和 $G$（$G$ 初始化为零），初始映射与两模型均冻结；校准使用原生接收方query、注意力权重、值和输出，**不使用黄金答案或生成续写**。

**(5) 推理折叠**
- 将学习到的修正折叠进初始仿射映射：
$$A_{\text{final}} = A(I+BG), \quad b_{\text{final}} = b(I+BG), \quad \Phi_{\ell,c}(x_j) = (x_j/r)A_{\text{final}} + b_{\text{final}}$$
- 推理使用每个接收方层和角色一个固定仿射映射，**无单独修正模块**。

## 6. 主要结论与发现

- **性能最优**：HeteroFold在所有四个长上下文基准和大多数短上下文设置上优于所评估的缓存传输基线；跨六个迁移方向一致。
- **多智能体可比**：HiddenBench上平均准确率30.6%、多数投票准确率29.2%，与TextMas（29.2%/27.7%）相当，优于Dense Latent+TA（18.5%/7.7%）和KV Ridge+TA（21.8%/16.9%）。
- **延迟优势**：32K上下文下Llama-3.1-8B→Ministral-3-14B比Native Prefill快**10.7×**，比Dense Latent和KV Ridge快**1.18–1.47×**；4K下加速约3.5–3.8×。
- **Token对齐关键**：将TA替换为same-index配对导致最大性能下降（GSM8K从63.46降至7.13，HotpotQA从50.29降至0.72）。
- **多层聚合与跨头混合有效**：单层映射和head-local映射均显著降低性能。
