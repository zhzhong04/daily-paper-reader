## 摘要
长输出推理将 KV 缓存瓶颈从固定的提示词转移到生成的轨迹。现有的推理缓存驱逐方法大多将缓存条目视为路由对象，估计某个旧键是否仍会被读取、是否会再次出现，或是否可以被替换。这种仅关注路由的视角忽略了两种效应：低注意力条目可能携带较大的值载荷，移除它们会改变未来预测；而新生成的状态可能在后来的查询有机会读取它们之前就显得陈旧。我们提出 AvoKV-E，一种免训练的驱逐策略，它首先延迟近期状态的可驱逐资格，然后使用候选归一化读取压力、键冗余和值载荷潜力对符合条件的条目进行排序。根据跨不同模型和数据集的实证评估，在匹配的活跃 KV 预算下，AvoKV-E 达到或超过冗余感知、基于重现和思维自适应的驱逐基线，并在缓存最紧张的情形下取得最大增益。组件与反事实分析进一步将这些增益与延迟观察、载荷感知评分、冗余和尺度鲁棒归一化联系起来。总体而言，结果表明，长推理 KV 驱逐不仅应保留可能被读取的键，还应保留维持推理轨迹的值载荷。

## Abstract
Long-output reasoning shifts the KV-cache bottleneck from the fixed prompt to the generated trace. Existing reasoning-cache eviction methods largely treat cached entries as routing objects, estimating whether an old key will still be read, will recur, or can be replaced. This routing-only view overlooks two effects: low-attention entries can carry large value payloads whose removal changes future predictions, and newly generated states can appear stale before later queries have had a chance to read them. We introduce AvoKV-E, a training-free eviction policy that first delays eligibility for recent states and then ranks eligible entries using candidate-normalized read pressure, key redundancy, and value-payload potential. According to empirical evaluation across different models and datasets, AvoKV-E matches or exceeds redundancy-aware, recurrence-based, and thought-adaptive eviction baselines at matched active-KV budgets, with its largest gains in the tightest-cache regime. Component and counterfactual analyses further connect these gains to delayed observation, payload-aware scoring, redundancy, and scale-robust normalization. Together, the results show that long-reasoning KV eviction should preserve not only keys that are likely to be read, but also the value payloads that sustain the reasoning trajectory.

# AvoKV-E 论文中文总结

## 1. 核心问题与整体含义

- **背景**：DeepSeek-R1、Qwen3 等长推理模型会生成很长的思维链，KV 缓存瓶颈从固定 prompt 转移到不断增长的生成轨迹。缓存预算紧张时，一次错误的驱逐可能导致模型重复计算、进入循环或无法给出最终答案。
- **现有方法局限**：多数推理缓存驱逐方法把 KV 条目当作“路由对象”，只判断旧 key 是否会被再次读取、是否重复、是否可被替代，即主要关注 attention 路由信号。
- **被忽略的两类效应**：
  - **value 载荷盲点**：低注意力条目也可能携带很大的 value 向量，其移除会显著改变未来预测。
  - **延迟读取问题**：新生成状态可能只是“还没被后续 query 读到”，而非真正无用；过早评分会把“未读”误判为“不重要”。
- **论文诊断**：图 1 与附录 D 通过 leave-one-out KL 诊断显示，低注意、高 value-norm 区域的高损害条目富集约 2.4 倍，Fisher 检验 p=0.009；部分低注意力 token 的强读取只发生在初始观察窗口之后，15% 的低注意力候选在 32 步内从未被强读。
- **整体含义**：长推理 KV 驱逐不应只保留“可能被读取的 key”，还应保留“支撑推理轨迹的 value 载荷”，并延迟对近期状态的判断，等待后续 query 提供因果证据。

## 2. 方法论

- **核心思想**：AvoKV-E 是免训练、在线、因果的 KV 驱逐策略，将问题拆成两步：
  1. **何时可以判断**：延迟近期状态的驱逐资格；
  2. **如何排序可驱逐项**：用载荷感知的淘汰风险分数对老候选排序。
- **缓存划分**：
  - 观察窗口 \(O_t\)：最近 \(W_{obs}\) 个 query 位置，用于测量读取压力。
  - 保护延迟缓冲 \(P_t\)：最近 \(W_{delay}\) 个新条目，暂时不可驱逐，且 \(W_{delay} \ge W_{obs}\)。
  - 候选集合 \(C_t\)：早于 \(t-W_{delay}\) 的旧条目，参与淘汰排序。
- **三个评分信号**：
  - **读取压力 \(p_i\)**：候选条目在观察窗口内从后续 query 获得的平均 attention，跨层和头平均。越高表示仍被读取。
  - **键冗余 \(r_i\)**：候选 key 与候选邻域内其他 key 的最大余弦相似度。越高表示越容易被替代，驱逐越安全。
  - **value 载荷潜力 \(b_i\)**：候选 value 的 L2 范数，除以同层同头候选 value 范数中位数。越高表示移除会丢失更多 value 内容。
- **关键设计**：不把 \(b_i\) 与 \(p_i\) 相乘。若相乘，会压制“低读取但高载荷”的状态，而这类状态正是论文诊断出的 attention-only 盲点。因此 payload 项独立存在，可“救回”低注意但高载荷候选。
- **候选相对归一化**：
  - 三个原始信号尺度不同，不能直接相加。
  - 使用候选集合内的 percentile rank 归一化：\(N_t(x_i)=\frac{\text{rank}_{C_t}(x_i)-1}{|C_t|-1}\)，映射到 \([0,1]\)。
  - 最终淘汰风险分：  
    \[
    S_i(t)=\lambda_p N_t(p_i)-\lambda_r N_t(r_i)+\lambda_b N_t(b_i)
    \]
  - 高读取压力、高 value 载荷提高风险分；高 key 冗余降低风险分。
  - 主实验权重为 \(\lambda_p=0.1,\lambda_r=0.9,\lambda_b=0.05\)。
- **保留集合构造**：
  - 先保留保护集 \(P_t\)。
  - 前 4 个初始缓存条目设为 \(S_i=+\infty\)，强制保留。
  - 剩余 \(B-|P_t|\) 个槽位按 \(S_i\) 选最高分候选。
- **在线流程**：
  - 每 128 个生成 token 触发一次压缩。
  - \(W_{obs}=8\)；预算 \(\ge 768\) 时 \(W_{delay}=8\)，预算 \(\le 512\) 时 \(W_{delay}=32\)。
  - 所有信号仅使用当前已生成前缀：attention 行、RoPE 后的 key、已存 value 范数，不需要未来 token、oracle 标签或辅助网络。
