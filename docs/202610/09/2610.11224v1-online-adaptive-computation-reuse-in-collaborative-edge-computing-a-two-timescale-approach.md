## 摘要
协作边缘计算（CEC）是一种高效的计算范式，使相邻边缘服务器能够彼此共享计算资源。尽管CEC可以提高资源利用率，但由于邻近终端用户经常卸载具有相似输入的任务，它仍然面临重复计算的问题。为提高系统效率，可以将先前执行过的任务的计算结果缓存起来，并由后续任务复用。然而，时变的任务流行度和到达率要求缓存与调度决策能够适应需求变化，而频繁的缓存更新会带来额外开销。为解决这一问题，本文面向CEC网络提出了一种双时间尺度计算复用算法。我们构建了一个联合考虑加权响应时间与缓存更新成本的优化问题，其中结果缓存决策在帧级确定，而工作负载调度、缓存搜索和计算资源分配在时隙级调整。利用最近的工作负载观测，我们构建了一个帧级代理问题，并将其分解为缓存子问题和调度子问题。针对缓存子问题，我们引入边际存储效率，并将缓存更新成本纳入一种基于二分法的算法中。在有界归一化边际灵敏度下，当单个结果大小相对于缓存容量较小时，且松弛解足够精确时，该算法对单基站缓存子问题可达到接近最优的目标值。针对调度子问题，我们采用投影梯度下降，并使用跨连续时隙热启动的回溯法。数值结果表明，在不同网络和工作负载设置下，与基准方案相比，所提方案能够持续获得性能增益。

## Abstract
Collaborative Edge Computing (CEC) is an efficient computing paradigm that enables neighboring edge servers to share computational resources with each other. Although CEC can enhance resource utilization, it still suffers from duplicate computations because nearby end-users often offload tasks with similar inputs. To improve system efficiency, the computation results of previously executed tasks can be cached and reused by subsequent tasks. However, time-varying task popularity and arrival rates require caching and scheduling decisions to adapt to demand changes, while frequent cache updates incur additional costs. To address this issue, this paper develops a two-timescale computation reuse algorithm for CEC networks. We formulate an optimization problem that jointly considers weighted response time and cache update cost, with result caching decisions determined at the frame level and workload scheduling, cache searching, and computational resource allocation adjusted at the slot level. Using recent workload observations, we construct a frame-level surrogate problem and decompose it into a caching subproblem and a scheduling subproblem. For the caching subproblem, we introduce marginal storage efficiency and incorporate cache update costs into a bisectionbased algorithm. Under bounded normalized marginal sensitivity, the algorithm achieves a near-optimal objective value for the single-BS caching subproblem when individual result sizes are small relative to the cache capacity and the relaxed solution is sufficiently accurate. For the scheduling subproblem, we utilize projected gradient descent and backtracking with warm starts across consecutive slots. Numerical results demonstrate consistent performance gains over benchmark schemes across diverse network and workload settings.
