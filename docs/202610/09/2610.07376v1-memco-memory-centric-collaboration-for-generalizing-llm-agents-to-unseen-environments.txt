Abstract 

Large language model (LLM) agents increasingly operate in interactive environments, where they need to make sequential decisions through observation, action, and feedback. Although memory can help agents reuse experience, existing work designs memory in isolation, where collecting enough trajectories to populate it is expensive. Existing shared-memory approaches mitigate isolated experience by pooling episodic memories across tasks and environments. How-ever, retrieving shared memory is challenged by the granularity, where retrieved memories can be either too specific to preserve current grounding or too coarse to support the next action. In this work, we propose MemCo , a memory-centric collaboration framework for generalizing LLM agents to unseen interactive environments. It maintains complementary local and global memory spaces, preserving environment-specific details locally while promoting transferable workflows induced from local trajectories to global memory. During online interaction, MemCo routes relevant local and global memories in terms of the agent’s current state and decision phase, enabling agents to reuse the experience of other agents without blindly transferring environment-specific details. Experiments on interactive decision-making benchmarks show that MemCo improves task success and reduces redundant exploration compared with isolate-memory and shared-memory baselines. ## 1 Introduction 

Large language model (LLM) agents are increasingly applied to interact with environments, where they make decisions based on the current state and execute actions toward the task goal. Retrieving episodic memories allows agents to reuse interaction experience at inference time (Cao et al., 2025; Fang et al., 2025; Liang et al., 2026). Methods such as Reflexion (Shinn et al., 2023), MemRL (Zhang et al., 2026b), and A-Mem (Xu et al., 2025) improve how individual agents organize and reuse prior experience. However, each agent still needs to collect useful trajectories through its own interactions, while limited experience may provide incomplete or unreliable guidance (Kwon et al., 2025). When multiple agents operate independently in different environments, experience acquired by one agent provides a natural reference for others. As illustrated in Fig. 1(a), agents can preserve experience from their own environments while sharing reusable experience that may support other agents, including those executing tasks in unseen environments, i.e., environments they have not previously interacted with. This motivates us to ask: how can one agent’s experience help other agents and vice versa? Existing methods such as G-Memory (Zhang et al., 2025), PlugMem (Yang et al., 2026), and MCMA (Liang et al., 2026) organize or transfer interaction experience across tasks or agents, demonstrating the potential of sharing experience. As shown in Fig. 1(b,c), G-Memory improves over in-context learning (ICL) and agents with isolated memory, yet still leaves room for improving task success and interaction efficiency, particularly on held-out layouts. Yet shared experience is not inherently useful across environments or decision contexts. This raises a crucial challenge: how can shared experience be organized into useful memory and effectively used to support another agent’s current decision? 

To address this challenge, we propose MemCo , a Mem ory-centric Co llaboration framework with complementary local and global memory spaces. As shown in Fig. 2, MemCo contains three main modules. In each agent, local memory construction converts interaction trajectories into a local memory graph, preserving environment-specific context while extracting experience patterns, actionable knowledge, and failure reflections. To form useful shared memory, progressive global memory collaboration abstracts selected local records while retaining their applicability conditions, aggregates evidence across agents, and promotes sufficiently supported records to global memory. To translate memory into effective decision guidance, query-guided memory support 

retrieves local and global memories according to the current decision context, filters incompatible guidance, and grounds shared experience in the current environment before composing memory support for the next decision. Thus, MemCo enables agents to benefit from experience accumulated by others without blindly transferring source-environment-specific information, while preserving the local grounding required for task execution in unseen environments. Our main contributions are: (1) We introduce memory-centric collaboration for agents interacting with environments, where experience accumulated across different environments can be shared to reduce repeated exploration and support task execution in unseen environments. (2) We develop MemCo with complementary local and global memory, turning shared experience into useful memory through evidence-aware global promotion and into decision guidance related to execution state. (3) Experiments across four benchmarks (ALFWorld, PDDL, FEVER, and ScienceWorld) and multiple LLM backbones show improved task performance with generally fewer interaction steps. 2Shareable Patterns Actionable Knowledge

## 2 Related Work 

Individual Experience and Agent Memory. Early agent paradigms such as ReAct (Yao et al., 2022) rely on the current interaction context without persistent experience across trials. Long-term memory systems subsequently support persistent storage and retrieval across interactions (Park et al., 2023; Packer et al., 2023; Zhong et al., 2024; Chhikara et al., 2025; Wang & Chen, 2025; Kwon et al., 2025). For interactive agents, prior work further turns trajectories into reflections, skills, procedural knowledge, or adaptive memory (Shinn et al., 2023; Wang et al., 2023; Zhu et al., 2023; Ding et al., 2026; Fang et al., 2025; Cao et al., 2025; Wu et al., 2025; Xu et al., 2025; Nan et al., 2025; Zhang et al., 2026b;a). These methods mainly improve how experience accumulated within an individual agent or memory system is represented and reused. 

Agent Collaboration through Shared Experience. Beyond communication, agent selection, or execution-time orchestration (Wu et al., 2024; Jia et al., 2025), agents can collaborate by reusing experience acquired in prior interactions. G-Memory (Zhang et al., 2025) organizes cross-trial collaboration memory within multi-agent systems, while MATM (Kim et al., 2026) supports population-level sharing of producer-agent trajectories. Agent KB (Tang et al., 2025) enables structured experience reuse across heterogeneous agent frameworks, whereas MemCollab (Chang et al., 2026) and FedAgentKE (Li et al., 2026) construct shared knowledge across different models or agent frameworks. Collectively, these works demonstrate the value of sharing agent experience. For agents interacting with different environments, however, shared experience is not uniformly useful: its value can depend on the receiving environment and current decision. MemCo 

addresses this setting by preserving local grounding while sharing reusable experience across agents. 

Constructing and Using Shared Memory. Prior work studies how reusable experience can be represented as transferable skills, rules, workflows, or structured memories (Ding et al., 2026; Fang et al., 2025; Cao et al., 2025; Wu et al., 2025; Xiang et al., 2026; Yang et al., 2026; Liang et al., 2026; Xia et al., 2026), as well as how stored memory can be selectively used at inference time (Liu et al., 2025; Zhao et al., 2026). MemCo 

jointly addresses both stages through evidence-aware global promotion and query-guided local and global memory use, while retaining the local grounding needed for execution. A more comprehensive discussion is provided in Appendix A. 33 Methodology

3.2 Framework Overview 

As in Fig. 2, MemCo maintains local memory Mli for environment-specific experience and global memory Mg

for reusable experience shared across agents. The framework addresses two stages: constructing memory from accumulated experience and using it for the current decision. For memory construction, local memory construction organizes each agent’s episodes into a graph and extracts patterns, actionable knowledge, and reflections, while progressive global memory collaboration abstracts selected shareable records, aggregates evidence across agents, and promotes supported records to global memory. For decision-time use, query-guided memory support selectively retrieves and composes relevant local and global memories into context Ct for the current decision. At step t, agent i selects an action according to Eq. 1 and uses environment feedback to form the next query, repeating this process until the episode terminates. During memory acquisition, completed episodes update local memory and provide selected records and evidence for global promotion. Subsequent queries can access the updated memories, enabling agents to benefit from one another’s experience while executing their own tasks independently. The algorithm details are in Appendix B.1. 

3.3 Local Memory Construction 

Local memory construction organizes an agent’s interaction episodes into a graph that connects related state–action transitions and their feedback across episodes. The graph preserves the context in which individual experiences occur and exposes recurring structures across episodes, from which MemCo induces shareable records together with their supporting evidence. This provides environment-specific memory for the agent itself and candidate records for cross-agent sharing. For each episode τn of agent i, MemCo constructs an episodic graph Gτn = ( Vτn , E τn ) whose nodes vxt , vat , and 

vft store normalized observations, parsed operations, and environment feedback, respectively. Directed edges connect them as temporal transitions: vxt → vat → vft → vxt+1 . Across Ni episodes of the same agent, nodes are matched when their types and normalized contents agree, and edges are matched when their relations and endpoints agree. 3.4 Progressive Global Memory Collaboration 

Progressive global memory collaboration turns selected local experience into reusable memory shared across agents. Each agent abstracts and shares selected local records with their episode-reduced promotion counts, while keeping fine-grained trajectories, local memory graphs, and instance-specific reflections local. MemCo 

aggregates evidence across agents and promotes supported abstract records into global memory for subsequent queries. For a shareable local record p ∈ P li ∪ E li , MemCo constructs its abstract form ¯p = Abstract( p) by replacing concrete entities where supported by the benchmark-specific task-role mapping and removing episode- and scene-specific anchors (Algo. 5). This preserves the record type, applicability conditions, action sequence or relation, and outcome. Records without removable environment-specific anchors can retain their structured form, while records without a transferable global form remain local. For example, a kettle’s current location remains local, while a fill-then-heat procedure can be shared using object and tool roles. Abstract records across agents share the same abstract key when their record types, applicability conditions, action sequences or relations, and outcomes match exactly (Appendix B.3.3). 3.5 Query-guided Memory Support 

To translate stored experience into support for the next decision, MemCo combines environment-specific local memory with reusable global memory accumulated across agents. The selected memory must be relevant to the current decision and grounded in the environment the agent is currently interacting with. At step t,the query qt = Q(g, xt, At, τ <t ) captures the goal, current observation, available actions, and task progress inferred from the preceding interaction history τ<t . This query guides both memory selection and composition. We retrieve two sets of memory entries from local and global sources separately: 

Slt = R  qt, Mli, k l , Sgt = R (qt, Mg , k g ) , (7) where R(·) is specified in Algo. 7. The local output Slt is selected from records in Pli , Eli , and Rli, together with bounded transition entries from query-matched states in Gli. These entries provide bounded local structural context for assessing workflow or rule applicability. The global output Sgt is selected from the promoted records in Mg . Both outputs obey their respective cardinality caps. Before selection, each memory entry m in the source-specific retrieval pool is scored along three complementary dimensions: state, task phase, and goal: 

r(m, qt) = rx(m, qt) + rp(m, qt) + rg (m, qt), (8) where rx measures consistency with the current state and available actions, rp measures compatibility with task progress, and rg measures the alignment of object, destination, or tool roles with the goal. Selection distinguishes applicability constraints from ranking preferences. Entries are filtered when their required conditions contradict the current state or their actions cannot be matched to At when such matching is required. The remaining entries are ranked using joint relevance, stored evidence, and action compatibility. We reduce priority when stale local information and other soft conflicts occur. Selection retains at most 

kl local and kg global entries. When a retrieval pool exceeds its budget, strong matches along individual relevance dimensions are retained before the remaining positions are filled by rank, preserving complementary support within the limit (Algo. 7). Composition connects shared knowledge to its local use by grounding global records against xt and At, with local evidence supplying environment-specific context where available. For example, a shared clean-before-place workflow specifies action order, while local evidence identifies a usable basin for cleaning the current object (Appendix B.4.5). The selected entries are organized by their roles in the current decision: grounding 

provides evidence for interpreting the current state, graph relations, and concrete action references; workflow guidance provides plans, procedures, and preconditions; and reflection provides failure patterns, repairs, and blocked actions. Baselines. We compare MemCo against several representative baselines: (1) In-Context Learning (ICL), using direct in-context prompting without a persistent memory bank; (2) A-Mem Xu et al. (2025), a specialized long-term memory architecture; (3) MemRL Zhang et al. (2026a), which reframes memory management as a set of learnable natural-language skills; and (5) G-Memory Zhang et al. Implementation Details. We implement MemCo using AutoGen Wu et al. (2024) and evaluate open- and closed-source models. We use α = 0 .05 and λ = 0 .35 for promotion across all benchmarks. Open-source model inference is conducted on a single NVIDIA RTX PRO 6000 Blackwell GPU. Both local and global retrievers use deterministic bounded selection with facet coverage and rank-based filling, i.e., kℓ = kg = 5 .Unless otherwise specified, we report accuracy (Acc., %) and the average number of interaction steps during evaluation. For each benchmark, memory is constructed from designated source partitions and evaluated on disjoint tasks, with no evaluation trajectories used for memory construction. We use one agent per source domain: four agents for ALFWorld and PDDL, two for FEVER, and ten for ScienceWorld. Each agent is evaluated on the merged test set using its own frozen local memory and the shared global memory, covering both its acquisition domain and other environments. ALFWorld’s Familiar and Held-out splits additionally assess layout generalization. Full partitioning and construction details are in Appendix F.

4.2 Mechanism and Sensitivity Analysis 

Following the memory lifecycle introduced in Section 3, we conduct controlled studies of MemCo ’s complementary memory scopes, evidence-aware promotion, and query-guided memory use. Unless otherwise specified, all variants use the same frozen local-memory snapshot and differ only in the component under evaluation. These results represent controlled within-snapshot comparisons rather than independent repetitions of the main experiments. 

Complementary Local and Global Memory. Fig. 4(c)-(d) shows that Local-only performs well on familiar layouts but degrades on held-out layouts, whereas Global-only narrows this gap. Held-out accuracy increases from 89 .64% with Local-only to 97 .14% with Global-only and 97 .86% with the full system. Retaining local evidence also improves familiar-layout accuracy over Global-only, from 96 .10% to 97 .40% . Their adaptive combination achieves the highest overall accuracy with shorter trajectories than either isolated scope, supporting complementary roles for local grounding and transferable global guidance with abstract rules and workflows. 

Finite-Evidence-Aware Progressive Collaboration. We replace the Wilson lower confidence bound promotion rule W (¯ p) with its counterpart ρ+(¯ p) while keeping λ = 0 .35 and the frozen local evidence fixed. This result is consistent with Wilson calibration favoring candidates supported by more reliable finite evidence.

## 6 Conclusion 

In this work, we introduced MemCo, a memory-centric collaboration framework for generalizing LLM agents to unseen interactive environments. MemCo constructs local memory from each agent’s interaction trajectories, progressively promotes reusable abstract records to shared global memory, and adaptively selects and composes local and global evidence into a decision-relevant memory context during online interaction. Experiments across four heterogeneous benchmarks show that MemCo improves task success and generally reduces redundant exploration compared with memory-free, isolated-memory, and shared-memory baselines. 

## Limitations 

First, our framework relies on initial interaction traces to bootstrap the global workflow memory. While a complete lack of early experience limits global guidance, this cold-start characteristic is common to all retrieval-based experience sharing systems. Second, we evaluate MemCo exclusively on text-based and symbolic interactive benchmarks. Extending this hierarchical memory architecture to multimodal environments with visual observations remains an open direction for future work. 11 References

15 A Extended Related Work 

Individual Experience and Agent Memory. Generative Agents (Park et al., 2023) stores observation streams and derives higher-level reflections, while MemGPT (Packer et al., 2023) manages information beyond the immediate context window. MemoryBank (Zhong et al., 2024), Mem0 (Chhikara et al., 2025), and MIRIX (Wang & Chen, 2025) study long-term memory for conversational, personalized, or multimodal interactions, while MEMENTO (Kwon et al., 2025) evaluates memory utilization for personalized embodied assistance. Long contexts themselves do not guarantee effective reuse, since relevant information may become difficult to access and irrelevant context can distract reasoning (Liu et al., 2024; Shi et al., 2023), motivating explicit storage and retrieval of decision-relevant experience. For interactive agents, a closely related line of work turns environment interaction into reusable decision support. Reflexion (Shinn et al., 2023) stores verbal reflections from previous trials; Voyager (Wang et al., 2023) and GITM (Zhu et al., 2023) accumulate reusable skills or knowledge for open-world interaction; and SkillGen (Ding et al., 2026) extracts domain skills for sequential decision making. Memp (Fang et al., 2025) studies procedural-memory construction, retrieval, and update, while ReMe (Cao et al., 2025) distills and refines procedural experience. Meta-Policy Reflexion (Wu et al., 2025) consolidates reflections into reusable rules, whereas A-Mem (Xu et al., 2025), Nemori (Nan et al., 2025), MemRL (Zhang et al., 2026b), and MemSkill (Zhang et al., 2026a) improve memory organization, episodic reuse, or memory-management policies. These methods primarily improve how experience accumulated within an individual agent or memory system is represented and reused. When multiple agents interact with different environments, a complementary question is how experience acquired by one agent can become useful to others. 

Agent Collaboration through Shared Experience. Multi-agent collaboration is commonly realized through communication, agent selection, or execution-time orchestration, e.g., AutoGen (Wu et al., 2024) and AgentStore (Jia et al., 2025). Experience sharing provides a complementary form of collaboration in which experience acquired in prior interactions can support other agents later. Recent work realizes such sharing through different representations. G-Memory (Zhang et al., 2025) organizes prior collaboration within a multi-agent system through hierarchical interaction, query, and insight memory. MATM (Kim et al., 2026) supports population-level storage and retrieval of producer-agent trajectories for later use by consumer agents. Agent KB (Tang et al., 2025) aggregates trajectories from heterogeneous agent frameworks into a structured knowledge base for cross-domain planning and feedback. MemCollab (Chang et al., 2026) distills shared constraints from trajectories generated by different backbone models, while FedAgentKE (Li et al., 2026) evolves transferable semantic knowledge across heterogeneous agents through federated distillation and aggregation. Collectively, these works demonstrate that experience can be reused beyond its original interaction and, in different settings, across agents, models, or agent frameworks. MemCo builds on this direction for independently acting agents that accumulate experience in different environments. It keeps environment-specific experience local while sharing reusable records across agents, so that cross-agent experience can be used without collapsing the context in which it was acquired. 

Constructing and Using Shared Memory. A first question is how reusable experience should be represented and retained. Procedural-memory methods show that trajectories can be distilled into more compact skills, scripts, rules, or workflows (Ding et al., 2026; Fang et al., 2025; Cao et al., 2025; Wu et al., 2025). FlowSearcher (Xiang et al., 2026) synthesizes memory-guided workflows from historical experience, while PlugMem (Yang et al., 2026) organizes episodic experience into a knowledge-centric memory graph. MCMA (Liang et al., 2026) learns memory structures at different abstraction levels for selective transfer under distribution shift, and Memora (Xia et al., 2026) explicitly balances abstraction against specificity. Together, these studies highlight that transferable memory benefits from capturing reusable structure while retaining information needed for later application. A second question is how stored memory should be used for the current decision. RCR-Router (Liu et al., 2025) dynamically selects structured memory subsets according to agent role and task stage, while ShardMemo (Zhao et al., 2026) uses masked mixture-of-experts routing over sharded memory. These works highlight that the utility of stored memory also depends on context-aware selection at inference time. MemCo connects these two stages in a single memory-centric collaboration process: environment-specific evidence is retained locally, reusable records are promoted using evidence accumulated across agents, and local and global memory are selected and grounded according to the receiving agent’s current state, progress, goal, and available actions. These mechanisms jointly define the proposed collaboration framework rather than treating shared-memory construction and decision-time use as separate problems. 16 B Algorithms and Implementation

B.2.5 Deterministic Evidence Assignment 

Evidence signs are assigned from normalized interaction signals rather than by an additional LLM call. The evidence semantics, episode reduction, aggregation, and Wilson promotion rule are shared across evaluation environments; only the interface that exposes the normalized state, action, and feedback fields depends on the environment.

The local graph is queried as a bounded structural index. State anchors are matched to the current query using normalized state content together with location, visible or held entities, task progress, and goal-related cues when available. From each retained anchor, retrieval follows only a bounded local neighborhood of the observed state–action–feedback–next-state transition. In the serialized graph, this is the corresponding state–action–next-state backbone together with its attached feedback fields. The resulting transition entries summarize concrete local evidence that can support the current decision; retrieval does not search arbitrary paths or construct a new long workflow from the merged graph. Graph-derived entries and records from Pli , Eli , and Rli enter the same bounded local selection stage. Their graph provenance can strengthen a record when the retrieved state, action, or outcome matches the current query, while incompatible or stale context lowers its priority. All such entries remain subject to the common state, progress, goal, and action-compatibility checks below. 

B.4.2 Memory Entry Construction, Matching, and Ranking 

At each decision step, MemCo constructs the query defined in Section 3.5 from the current goal, observation, available actions, and interaction history. The same retrieval function R is called independently on local and global memory according to Eq. 7. Local retrieval draws from the local records and bounded graph neighborhoods described above, whereas global retrieval draws from promoted abstract records in Mg .Candidate entries are evaluated through the three complementary relevance facets in Eq. 8: 

r(m, qt) = rx(m, qt) + rp(m, qt) + rg (m, qt).

Here rx measures consistency with the current state and available actions, rp measures compatibility with task progress, and rg measures alignment with the goal and its functional roles. These facets score the same memory entry from complementary views; they are not independent pass/fail gates. Each facet is computed by deterministic comparisons over the normalized fields available to the entry: compatible matches contribute positively, explicit mismatches reduce the score, and unavailable optional fields contribute no update. The reported outer weights of the three facets are one. These comparisons use the common normalized representation rather than a benchmark-specific retrieval objective.      

> Facet Main emphasis Examples of matching evidence
> rxCurrent state and action context State or location consistency, visible or held entities, applicable conditions, and compatibility with currently available actions.
> rpTask and execution progress Task stage, completed or remaining subgoals, failure context, and whether the stored procedure is appropriate at the current decision phase.
> rgGoal and functional roles Alignment between stored object, destination, tool, or action roles and the current task goal.

Applicability constraints are handled before ranking: an entry is removed when a required condition contradicts the current state or when a required action cannot be matched to At. These hard compatibility checks are distinct from the soft preferences used to rank the remaining entries. The joint relevance score is then combined with stored evidence, current action binding, source-specific context, and soft conflict penalties to obtain the full rank used for bounded selection: 

srank (m, qt) = r(m, qt) + ∆ ev (m) + ∆ bind (m, qt) + ∆ src (m, qt) − psoft (m, qt).

Here ∆ev summarizes the occurrence-level evidence retained with the entry, ∆bind reflects compatibility between the stored operation or semantic roles and the currently available actions, ∆src incorporates source-specific supporting context (such as query-matched local graph context for local entries or retained applicability and role context for global entries), and psoft collects non-disqualifying conflicts such as stale or weakly mismatched guidance. These terms are deterministic adjustments over the same normalized fields used by the common retrieval interface. Occurrence-level statistics can contribute to retrieval ranking, whereas the episode-reduced counts n+, n − are reserved for Wilson promotion. The Wilson score therefore controls membership in global memory rather than being added directly to the online relevance score. 26 B.4.3 Bounded Selection

B.4.4 Composition and Rendering 

Retrieval and composition serve different roles. Retrieval selects relevant entries within each memory source, whereas composition determines how the selected local and global entries should be used in the current decision. With H = {ground , workflow , reflection }, grounding uses current-state facts and graph relations; workflow support uses plans, procedures, and preconditions; and reflection uses failure patterns, repairs, and blocked actions. Entries whose content is incompatible with the current role or decision context are removed. For a global record, composition first binds its abstract object, destination, tool, and action roles to the current query and available actions. A global record is not emitted when a required binding cannot be established. Local state constraints and concrete local grounding take precedence over an incompatible abstract recommendation. The remaining support is deduplicated, organized by role, and kept within a bounded 27 context budget before rendering. This stage therefore converts shared knowledge into current-environment support rather than directly copying a stored global record into the prompt. The renderer serializes the admitted support into the three memory-bearing fields in Eq. 10. It keeps only information needed for the current decision and uses the current bindings for grounded global records rather than source-environment anchors. Episode-level reduction prevents repeated annotations within one episode from directly multiplying the promotion evidence, but does not establish independence or identical distribution across episodes.

## F Benchmark Domain Construction and Evaluation Scope 

F.1 ALFWorld Multi-Domain Environment 

To evaluate collaboration across environments, ALFWorld tasks are organized into four functional scene domains: Kitchen, Living Room, Bedroom, and Bathroom. We sample 100 training tasks from each domain for experience acquisition. Following the official protocol, evaluation uses both the Familiar Layout (valid_seen )and Held-out Layout (valid_unseen ) splits. The resulting training/Familiar/Held-out counts are Kitchen (100 /20 /20 ), Living Room ( 100 /17 /11 ), Bedroom ( 100 /20 /20 ), and Bathroom ( 100 /20 /19 ). Following the problem formulation, an unseen environment is defined with respect to the evaluated agent: it is an environment in which that agent did not acquire experience before evaluation. This agent-specific notion and the official held-out-layout split provide complementary axes of generalization. An environment may be unseen to one agent while experience from other agents is available through global memory; the Held-out Layout split additionally changes layout familiarity. 

F.2 PDDL Planning and Domain Partitioning 

PDDL tasks are organized into the four planning domains Gripper, Barman, Blockworld, and Tyreworld. The source sets contain 20, 20, 10, and 10 tasks, respectively, and evaluation uses a unified test set of 60 tasks. Local memory is constructed independently for each source domain before cross-agent global memory is formed. 

F.3 FEVER Domain Partitioning 

For FEVER, we construct two semantic source domains, Film/TV and Music, with 100 training examples in each domain. As noted in the AI Use Statement, GPT-4o-mini is used only to assist the semantic domain labeling used for this partition construction; it is not an evaluation-time memory component. Evaluation uses 60 disjoint examples, 30 from each domain, with a balanced distribution over SUPPORTS, REFUTES, and NEI labels. These partitions provide distinct sources of interaction experience while keeping the verification task and action interface unchanged. 

F.4 ScienceWorld Task-Family Partitioning 

ScienceWorld tasks are organized by their official task families while preserving the official train/test variation split. We sample up to 10 training variations per task template for local experience acquisition and up to 2 36 test variations for evaluation, yielding 60 held-out evaluation variations in the merged test set. Each local domain is evaluated with the same local-plus-global memory protocol. 

F.5 Acquisition, Evaluation, and Controlled Comparisons 

During acquisition, agents interact with their designated source environments, update their own local memories, and contribute selected shareable records to global promotion. Global memory is constructed only from the completed local stores. During evaluation, local and global memories are frozen: the evaluated agent refreshes its query and retrieved support at every decision step, but the test trajectory is not written back into either memory. For each source-domain local memory, evaluation is performed on the common merged test set together with the shared global memory. Consequently, the same evaluated agent encounters both tasks aligned with its own acquisition domain and tasks from environments in which it did not acquire local experience. This operationalizes the agent-specific unseen-environment setting in the problem formulation while allowing the shared global memory to supply experience contributed by other agents. In ALFWorld, Familiar and Held-out additionally measure whether the layout itself was seen in the benchmark training split. The controlled ablations in Appendix C reuse the same frozen local-memory snapshot. Threshold sensitivity reconstructs only the global memory from the same evidence, while the other component studies change the evaluated memory scope, promotion rule, retrieval, or composition policy without recollecting source experience.

The unit of analysis in these tests is the matched backbone–task configuration. The two metrics are tested separately, and the analysis does not treat the three repeated runs or the two metrics from one configuration as additional independent evaluation blocks. Accordingly, these results should be interpreted as evidence of consistent performance differences across the evaluated configurations rather than as a claim about all possible models and environments. Configurations reuse backbones and task families, so dependence between blocks may limit that inferential interpretation; the reported p-values are conditional on the block-level assumptions and are not a substitute for independent task- or seed-level replication. The average ranks and paired differences remain descriptive summaries of the evaluated configurations. 

## I Case Study: Adaptive Memory Support and Cross-Environment Generalization 

To qualitatively evaluate MemCo , we analyze the trajectories across heterogeneous settings to investigate how local situational grounding and global procedural workflows interact dynamically online. 

Exploration Efficiency. As shown in Fig. A.1(a) and A.1(b), when facing the same task “Put a clean cloth in countertop”, the displayed G-Memory trajectory attempts to place the cloth before satisfying the cleanliness requirement, resulting in redundant interactions. In contrast, MemCo retrieves decision-relevant support before placement: the reusable clean-before-store ordering is combined with local actionable knowledge for the current state. The resulting trajectory avoids the invalid move and completes the task with fewer interaction steps. 

Unseen-Environment Generalization. The comparison between Fig. A.1(b) and A.1(c) illustrates how shared experience supports an agent in an unseen environment. The task changes from cleaning a cloth in a kitchen to “Clean a bar of soap and put it in a vanity” in a bathroom. A kitchen-specific instruction can be irrelevant in the bathroom, whereas the clean-before-place ordering can remain useful under the corresponding applicability conditions. As illustrated in Fig. A.1(c), query-guided selection and composition exclude incompatible kitchen-specific guidance, including the irrelevant “clothwasher trace”. The shared workflow supplies the action order; the current observation and available actions ground its roles in the bathroom basin and vanity, with applicable local evidence providing further context. This decision-time grounding does not require writing new environment-specific records into the frozen evaluation memory. The shown trajectory completes the task in 6 steps, illustrating how shared procedural guidance can be transferred to an environment unseen by the evaluated agent while current-environment grounding determines how that guidance is executed. 41 Figure A.1: Case study showcasing adaptive memory support and cross-environment generaliza-tion.
