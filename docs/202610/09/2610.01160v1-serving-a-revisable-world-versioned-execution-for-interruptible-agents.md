## 摘要
LLM 智能体在用户更改指令、工具失败或新信息改变计划时，会修订正在运行的任务。如今的服务器将修订表示为中止旧请求并提交替代请求。然而，旧执行的缓冲输出和未完成工作必须停止影响应用，而已完成的 KV 状态可能仍对其替代者有用。分别处理这些职责可能导致过时效果仍可发布，并迫使后继者重建有效状态。我们提出 Retire，一种围绕版本化执行的服务控制平面重新设计。请求拥有调度和内存资源；执行版本拥有 authority（权限），即发布输出或为当前执行安装状态的许可。Retire 首先撤销过时工作，然后限制其剩余执行，并认证其后继者可以继承的已完成前缀。后继者从该状态运行，同时被隔离的旧资源被异步回收。这将快速失效与选择性保留统一在一次版本转换中。我们在 vLLM 中实现 Retire，涵盖输出发布、GPU 执行、KV 交接、分层恢复以及分布式和多租户服务。正确性实验验证了这些路径上的当前版本输出和有效状态继承。在受控配对实验中，将失效与继承相结合，使从修订到后继者的首 token 时间中位数减少 17.1%。对记录的编码智能体中断到达进行回放，不会产生过时输出，并保持每个最终版本在反复修订中持续推进。Retire 将中止并重启转变为协调式交接，快速停止过时工作，并为后继者保留有用工作。

## 速览
**TLDR**：LLM代理常因用户改指令、工具失败或新信息而修订运行任务。传统服务只能中止旧请求再提交替代请求，但旧执行的缓冲输出和未完成工作仍需停止生效，已完成KV状态却可被后继继承。Retire提出版本化执行控制面：请求持有调度与内存，执行版本持有发布与安装状态权限；先撤销过期工作，再限定其执行并认证可继承前缀。在vLLM实现后，修订到后继首token时间中位数降17.1%，回放无过期输出，统一了快速失效与选择性保留。 \
**Motivation**：LLM代理需在运行中修订任务，传统中止旧请求再提交替代请求会留下过期输出风险，或迫使后继重建有效KV状态。 \
**Method**：Retire将请求的资源所有权与执行版本的权威分离，先撤销过期工作、限制其执行，并认证后继可继承的已完成前缀。 \
**Result**：在vLLM中实现后，受控配对实验使修订到后继首token时间中位数降低17.1%，编码代理中断回放无过期输出。 \
**Conclusion**：Retire把中止并重启改为协调式交接，既能快速停止过期工作，又能为后继保留有用工作，支持可修订代理服务。

## Abstract
LLM agents revise running tasks when users change instructions, tools fail, or new information changes a plan. Today's servers express a revision as aborting old requests and submitting replacements. Yet the old execution's buffered output and outstanding work must stop affecting the application, while completed KV state may still be useful to its replacement. Handling these obligations separately can leave obsolete effects publishable and force the successor to rebuild valid state.   We present \retire, a serving control-plane redesign around \emph{versioned execution}. Requests own scheduling and memory resources; execution versions own \emph{authority}, the permission to publish output or install state for the current execution. \retire first revokes obsolete work, then bounds its remaining execution and certifies the completed prefix its successor can inherit. The successor runs from that state while isolated old resources are reclaimed asynchronously. This unifies fast invalidation and selective preservation in one version transition.   We implement \retire in vLLM across output publication, GPU execution, KV handoff, tiered recovery, and distributed and multi-tenant serving. Correctness experiments verify current-version output and valid state inheritance across these paths. Combining invalidation with inheritance reduces revision-to-successor time-to-first-token by a median 17.1\% in controlled paired experiments. A replay of recorded coding-agent interruption arrivals emits no obsolete output and keeps every final version progressing through repeated revisions. \retire turns abort-and-restart into a coordinated handoff that stops obsolete work quickly and preserves useful work for its successor.
