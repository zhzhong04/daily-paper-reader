## 摘要
将长上下文推理分解到多个协作智能体上，限制的是每次调用时的活跃KV缓存，而非证据总量；当KV缓存内存成为瓶颈时，这一点至关重要。许多此类系统会加入一个持久层，用于存储和召回推理轨迹，通常通过报告准确率提升的消融实验来验证。我们在一个三层智能体架构上对二者进行了测量。分解确实有效：每查询的峰值KV工作集为14.3 MiB，而单遍和检索增强基线分别为35.5和35.3 MiB。持久层则不然：在八个受控数据集对上，每组n=100，它带来+0.368 MiB [+0.167, +0.590]的峰值缓存开销，且未产生可检测的准确率变化（+0.015，95% CI [-0.011, +0.046]）。我们认为这一零结果是结构性的：单问题基准为每个条目提供其自身证据并独立评分，而正确性要求在条件之间重置已存储的轨迹，因此召回没有任何有信息量的内容可检索。得出这一结论经历了四次测量校正——其中三次夸大了表面收益，第四次则使该量级的效果看起来可分辨——而这些在结果表中均不可见。我们给出了智能体记忆消融必须满足的条件，以及无需了解具体缺陷即可使用的检测程序。

## Abstract
Decomposing long-context inference across cooperating agents bounds the active KV cache per call rather than total evidence, which matters when KV-cache memory binds. Many such systems add a persistent tier storing and recalling reasoning traces, usually validated by an ablation reporting an accuracy gain. We measure both on one three-tier agent architecture. Decomposition delivers: peak KV working set of 14.3 MiB per query against 35.5 and 35.3 MiB for single-pass and retrieval-augmented baselines. The persistent tier does not: across eight controlled dataset pairs at n=100 per arm it costs +0.368 MiB [+0.167, +0.590] of peak cache and produces no detectable accuracy change (+0.015, 95% CI [-0.011, +0.046]). We argue the null is structural: single-question benchmarks supply each item with its own evidence and score it independently, and correctness requires resetting stored traces between conditions, so recall has nothing informative to retrieve. Reaching it took four measurement corrections -- three inflating the apparent benefit, the fourth making an effect that size look resolvable -- none visible in the results table. We give the conditions an agent-memory ablation must satisfy and detection procedures that need no knowledge of the specific defect.

## 1. 核心问题与整体含义（研究动机与背景）

- **内存瓶颈问题**：KV 缓存是长上下文推理的内存瓶颈——它随上下文增长，按**峰值**而非平均值分配，常超出边缘加速器的 VRAM，因此缓存管理本身就是一个系统问题。
- **两种应对路线的混淆**：检索增强（RAG）与智能体分解常被当作长上下文的可互换答案，但对"记忆"而言二者不同：
  - RAG 改变**哪些证据进入单次调用**；
  - 分解改变**证据被分散到多少次调用**，只有后者能限制峰值 KV。
- **持久记忆层的流行做法**：许多多智能体系统在分解架构上再加一层持久存储，保存并召回推理轨迹，通常用一个"关闭该层→准确率下降"的消融实验来证明其价值。
- **本文核心问题**：在**同一个三层智能体架构**上，同时测量分解与持久记忆层的真实成本（峰值 KV）与收益（准确率），并追问：单题基准上的记忆消融实验，究竟能否测出记忆的作用？

## 2. 论文提出的方法论

- **被测架构 COA-PKV（三层）**：
  - **L1**：临时的每次调用 KV 缓存；
  - **L2**：Redis 支撑的键值存储，承载类型化的 Communication Unit，使智能体接收蒸馏后的前驱输出而非原始上下文；
  - **L3**：Qdrant 向量库，承担两个**代码上可分离**的角色——语义证据过滤（进入缓存前）与 (q, k, v) 轨迹持久化（跨查询召回）；**只有第二个**才是"持久记忆"主张。
- **对照臂 COA-NoKV**：仅禁用 `search_outputs`（召回）与 `store_qkv`（写入）两个操作，L1、L2 与证据过滤完全一致，实现单轴消融。
- **峰值 KV 度量**：定义为一次查询中**单次调用**的 (prompt + generated) 最大足迹，按服务模型的 10,240 B/token KV 几何换算；不等于设备占用（不含线性注意力层状态、权重、分页取整、并发序列限制）。
- **统计方法**：按问题配对（memory-on 减 memory-off），单元内用百分位 bootstrap（B=10⁴）；跨单元用两阶段 cluster bootstrap（先重采样单元，再在单元内重采样问题），因同一单元内问题共享难度分布。
- **四次测量校正（作为方法贡献提出）**：
  - **C1 组件确实执行**：为每个"存在即主张"的组件发出计数器，并在运行摘要中强制非零（曾出现轨迹写入无人读取、客户端标志对服务端无效、reranker 404 静默保留原序等惰性组件）。
  - **C2 运行相互独立**：运行前用评测问题查询存储，任何超阈值命中即为污染；曾出现固定种子重跑检索到自身旧答案（100/100 问题已带存储轨迹）。
  - **C3 只改变命名轴**：diff 两臂序列化请求，必须只差一个字段；再对顺序做平衡（时间/顺序无法被 diff 看见）。
  - **C4 效应超过测量下限**：用**重复运行**估计波动带，而非运行内 bootstrap（后者低估不确定性约两倍）。

## 6. 论文的主要结论与发现

- **分解确实有效**：峰值 KV 每查询 **14.3 MiB**，对比 FLAT 35.5 MiB 与 RAG 35.3 MiB，降幅约 **59.9% / 59.7%**（区间无重叠，2.5× 更低）；延迟 29s vs 67s/52s（1.8–2.3× 更低）。
- **代价是总流量更高**：累积 KV 流量约 **1.6×**——结论是"更低峰值、更高总流量"，这正是 KV 缓存内存受限时值得做的权衡。
- **持久层不划算**：八对数据集上，启用召回使峰值 KV 增加 **+0.368 MiB [+0.167, +0.590]**（约 2%），准确率变化 **+0.015（95% CI [−0.011, +0.046]）**，不可与噪声分离。
- **零结果是结构性的**：
  - 单题基准为每个条目自供证据并独立评分，问题 i 上学到的东西对问题 j 无用；
  - 正确性要求在条件间**重置轨迹**（否则固定种子重跑会检索到自己的旧结论），于是同条件内召回只能触达同一次运行中无关条目的轨迹；
  - 实测召回仅对 **24%** 的问题可达（剥离模板后 20%），其余问题召回"可证明返回空"，故 +0.015 是 **intention-to-treat** 估计；可达子组为 −0.012 [−0.073, +0.046]（欠功率），不可达子组 +0.009 [−0.007, +0.026] 充当内置对照。
- **可迁移的推论（逆否命题）**：在独立条目基准上报告的非零记忆效应，**更可能是伪影而非发现**。
- **四次校正的量化后果**：C1 组件惰性（"正确代码实现了彻底、永久且与成功无法区分的退化"）；C2 污染使某数据集 0.2949 → 0.2282（**下降**）；C3 未校正的 MMLU-Pro 读出 +0.370 的 37 分假收益，同解析器下为 +0.010；C4 历史波动带 ±0.09–0.10 使所有准备引用的差异都不可分辨。
- **测量下限不是固有属性**：轨迹重置协议下重测，标准差降至 0.003（MuSiQue）/0.007（2WikiMQA），修复服务栈后 σ=0，即 ±0.006–0.014，远小于 0.046 的界。
- **准确率与 RAG 持平**：所有差异都小于重现带。

## 7. 优点

- **首次把智能体架构的峰值 KV 作为"测量并消融"的系统量报告**，并澄清 RAG 与分解对记忆的不可互换性——"过滤证据更好，并不会缩小最大的一次调用"。
- **单轴消融设计干净**：两臂仅差两个 `kv_enabled` 操作，其余所有框执行一致；隔离检查机械化、可审计（不可读记录算失败而非"猜干净"）。
- **测量而非假设召回可达性**：精确复现检索器谓词，得到可达/不可达两组，后者构成内置对照，把"零效应"从"没测出来"升级为"结构性无信息可召"。
- **对四类测量偏差的坦诚与系统化**：C1–C4 以"条件"而非"bug"表述，且校正使单元**双向移动**（两升、一降、两回退）——作者据此论证这是测量的签名而非调参。
- **给出通用检测流程**（计数器强制非零、运行前查询存储、序列化请求 diff + 顺序平衡、用重复运行估波动带），不依赖知道具体缺陷。
- **可再推导性**：公布 `kv_layer_cost_ci.py` 等脚本，打印解析出的 run id 与每列 n；逐单元结果与逐数据集 KV 表分离报告。
- **附录对话日志**极具教育意义：一条 F1=0 掩盖了三种不同失败机制（合成器自我背离、表面形式与 gold 字符串不匹配等），并揭示 critic 把正确答案判为"事实错误"却被下游覆盖的真实系统行为。

## 8. 不足与局限

- **覆盖面**：单一系统、单一团队；条件"目标上通用、频率上未知"，且为重建而非推导；FLAT 臂单次运行；重现带基于 2–4 次重复，本身不精确。
- **核心主张的边界**："持久召回能提升准确率"是**未被检验**而非被证伪；本文只声称排除了大于约 0.046 的效应。
- **残留混淆风险**：C3 的顺序混淆（memory-on
