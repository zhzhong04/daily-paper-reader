## 摘要
提示特化的多智能体系统使多个智能体能够共享一个模型，同时扮演互补角色以解决复杂任务。然而，智能体特定的前缀会改变针对同一共享上下文生成的 KV 缓存，导致每个智能体重复预填充不断增长的上下文，并构建单独的缓存，从而带来高昂的计算和内存开销。选择性重计算可以减少这种冗余，但仍需保留大量模型执行；而现有的增量校正方法要么仅支持循环出现的上下文关系，要么为动态变化的上下文维护内存密集型的在线校正状态。对于首次出现的共享上下文，这些方法还会在智能体工作流之外构建参考缓存，并且第一个智能体处的近似校正会影响传递给后续智能体的输出。我们提出 KVCMAS，一种在线 KV 缓存校正框架，它使用紧凑的低秩状态表示跨智能体缓存偏差，并沿智能体工作流无缝地串联校正，而无需额外的参考预填充。该设计支持动态变化的共享上下文，同时保留精确的首个智能体缓存。在多种语言和视觉-语言工作负载中，KVCMAS 在高度并发服务下达到最低 TTFT 的同时，匹配或提升了先前 KV 缓存共享方法的准确率。在受控服务轨迹下，相较于无 KV 缓存共享的推理，它实现了 2.0 倍的 TTFT 加速，并且相较于先前的 KV 缓存校正方法，将峰值 GPU 内存最多降低 3.7 倍。这些结果确立了 KVCMAS 作为一种准确且可扩展的 KV 缓存共享方法，适用于提示特化的多智能体服务。

## Abstract
Prompt-specialized multi-agent systems enable multiple agents to share a model while performing complementary roles to solve complex tasks. However, agent-specific prefixes change the KV cache generated for the same shared context, causing each agent to repeatedly prefill the growing context and construct a separate cache with high computation and memory overhead. Selective recomputation reduces this redundancy but still retains substantial model execution, while existing delta correction methods either support only recurring context relations or maintain memory-intensive online correction states for dynamically changing context. For first seen shared context, these methods also construct a reference cache outside the agent workflow, and an approximate correction at the first agent affects the outputs passed to subsequent agents. We present KVCMAS, an online KV cache correction framework that represents cross-agent cache deviations using compact low-rank states and seamlessly chains corrections along the agent workflow without an additional reference prefill. This design supports dynamically changing shared context while preserving an exact first-agent cache. Across multiple language and vision-language workloads, KVCMAS matches or improves the accuracy of prior KV cache sharing methods while achieving the lowest TTFT under highly concurrent serving. Under controlled serving traces, it provides a 2.0x TTFT speedup over inference without KV cache sharing and reduces peak GPU memory by up to 3.7x relative to a prior KV cache correction method. These results establish KVCMAS as an accurate and scalable KV cache sharing approach for prompt-specialized multi-agent serving.

# KVCMAS 论文深度总结

## 1. 核心问题与研究背景

- **场景定位**：提示特化（prompt-specialized）的多智能体系统（MAS）中，多个智能体共享同一套模型权重，仅通过不同的角色提示词（role prompt）实现互补分工（规划、工具调用、评审、编排等），无需额外训练即可扩展新角色。
- **核心矛盾**：
  - 智能体轨迹由**智能体特定前缀段（PF）**与**共享上下文段（PH）**交替构成（如系统提示、胶水提示属于 PF；用户查询、检索信息、工具观测、前序智能体输出属于 PH）。
  - 同一 PH 段在不同智能体下因前置 PF 不同，会产生**不同的 KV 缓存**（`C_i,seg ≠ C_j,seg`），因此无法直接复用。
  - 若不复用，每个智能体都要重复预填充不断增长的上下文，随多轮交互、多智能体、多模态输入而急剧放大服务开销。
- **现有方法的两难**：
  - **选择性重计算**（DroidSpeak、CacheBlend、RelayCaching）：只重算部分层/词元，未覆盖的偏差仍残留；提高覆盖率则重算量增大，精度与效率难以兼顾（附录 A.1 显示至少一半误差无法被覆盖，VLM 任务上偏差/注意力选择仅去除约 20% 误差）。
  - **增量校正**（GraphFlow、Kamera）：仅针对**循环出现**的上下文关系构建校正，无法适应动态变化的用户请求与智能体输出。
  - **KVComm**：用在线锚点池支持动态上下文，但存储全维基缓存与智能体特定校正，内存随共享上下文长度增长（V=20、4K 段、4 智能体时 Llama-3.1-8B 约需 50 GiB）。
  - **非链式校正的通病**：对首次出现的共享上下文需在智能体工作流之外额外构建无上下文参考缓存；且第一个智能体的近似校正误差会作为共享上下文传播给后续智能体，放大聚合误差。

## 2. 方法论

### 2.1 核心思想

KVCMAS 是一个**在线 KV 缓存校正框架**，包含两大设计：

1. **低秩锚点池**：跨智能体缓存偏差集中在低维特征空间，用紧凑低秩因子存储在线校正状态。
2. **链式校正**：以工作流中自然产生的源智能体缓存作为参考，而非单独构建无上下文参考，从而消除额外参考预填充并保留精确的首个智能体缓存。

### 2.2 关键技术细节

**(1) 低秩在线校正**

- 观察：智能体特定增量校正的有效秩（保留 90% 奇异值能量的最小秩）在各负载下**均低于 32**，远小于完整特征维度；基缓存有效秩略高但结构相似（图 2）。
- 对每个键/值矩阵 `Z ∈ R^{L_seg × D}` 做截断 SVD：
  `Z = U_Z Σ_Z R_Z^T ≈ U_Z,r Σ_Z,r R_Z^T,r = A_Z B_Z`，其中 `A_Z ∈ R^{L_seg × r}`，`B_Z ∈ R^{r × D}`。
- 内存从 `O(V·N·L·D)` 降至 `O(V·N·r·(L+D))`。
- 重建的基表示仅用于锚点匹配；重建的校正被应用于源智能体缓存，物化出**全维目标缓存**，注意力仍使用全维 KV。
- 附录 A.2 进一步指出：PF 诱导偏差有效秩仅约 4–6（秩 8 即可保留 90% 能量），而动态变化的 PH 诱导偏差秩更高，是更难的校正目标。

**(2) 链式校正**

- 精确关系：`∆_{j←i,seg} = C_{j,seg} − C_{i,seg} = ∆_{j←ref,seg} − ∆_{i←ref,seg}`。
- 精确校正下，无上下文参考与源智能体参考在代数上等价；但经验校正下，参考选择决定近似误差。
- KVCMAS 对第一个智能体**密集预填充**得到精确缓存，之后每个物化的共享上下文缓存成为下一条工作流边的参考，形成链式校正（图 3 显示链式结构降低了逐层与逐智能体的聚合校正误差）。

**(3) 校正流程（图 1）**

1. 第一个智能体密集预填充，产生精确缓存。
2. 对从智能体 i 到 j 的共享段转移：重新对齐 key 位置 → 源缓存与在线锚点匹配 → 估计校正。
3. 每个共享占位槽维护一个锚点池，锚点存储低秩基缓存与各消费智能体的校正。
4. 相似度加权估计校正：`∆̂_{j←i,seg} = Σ_v w_v A_{∆,v} B_{∆,v}`，权重归一化 `Σ w_v = 1`。

**(4) 可靠性门控**

- 对长度为 k 的比较前缀，用各层值状态距离 `d_gate_v` 经温度 T=1 的 softmax 得到门控权重 `g_v`。
- 归一化熵 `H(g) = −Σ g_v log₂ g_v / log₂|A_k|`；`H(g) ≤ τ` 时接受校正，否则回退密集预填充；可比较锚点少于 2 个时直接密集预填充。
- 位置对齐：key 在统一规范坐标下匹配，校正后对齐到目标位置；value 无需旋转。
- 变长段：锚点不填充、不按长度分池；无覆盖锚点时只校正最长覆盖前缀，剩余行保留位置重对齐后的源缓存。
- 池更新：接受校正不重新插入；密集回退后分解源缓存与观测校正并插入新锚点；池满时在五个最旧条目中淘汰最不常用者。
