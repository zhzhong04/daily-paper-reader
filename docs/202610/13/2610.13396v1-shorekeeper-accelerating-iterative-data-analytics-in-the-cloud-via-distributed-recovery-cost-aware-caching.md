## 摘要
由迭代图或机器学习处理驱动的大规模数据密集型工作负载，由于不断生成新的中间数据，对内存有着永无止境的需求。尽管现有缓存策略力求将性能关键数据保留在内存中，但它们在实践中往往失效，因为它们局限于节点本地内存管理，并假设节点具有高可用性。本文提出 ShoreKeeper，一个将集群范围内存视为统一、弹性资源池以最大化执行效率的框架。ShoreKeeper 采用全局优化模型，将分布式数据流映射为单一图抽象，以最小化集群范围内从缓存中被逐出数据的恢复代价。为应对随时间波动的内存工作集和集群容量，ShoreKeeper 采用图剪枝技术，可快速细化缓存方案。这些优化使 ShoreKeeper 无论部署在高可用虚拟机还是云中经济高效的可抢占实例上，都能无缝工作。我们的实验表明，ShoreKeeper 始终优于最先进的系统。

## Abstract
Large-scale data-intensive workloads powered by iterative graph or machine learning processing have an insatiable demand for memory due to the continuous generation of new intermediate data. Although existing caching strategies strive to keep performance-critical data in memory, they often fail in practice because they are limited to node-local memory management and assume high node availability. In this paper, we introduce ShoreKeeper, a framework that maximizes execution efficiency by treating cluster-wide memory as a unified, elastic pool. ShoreKeeper employs a global optimization model that maps distributed dataflows into a single graph abstraction to minimize the recovery cost of data evicted from cache across the cluster. To handle memory working sets and cluster capacities that fluctuate over time, ShoreKeeper employs a graph-pruning technique that permits the fast refinement of the caching plan. These optimizations allow ShoreKeeper to work seamlessly whether deployed on highly available VMs or cost-effective preemptible instances in the cloud. Our experiments show that ShoreKeeper consistently outperforms state-of-the-art systems.
