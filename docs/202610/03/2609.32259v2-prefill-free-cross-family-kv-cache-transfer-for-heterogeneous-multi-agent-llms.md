## 摘要
近期的多智能体LLM系统越来越多地将异构模型组合起来，以服务于专门化的智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。复用发送方的键值（KV）缓存可以避免这种冗余，但跨模型家族的免预填充传输必须处理分词、模型深度和KV表示方面的差异。为解决这些问题，我们提出HeteroFold，一种免预填充的跨家族KV缓存传输方法，使发送方和接收方均保持冻结。HeteroFold对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold在所有四个长上下文基准和大多数短上下文设置上均取得了最佳的缓存传输性能。它在多智能体基准上也与基于文本的通信相当。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B传输比Native Prefill快10.7倍，比最先进的免预填充基线Dense Latent和KV Ridge快1.18–1.47倍。这些结果表明，HeteroFold能够在接收方无需预填充的情况下实现高效的跨家族KV复用。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多智能体 LLM 系统（MAS）日益采用异构模型组合——不同家族、不同规模的模型承担求解器、评估器、聚合器等专门化角色（如 X-MAS、MetaGPT 等）。这类系统在协作过程中需要频繁交换共享上下文。
- **核心痛点**：现有通信以文本为载体，接收方必须对发送方已处理过的共享上下文**重新预填充（prefill）**，并重建自身的 KV 缓存。随着上下文增长，这带来大量冗余计算与延迟（每轮通信都要重复）。
- **理想方案**：直接复用发送方的 KV 缓存，实现免预填充通信。但跨模型家族传输面临三重不匹配：
  - **分词器差异**：不同模型对同一文本切分方式不同，token 边界不对齐；
  - **模型深度差异**：层数不同，无法逐层对应；
  - **KV 表示差异**：头数、维度、特征分布不同。
- **关键洞察**：仅降低缓存重建误差并不足够。论文图 2 显示，KV Ridge 的重建误差低于 HeteroFold，但其注意力权重与注意力输出误差反而更大——**有效传输必须保持接收方的下游计算行为，而不仅是缓存数值本身**。
- **整体含义**：HeteroFold 是（据作者称）首个具有显式跨分词器对齐的、接收方免预填充的跨家族 KV 缓存传输方法，为异构 LLM 智能体之间的高效缓存共享提供了可行路径。

## 2. 方法论：HeteroFold 的核心思想与关键技术

### 2.1 总体框架
给定冻结的发送方 $\mathcal{S}$（$L_S$ 层）与接收方 $\mathcal{R}$（$L_R$ 层），HeteroFold 将发送方缓存 $\mathcal{C}_S(x)$ 映射为接收方可直接解码的缓存 $\hat{\mathcal{C}}_R(x)$，**无需接收方预填充**，且两个模型均保持冻结。流程包含三步：**Token 与层对齐 → Recolor KV 映射 → 输出感知校准**。

### 2.2 Token 对齐（Token Alignment, TA）
- 以**共享字符结束边界**建立发送方–接收方 token 对应关系。
- 对未匹配的接收方边界，复用最近的前一个共享边界处的发送方状态；首个匹配之前使用第一个发送方状态。
- **多对一情况不做平均**，直接取共享边界处的发送方 token 状态。
- 示例：Qwen3 切分为 `The | unbelievable | result | .`，Ministral-3 切分为 `The | unbel | iev | able | result | .`，接收方字符位置 9、12 处的 token 复用 Qwen3 在字符 3 处的状态。
- 映射后接收方使用**自己的位置索引**重新施加 RoPE。

### 2.3 层对齐（Layer Alignment, LA）
- 采用比例深度对齐：$\pi(\ell) = 1 + \text{round}\left(\frac{(\ell-1)(L_S-1)}{L_R-1}\right)$。
- 以匹配层为中心取 **3 个发送方层**（偏移 −4、0、+4），并裁剪到模型边界：$N(\ell) = \text{clip}_{[1,L_S]}\{\pi(\ell)-4, \pi(\ell), \pi(\ell)+4\}$。
- 将所选层的 K/V 特征**展平拼接**，使头数不同的模型也能进行跨头映射：$x_{\ell,c}^n = [c_{S,i_n}^{t_1} \| c_{S,i_n}^{t_2} \| c_{S,i_n}^{t_3}]$。
- 动机：图 4(a) 显示多层聚合对预测接收方原生 K/V 的 $R^2$ 高于单层。

### 2.4 Recolor：矩匹配的 KV 映射
- 对每个接收方层和角色 $c \in \{K, V\}$，收集 N 个对齐 token 对 $(X, Y)$。
- 先做全局 RMS 归一化：$r = \sqrt{\frac{\sum_n w_n \|x_n\|_2^2}{\tilde{d}_S \sum_n w_n}}$，$Z = X/r$（$r$ 推理时固定）。
- **白化 → Procrustes 对齐 → 重着色**：
  - 对 $\Sigma_Z^{-1/2}\Sigma_{ZY}\Sigma_Y^{-1/2}$ 做薄 SVD 得 $U\Lambda Q^\top$，取 $R^\star = UQ^\top$；
  - 最终仿射映射：$A = \Sigma_Z^{-1/2} R^\star \Sigma_Y^{1/2}$，$b = \mu_Y - \mu_Z A$，$y^{(0)} = (x/r)A + b$。
- 在 $\tilde{d}_S \geq d_R$ 且协方差非奇异时，该映射可精确匹配接收方均值与协方差（数值稳定化使其近似成立）。
- 动机：图 4(b,c) 显示 Recolor 比 Ridge（$\ell_2$ 正则最小二乘）更接近原生 K/V 分布。

### 2.5 输出感知校准（Output-Aware Calibration）
- 观察到 Recolor 后仍存在注意力输出残差（图 4(d)），因此将 KV 量化中的输出感知校准思想迁移至跨家族传输。
- 注意力输出差异可分解为：
  $$\hat{O} - O^* = \underbrace{[(\hat{P} - P^*)V^*]W_O^\top}_{\text{key 引起的变化}} + \underbrace{[\hat{P}(\hat{V} - V^*)]W_O^\top}_{\text{value 引起的变化}}$$
- 据此对 K 和 V 分别添加**秩 16 的低秩修正**：$\hat{y}_{\ell,c} = y^{(0)}_{\ell,c} + (y^{(0)}_{\ell,c} B_{\ell,c}) G_{\ell,c}$，其中 $B \in \mathbb{R}^{d_R \times \rho_c}$、$G \in \mathbb{R}^{\rho_c \times d_R}$，**仅训练 B、G，G 初始化为零**。
- **Key 损失**：匹配注意力模式 + 其经输出投影后的影响
  $$\mathcal{L}_{\ell,K} = \mathbb{E}\left[D_{KL}(P^*_{\ell,h,p} \| \hat{P}_{\ell,h,p}) + \frac{\|\Delta O_{K,\ell,h,p}\|_2^2}{d_{model}^R}\right]$$
- **Value 损失**：固定映射后的注意力权重，优化 value 以匹配最终输出
  $$\mathcal{L}_{\ell,V} = \mathbb{E}\left[\frac{\|\hat{O}_\ell - O^*_\ell\|_F^2}{\max(\|O^*_\ell\|_F^2, \epsilon)}\right]$$
- 校准仅使用问题跨度内的原生接收方 query/attention/value/output，**不使用 gold 答案或生成续写**。
- **推理折叠**：校准后将修正折入仿射映射：$A_{final} = A(I + BG)$，$b_{final} = b(I + BG)$，推理时每层每角色仅一个固定仿射映射，无需额外推理模块。

### 3.3 对比方法
- **TextMas**：标准文本通信 + 接收方原生预填充（无损参考上界）。

## 6. 主要结论与发现

- **缓存传输性能**：HeteroFold 在**全部四个长上下文基准**和**大多数短上下文设置**上优于所评估的缓存传输基线（Dense Latent、KV Ridge 及其 +TA 变体），且在六个方向上一致。
- **多智能体通信**：在 HiddenBench 上，HeteroFold 的平均准确率 30.6%、多数投票准确率 29.2%、无效率 3.2%，**与 TextMas（29.2%/27.7%/4.0%）相当**，同时显著优于 Dense Latent + TA（18.5%/7.7%/3.2%）与 KV Ridge + TA（21.8%/16.9%/20.9%）。
- **延迟优势**：32K 上下文下，Llama-3.1-8B→Ministral-3-14B 传输比 Native Prefill **快 10.7×**，比 Dense Latent/KV Ridge **快 1.18–1.47×**；4K 时约 3.5–3.8×，随上下文增长而扩大。
- **行为保持**：在 QuALITY 上，HeteroFold 的 next-token KL、attention KL 更低，答案一致率更高，说明其更接近原生接收方行为。
- **Token 对齐重要性**：同索引配对的位置错配随上下文增长而增大（图 5），TA 可维持接近对齐；消融中替换 TA 导致最大性能下降（GSM8K 从 63.46 降至 7.13）。
- **缓存重建误差 ≠ 行为保持**：KV Ridge 重建误差更低但行为更差，支持"输出感知"校准的必要性。
- **同家族也有效**：在 Qwen3 同家族传输

中，HeteroFold 也优于或接近原生预填充，说明该框架并非仅针对跨家族场景的特化技巧，同时可作为实现正确性的 sanity check。  
- **自然语言内容保持**：在 GSM8K 问题重建任务中，传输后的缓存仍能支撑较高保真度的内容恢复，表明映射未严重破坏语义信息。  
- **自回归解码稳定性**：长程生成未出现明显崩溃或重复退化，说明校准后的缓存可作为接收方后续解码的可用初始状态。  
- **效率—性能权衡**：以约 0.40–0.50 GB 的 mapper 存储和一次性校准成本，换取免接收方预填充推理；在长上下文与多轮通信中收益随上下文增长而放大。  
- **误差归因**：token 边界错配与 KV 分布偏移是主要瓶颈，TA 与 Recolor 分别缓解这两类问题；输出感知校准进一步弥补剩余的下游行为差距。

## 7. 局限性与批判性分析

- **校准依赖接收方原生中间量**：输出感知校准需要收集接收方在问题跨度内的 query、attention、value 与 output，虽然不使用 gold 答案，但在实际部署中仍需可访问接收方内部状态并准备校准语料。  
- **模型覆盖范围有限**：实验仅覆盖 Llama-3.1-8B、Qwen3-4B、Ministral-3-14B 三类稠密模型与六个方向，尚未验证 MoE、超长上下文专用架构、多模态模型或词表/深度差异更极端的组合。  
- **层对齐假设较启发式**：比例深度对齐与固定偏移邻域在均匀堆叠的 Transformer 上较自然，但对层功能分布不均、跨层跳跃连接复杂或深度差异极大的模型，可能不是最优。  
- **Token 对齐的边界情形**：共享字符结束边界对英文和常见子词分词较有效，但对多语言、代码、Unicode 组合字符、表情符号等，字符级边界可能不稳定，论文未充分展开。  
- **理论保证有限**：Recolor 的矩匹配在理想条件下可匹配一阶、二阶统计量，但数值稳定化、低秩校准和有限校准样本使其更接近经验性近似，缺乏对下游任务误差的严格界。  
- **隐私与安全风险**：直接传输 KV 缓存可能比文本通信泄露更多中间表示信息，跨智能体信任、缓存投毒、恶意发送方等场景未被讨论。  
- **延迟结论的部署依赖性**：10.7× 等加速在 NVLink 连接的双 H100 环境下测得，真实多节点、网络受限或批处理场景下收益可能变化。  
- **基线复现风险**：Dense Latent、KV Ridge 等基线为作者自行实现，缺少公开代码与独立复现，绝对比较优势仍需第三方验证。  
- **多智能体评测绝对值不高**：HiddenBench 上平均准确率约 30%，虽与 TextMas 相当，但任务本身仍具挑战性，说明缓存传输并未解决智能体协作的全部推理瓶颈。

## 8. 总体评价与启示

HeteroFold 的核心贡献在于把“跨家族 KV 缓存传输”从单纯的缓存数值回归，推进为**面向接收方下游行为的免预填充通信**。其方法设计具有清晰的工程闭环：先用共享字符边界解决 tokenizer 不对齐，再用比例层对齐与跨头拼接处理深度和头数差异，随后用 Recolor 做分布级矩匹配，最后用输出感知低秩校准弥补行为残差，并将校准折叠回仿射映射以保证推理零额外模块。实验上，论文覆盖长上下文 QA、短上下文 QA 与多智能体通信，提供了消融、敏感性、延迟和行为保持分析，整体论证较为完整。

其实际意义在于：当异构 LLM 智能体需要反复共享同一长上下文时，HeteroFold 可显著减少接收方重复 prefill，并在部分设置下接近文本通信的无损上界。不过，它仍不是“即插即用”的通用协议：校准数据、接收方内部状态访问、模型架构假设和安全性问题，都会影响真实部署。未来值得关注的方向包括：更鲁棒的跨分词器对齐、无需接收方中间量的轻量校准、对 MoE/多模态模型的扩展，以及 KV 缓存传输的隐私保护与信任机制。
