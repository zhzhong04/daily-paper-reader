## 摘要
近年来的多智能体LLM系统越来越多地组合异构模型，以承担专门的智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。复用发送方的键值（KV）缓存可以避免这种冗余，但跨模型家族的免预填充传输必须处理分词、模型深度和KV表示方面的差异。为解决这些问题，我们提出 HeteroFold，一种免预填充的跨家族KV缓存传输方法，使发送方和接收方均保持冻结。HeteroFold 对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold 在所有四个长上下文基准和大多数短上下文设置上取得了最佳的缓存传输性能。它在多智能体基准上也与基于文本的通信相当。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B 传输比 Native Prefill 快 10.7×，比最先进的免预填充基线 Dense Latent 和 KV Ridge 快 1.18–1.47×。这些结果表明，HeteroFold 能够实现高效的跨家族 KV 复用，而无需接收方预填充。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多智能体 LLM 系统（MAS）越来越多地采用异构模型（不同家族、不同规模）来承担专门角色（求解者、评估者、聚合者等），如 X-MAS、MetaGPT、AutoGen 等框架。
- **核心痛点**：异构智能体之间需要交换共享上下文，但基于文本的通信要求**每个接收方重新预填充（prefill）** 发送方已经处理过的文本，并重建自己的 KV 缓存。随着上下文长度增长，这种冗余计算与延迟被显著放大。
- **可行的思路**：直接复用发送方的 KV 缓存，实现"免接收方预填充"（prefill-free）传输。但跨模型家族传输必须解决三类错配：
  1. **分词器不匹配**（tokenization mismatch）；
  2. **模型深度不同**（layer/depth mismatch）；
  3. **KV 表示分布不同**（KV representation mismatch）。
- **关键洞察**：作者指出，**仅仅降低缓存重建误差并不等于保持接收方行为**。例如 KV Ridge 的 KV 重建误差低于 HeteroFold，但其传输后接收方的注意力模式被扭曲（图 2：KV Ridge 在 attention weights 上误差 1.14，而 HeteroFold 仅 0.51）。因此，有效的传输必须保持的不只是缓存数值，而是其**下游引发的接收方计算行为**。
- **现有工作局限**：
  - TextMas（标准文本通信）：需要接收方预填充；
  - C2C：需要接收方先生成 prompt cache，未消除接收方预填充；
  - Recursive MAS：传输的是隐表示，仍需经过接收方各层处理，不是即解码可用的 KV；
  - LatentMAS：假设缓存兼容；
  - Dense Latent、KV Ridge：虽免预填充，但原评估都在**同家族、共享分词器**的场景内，未处理跨家族错配。
- **整体含义**：HeteroFold 是（作者所称）**首个具备显式跨分词器对齐、且无需接收方预填充的跨家族 KV 缓存传输方法**，为异构多智能体间的高效缓存共享提供了一条可行路径。

## 2. 方法论：核心思想与关键技术细节

**核心思想**：在**发送方与接收方模型均冻结**的前提下，将发送方 KV 缓存经"结构对齐 → 空间映射 → 行为校准"三步，转换为接收方可直接解码的兼容缓存；所有学习到的修正最终折叠为固定的仿射映射，推理时无额外模块。

**整体流程（图 3）**：

### 2.1 Token 与层对齐（Token and Layer Alignment）

- **Token Alignment (TA)**：以**共享字符结束边界**建立发送方—接收方 token 的对应关系。
  - 对未匹配的接收方边界，采用"最近的前一个共享边界"处的发送方状态（前向填充）；
  - 多对一情形**不做平均**，直接使用匹配字符边界处的发送方 token；
  - 第一个匹配之前的接收方位置使用发送方第一个 token；
  - 映射完成后，接收方使用**自己的位置索引**施加 RoPE。
  - 示例："The unbelievable result." 中 Qwen3 分词为 `The | unbelievable | result | .`，Ministral-3 分词更细，两者通过字符边界对齐。
- **Layer Alignment (LA)**：采用按相对深度比例对齐，并聚合邻域多层：
  - π(ℓ) = 1 + round((ℓ−1)(L_S−1)/(L_R−1))；
  - 取偏移 (−4, 0, +4) 三个发送方层：N(ℓ) = clip[1, L_S](π(ℓ)−4, π(ℓ), π(ℓ)+4)；
  - 将这三层的 K/V 特征**跨全部 head 展平后拼接**，以支持 head 数不同的跨头映射。
  - 图 4(a) 表明多层输入对预测原生接收方 K/V 的 R² 明显高于单层。

### 2.2 矩匹配的 Recolor KV 映射（Moment-Matched Recoloring）

- 对每个接收方层与角色 c ∈ {K, V}，收集 N 个对齐 token 对，堆叠为 X（发送方，维度 3·d_KV^S）与 Y（接收方目标，d_KV^R）。
- 计算全局标量 RMS：r = sqrt( Σ w_n‖x_n‖² / (d̃_S · Σ w_n) )，Z = X/r。
- 白化后做 **Procrustes 对齐**（SVD：Σ_Z^{−1/2} Σ_ZY Σ_Y^{−1/2} = UΛQᵀ，R* = UQᵀ）。
- 恢复接收方协方差与均值，得到 Recolor 初始化：
  - **A = Σ_Z^{−1/2} R* Σ_Y^{1/2}**，**b = μ_Y − μ_Z A**，y⁽⁰⁾ = (x/r)A + b。
  - 理论上满足 μ_Z A + b = μ_Y 且 AᵀΣ_Z A = Σ_Y（协方差匹配）。
- 动机：Ridge（ℓ2 正则最小二乘）重建误差低但分布失真，Recolor 更贴近接收方原生 K/V 分布（图 4(b,c)）。

### 2.3 输出感知校准（Output-Aware Calibration）

- 将传输前后的注意力输出差分解为两项：
  - **键引起的变化**：[(P̂ − P*)V*]W_Oᵀ；
  - **值引起的变化**：[P̂(V̂ − V*)]W_Oᵀ。
  - 这一分解为 K 和 V 分别设计校准目标提供依据。
- 在 Recolor 输出上加入**秩 ρ_c = 16 的低秩修正**：
  - ŷ = y⁽⁰⁾ + (y⁽⁰⁾B)G，B ∈ R^{d_R×ρ_c}，G ∈ R^{ρ_c×d_R}；
  - **只训练 B、G**（G 初始化为 0，B 用 std=0.02 的零均值正态初始化），模型与初始映射保持冻结。
- **键目标**：匹配原生注意力权重（KL 散度）+ 键引起的投影后输出误差平方；
  **值目标**：在固定映射注意力权重下，最小化归一化输出误差（Frobenius 范数比）。
- 校准仅使用**问题跨度内的 token**（重叠 prompt 的问题部分）上的原生 query、attention、value、output，**不使用金答案或生成的续写**。
- 优化：K/V 目标联合训练 4 个 epoch，AdamW，lr=3e−4，weight decay=1e−4，梯度裁剪 1，选留出损失最低的 checkpoint。

### 2.4 推理折叠（Folding for Inference）

- 校准后把低秩修正折叠进仿射映射：
  - **A_final = A(I + BG)**，**b_final = b(I + BG)**；
  - Φ_{ℓ,c}(x) = (x/r)A_final + b_final。
- 推理时每个接收方层、每个角色仅用一个固定仿射映射，**无独立修正模块**；映射特征重塑为接收方 KV head，K 由接收方施加原生 key normalization 与 RoPE。
- 存储成本：每个方向约 201–252 M 参数（BF16 约 0.40–0.50 GB），比 Dense Latent 少约 25%，比 KV Ridge 少约 62%。
