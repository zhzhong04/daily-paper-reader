## 摘要
提示词专门化的多智能体系统使多个智能体能够共享一个模型，同时扮演互补角色以解决复杂任务。然而，智能体特定的前缀会改变为同一共享上下文生成的 KV 缓存，导致每个智能体重复预填充不断增长的上下文，并构建独立的缓存，带来高昂的计算和内存开销。选择性重计算可减少这种冗余，但仍保留大量模型执行；而现有的增量校正方法要么仅支持重复出现的上下文关系，要么为动态变化的上下文维护内存密集型的在线校正状态。对于首次出现的共享上下文，这些方法还会在智能体工作流之外构建参考缓存，并且第一个智能体处的近似校正会影响传递给后续智能体的输出。我们提出 KVCMAS，一种在线 KV 缓存校正框架，它使用紧凑的低秩状态表示跨智能体的缓存偏差，并沿智能体工作流无缝串联校正，而无需额外的参考预填充。该设计支持动态变化的共享上下文，同时保留精确的首个智能体缓存。在多种语言和视觉-语言工作负载上，KVCMAS 在高度并发服务下达到最低 TTFT，同时匹配或优于先前 KV 缓存共享方法的准确率。在受控的服务轨迹下，相较于未使用 KV 缓存共享的推理，它将 TTFT 加速 2.0 倍，并且相较于先前的 KV 缓存校正方法，将峰值 GPU 内存最多降低 3.7 倍。这些结果确立了 KVCMAS 是一种准确且可扩展的 KV 缓存共享方法，适用于提示词专门化的多智能体服务。

## Abstract
Prompt-specialized multi-agent systems enable multiple agents to share a model while performing complementary roles to solve complex tasks. However, agent-specific prefixes change the KV cache generated for the same shared context, causing each agent to repeatedly prefill the growing context and construct a separate cache with high computation and memory overhead. Selective recomputation reduces this redundancy but still retains substantial model execution, while existing delta correction methods either support only recurring context relations or maintain memory-intensive online correction states for dynamically changing context. For first seen shared context, these methods also construct a reference cache outside the agent workflow, and an approximate correction at the first agent affects the outputs passed to subsequent agents. We present KVCMAS, an online KV cache correction framework that represents cross-agent cache deviations using compact low-rank states and seamlessly chains corrections along the agent workflow without an additional reference prefill. This design supports dynamically changing shared context while preserving an exact first-agent cache. Across multiple language and vision-language workloads, KVCMAS matches or improves the accuracy of prior KV cache sharing methods while achieving the lowest TTFT under highly concurrent serving. Under controlled serving traces, it provides a 2.0x TTFT speedup over inference without KV cache sharing and reduces peak GPU memory by up to 3.7x relative to a prior KV cache correction method. These results establish KVCMAS as an accurate and scalable KV cache sharing approach for prompt-specialized multi-agent serving.

# KVCMAS 论文总结

## 1. 核心问题与整体含义
- **研究背景**：提示词专门化的多智能体系统（MAS）中，多个智能体共享同一模型权重，但使用不同的角色前缀（system prompt、glue prompt）扮演规划、执行、批评、反思等互补角色。
- **核心问题**：共享上下文（PH 段，如用户查询、工具观察、其他智能体输出）内容相同，但由于各智能体前缀不同，同一共享上下文会生成不同的 KV 缓存，即 \(C_{i,seg}\neq C_{j,seg}\)。这导致每个智能体重复预填充不断增长的上下文，并保留独立 KV 缓存，带来高昂计算与显存开销。
- **现有方法局限**：
  - 选择性重计算只重建部分层/Token，未覆盖的缓存偏差仍存在，且精度提升依赖更多模型执行。
  - 增量校正中，GraphFlow、Kamera 等只适合重复出现的上下文关系，难以处理动态新请求。
  - KVComm 支持动态上下文，但以全维形式存储在线锚点与校正，显存随共享上下文、锚点数、智能体数增长。
  - 已有校正方法通常需在智能体工作流外构建 context-free 参考缓存；首个智能体的近似校正误差还会传播到后续智能体。
- **整体含义**：KVCMAS 旨在为提示词专门化 MAS 提供一种**在线、低秩、链式**的 KV 缓存校正框架，在保持准确率的同时降低 TTFT 和峰值显存，支持动态共享上下文。

## 2. 方法论
### 2.1 核心思想
- 跨智能体 KV 缓存偏差集中在低维特征空间，可用低秩状态紧凑表示。
- 校正应沿智能体工作流“链式”传递：首智能体精确 dense prefill，后续边以上一智能体已产生的缓存为参考，避免额外 context-free 参考预填充。
- 对每个共享段，若锚点匹配可靠则应用低秩增量校正，否则回退到 dense prefill。

### 2.2 关键技术细节
- **上下文共享约定**：智能体轨迹交替包含智能体特定前缀段 PF 和共享上下文段 PH。PF 不跨智能体共享，PH 是 KV 缓存复用与校正目标。
- **低秩锚池**：
  - 每个共享上下文槽维护最多 \(V\) 个锚点。
  - 锚点存储 base cache 与 delta correction 的低秩因子，经截断 SVD：
    \[
    Z \approx U_{Z,r}\Sigma_{Z,r}R_{Z,r}^\top = A_Z B_Z
    \]
  - 锚点内存从 \(O(VNLD)\) 降至 \(O(VNr(L+D))\)，其中 \(r\) 为秩，\(N\) 为消费智能体数，\(L\) 为段长，\(D\) 为特征维。
- **链式校正**：
  - 从源智能体 \(i\) 到目标智能体 \(j\) 的精确校正为：
    \[
    \Delta_{j\leftarrow i,seg}=C_{j,seg}-C_{i,seg}=\Delta_{j\leftarrow ref,seg}-\Delta_{i\leftarrow ref,seg}
    \]
  - 与 context-free 参考相比，链式参考来自实际工作流，减少近似误差，并避免额外参考预填充。
- **在线估计**：
  - 将当前源缓存与各锚点重建的 base cache 比较，按相似度赋权。
  - 校正估计为低秩增量加权组合：
    \[
    \hat{\Delta}_{j\leftarrow i,seg}=\sum_{v=0}^{V-1} w_v A_{\Delta,v}B_{\Delta,v},\quad \sum_v w_v=1
    \]
  - 接受校正后，将 \(\hat{\Delta}\) 加到位置对齐后的源缓存上，物化全维目标缓存，供普通注意力使用，并作为下一工作流边的参考。
- **可靠门控与回退**：
  - 用锚点匹配权重的归一化熵衡量可靠性，\(H(g)\leq \tau\) 时接受校正，否则 dense prefill。
  - 匹配少于两个锚点也触发 dense prefill。
  - 位置对齐：keys 在统一位置坐标下匹配并旋转到目标位置，values 无需旋转。
- **锚池更新**：dense fallback 后计算观测到的源到目标校正，低秩分解并插入新锚点；接受校正不重新插入；池满时按 LFU 驱逐较旧锚点。
