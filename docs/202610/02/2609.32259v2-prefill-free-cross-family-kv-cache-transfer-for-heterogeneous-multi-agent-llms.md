## 摘要
近期多智能体LLM系统越来越多地结合异构模型以承担专门化智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。复用发送方的键值（KV）缓存可避免这种冗余，但跨模型家族的免预填充传输必须处理分词、模型深度和KV表示方面的差异。为解决这些问题，我们提出HeteroFold，一种免预填充的跨家族KV缓存传输方法，保持发送方和接收方均冻结。HeteroFold对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold在全部四个长上下文基准和大多数短上下文设置上取得最佳缓存传输性能。它在多智能体基准上也达到与基于文本的通信相当的表现。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B传输比Native Prefill快10.7倍，比最先进的免预填充基线Dense Latent和KV Ridge快1.18–1.47倍。这些结果表明，HeteroFold能够实现高效的跨家族KV复用，而无需接收方预填充。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

- **理想方案**：直接复用发送方的 KV 缓存，让接收方**免预填充**即可解码。但跨模型家族时存在三重错配：
  - **分词器差异**（token 边界不对齐）；
  - **模型深度差异**（层数不同，信息分布位置不同）；
  - **KV 表示差异**（头数、特征分布、归一化/RoPE 位置不同）。
- **关键观察（论文的核心洞察）**：**缓存重建误差小 ≠ 接收方行为被保留**。图 2 显示 KV Ridge 在 K/V 重建误差上低于 HeteroFold，但其注意力权重 KL 与注意力输出误差都更差——即它扭曲了接收方的注意力。因此有效传输必须保留的不只是缓存数值，而是**其诱导出的下游接收方计算**。
- **整体含义**：论文提出 HeteroFold，作者称其为**首个带显式跨分词器对齐的、接收方免预填充的跨家族 KV 缓存传输方法**，为异构 LLM 智能体之间的高效缓存共享与更通用的跨家族 KV 接口迈出一步。

## 2. 方法论

### 2.1 总体框架

- 设冻结的发送方 **S**（L_S 层）与接收方 **R**（L_R 层），HeteroFold 将发送方缓存 C_S(x) 映射为接收方可直接解码的缓存 Ĉ_R(x)，**双方模型均保持冻结**，且推理时不需要额外的校正模块。
- 三大组件：**Token & Layer Alignment（对齐）→ Recolor（KV 映射）→ Output-Aware Calibration（接收方行为校准）**。
- 映射位置约定：**K 在 key normalization 与 RoPE 之前映射，V 在 value projection 之后映射**；接收方随后施加自己原生的 key normalization 与 RoPE（RoPE 用 FP32，KV 用 BF16）。

### 2.2 Token Alignment（TA）

- 通过**共享的字符结束边界**建立发送方—接收方 token 对应关系：配对结束于同一字符位置的 token。
- 接收方边界在发送方无精确匹配时，**回填到最近的更早共享边界对应的发送方状态**；首个匹配之前的位置用发送方第一个 token。
- **多对一情形不做平均**，直接取该字符边界处的发送方 token，以匹配同一因果前缀端点。
- 之后接收方按**自己的位置索引**施加 RoPE。示例：Qwen3 把 "The unbelievable result." 切成 4 个 token，Ministral-3 切成 6 个，字符边界 9、12 处的接收方 token 复用发送方结束于字符 3 的状态。

### 2.3 Layer Alignment（LA）

- 动机（图 4a）：接收方所需信息可能分散在发送方多层中，聚合邻近层比单层更能预测接收方原生 K/V。
- 采用**比例深度对齐**：π(ℓ) = 1 + round((ℓ−1)(L_S−1)/(L_R−1))，并取偏移 (−4, 0, +4) 三层，裁剪到 [1, L_S]，记为 N(ℓ)。
- 对每个角色 c ∈ {K, V}，将选中的三个发送方层特征**展平拼接**（含所有 KV 头）作为输入 x，接收方对应 token 特征为监督目标 y：x = [c^{t1} ∥ c^{t2} ∥ c^{t3}]，y = c^{R,ℓ}。展平使得**头数不同也能做跨头映射**。

### 2.4 Moment-Matched Recolor

- 动机：逐 token 重建目标（Dense Latent、KV Ridge）可在低重建误差下扭曲注意力；Recolor 直接匹配接收方特征的一阶、二阶统计量。
- 流程（每个接收方层、每个角色 K/V 各一套映射）：
  1. 对拼接特征 X 计算全局标量 RMS r，得到 Z = X/r（r 在推理时固定）；
  2. 计算加权均值 μ_Z, μ_Y、协方差 Σ_Z, Σ_Y 与互协方差 Σ_ZY；
  3. 对两个特征空间做白化，再用 **Procrustes 对齐**配对的 token，薄 SVD 得 Σ_Z^{-1/2}Σ_ZYΣ_Y^{-1/2} = UΛQᵀ，R\* = UQᵀ；
  4. 恢复接收方协方差与均值：**A = Σ_Z^{-1/2} R\* Σ_Y^{1/2}，b = μ_Y − μ_Z A**，初始映射 y^(0) = (x/r)A + b。
- 理论上（d̃_S ≥ d_R 且协方差非奇异）该无正则映射满足 μ_Z A + b = μ_Y 且 AᵀΣ_Z A = Σ_Y；实际中数值稳定化使协方差匹配近似成立。

### 2.5 Output-Aware Calibration

- 动机（图 4d）：Recolor 只保证全局统计结构，注意力输出误差仍残留。论文把面向 KV 量化的 output-aware 校准（Yun et al., 2026）迁移到跨家族缓存传输。
- 误差分解：**Ô − O\* = [(P̂ − P\*)V\*]W_Oᵀ（key 诱导） + [P̂(V̂ − V\*)]W_Oᵀ（value 诱导）**，因此对 K 和 V 分别设目标。
- 在校准映射上叠加**秩 ρ 的低秩校正**：ŷ = y^(0) + (y^(0)B)G，B ∈ R^{d_R×ρ}，G ∈ R^{ρ×d_R}，ρ = 16，G 初始化为 0；**只训练 B、G，映射与两个模型都冻结**。
- 损失函数：
  - Key 目标：L_K = E[ D_KL(P\* ∥ P̂) + ∥ΔO_K∥²/d_model^R ]，其中 ΔO_K 是 key 诱导的、经输出投影后的输出变化，用接收方原生 query、value，逐 query head 计算并按头与问题 token 平均（GQA 下按对应 KV 头映射）。
  - Value 目标：L_V = E[ ∥Ô − O\*∥_F² / max(∥O\*∥_F², ε) ]，固定映射后的注意力权重 P̂，只优化 V（对 P̂ 停梯度）。
- 校准只用**与问题 span 重叠的 token**上的原生 query/attention/value/output，**不使用金标答案或生成续写**；两目标联合优化 4 个 epoch，AdamW，lr 3×10⁻⁴，weight decay 10⁻⁴，梯度裁剪 1，B ~ N(0, 0.02)，按最低联合 held-out loss 选 checkpoint。
- **折叠推理**：Afinal = A(I + BG)，bfinal = b(I + BG)，每个接收方层、每个角色只需一个固定仿射映射，推理时无额外校正模块。
