## 摘要
现代大语言模型（LLM）服务系统越来越频繁地处理重复或共享的上下文，然而即使另一个模型已经处理过相同的输入，每个模型通常仍会执行自己的预填充计算。现有的KV缓存重用机制在单个模型内大幅减少了冗余计算，但通常假设缓存的产生者和消费者是同一个模型。我们研究跨模型KV共享，将源模型产生的KV状态转换为可由不同目标模型消费的表示，包括在规模、架构、注意力配置、分词器以及模型家族等方面存在差异的模型。我们在家族内和跨家族两种设置下评估该方法。对于Qwen2.5-7B→Qwen2.5-1.5B，转换后的KV状态将LongBench2准确率从27.59%提升至34.48%，相比原生1.5B基线提升了6.89个百分点，同时降低了相对原生目标预填充的交接成本。对于跨家族的Qwen2.5-1.5B→Gemma-2-2B设置，在4K上下文长度下，KV交接可将目标侧预填充成本降低高达67.05%，同时保持接近原生模型基线的解码困惑度。在更异构的Llama3.1-70B→Qwen2.5-7B设置中，跨家族交接实现了44.0%的准确率，而原生Qwen2.5-7B推理为45.7%，同时将测得的延迟从899毫秒降至138毫秒。这些结果初步表明，KV状态可以充当可迁移的计算表示，而非严格局限于模型的缓存，并促使上下文移动性成为一种系统抽象，用于在异构LLM和多智能体推理工作流中减少冗余预填充。

## Abstract
Modern large language model (LLM) serving systems increasingly operate over repeated or shared context, yet each model typically performs its own prefill computation even when another model has already processed the same input. Existing KV-cache reuse mechanisms substantially reduce redundant computation within a single model, but generally assume that the producer and consumer of a cache are identical. We study \emph{cross-model KV sharing}, which translates the KV state produced by a source model into a representation that can be consumed by a different target model, including models that differ in scale, architecture, attention configuration, tokenizer, and model family. We evaluate the approach in both within-family and cross-family settings. For Qwen2.5-7B $\rightarrow$ Qwen2.5-1.5B, translated KV states improve LongBench2 accuracy from 27.59\% to 34.48\%, a gain of 6.89 percentage points over the native 1.5B baseline, while reducing handoff cost relative to native target prefill. For the cross-family Qwen2.5-1.5B $\rightarrow$ Gemma-2-2B setting, KV handoff reduces target-side prefill cost by up to 67.05\% at 4K context length while maintaining decoding perplexity close to native-model baselines. In a more heterogeneous Llama3.1-70B $\rightarrow$ Qwen2.5-7B setting, cross-family handoff achieves 44.0\% accuracy compared with 45.7\% for native Qwen2.5-7B inference, while reducing measured latency from 899ms to 138ms. These results provide initial evidence that KV states can serve as transferable computational representations rather than strictly model-local caches, and motivate \emph{context mobility} as a systems abstraction for reducing redundant prefill across heterogeneous LLM and multi-agent inference workflows.

## 一、论文的核心问题与整体含义

### 研究动机与背景

- 现代 LLM 推理正演变为一个**多模型协作的系统问题**：同一应用往往组合多个模型，例如模型路由与级联（将简单请求分配给小模型、困难请求升级到大模型）、多智能体系统、检索增强生成等工作流。
- 不同模型经常处理**相同或高度重叠的上下文**（如对话历史、用户提示、检索文档），但现有推理基础设施存在一个关键缺陷：**每个模型被调用时都独立执行完整的 prefill 计算**，即使其他模型已经处理过完全相同的输入。
- 由于 KV 缓存被传统上视为**严格绑定于单个模型的运行时产物**，现有 KV 缓存复用机制（如前缀缓存）只能在同一模型内部生效，无法在不同模型之间共享已经算好的上下文表征。

### 核心问题的本质

> 当多个模型操作于相同上下文时，每个模型各自重复"理解"该上下文的计算工作是否必要？

本文的核心观点是：**这个重复是不必要的**。作者提出"跨模型 KV 共享"（Cross-Model KV Sharing）的概念——将源模型产生的 KV 状态翻译为另一种目标模型可直接消费的表示，使得异构模型之间可以共享上下文计算成果，避免重复的 prefill 开销。

### 整体系统性含义

该工作推动了一种新视角：KV 状态不应仅被视为**模型本地的临时执行产物**，而应被视为**可存储、可迁移、可翻译、可跨模型消费的计算资产**。由此引入"上下文移动性"（Context Mobility）这一系统抽象，为异构 LLM 与多智能体推理工作流的冗余 prefill 消除奠定了基础。

## 二、提出的方法论

### 核心思想

- 为跨模型场景引入一个**通用上下文复用层（Universal Context-Reuse Layer）**，其核心是一个"翻译模块"（transport/translation module）。
- 源模型 A 对共享上下文 C 执行 prefill 得到原生 KV 状态 KV_A(C)；翻译模块将其映射为目标模型 B 可消费的表示，形式化为：

\[
\widehat{KV}_B(C) = T_{A \to B} \left( KV_A(C) \right)
\]

其中 \( T_{A \to B} \) 表示从模型 A 表示空间到模型 B 表示空间的变换。

### 关键设计理念

1. **并非追求精确复现**：翻译不需要做到 \(\widehat{KV}_B(C) = KV_B(C)\)（目标模型原生 KV），只需携带足够上下文信息，使目标模型能以可接受的输出质量继续解码。
2. **可学习的目标函数**：训练目标是缩小翻译状态与原生 KV 状态之间的表示距离：
   \[
   L_{KV} = D\left( T_\theta(KV_A(C)), \; KV_B(C) \right)
   \]
   但作者指出，最小化原始 KV 距离并非唯一目标——也可能直接优化后续输出、注意力行为、logits 或任务准确率。
3. **覆盖异构差异**：翻译需适配源/目标模型在规模、注意力层数、隐层维度、注意力配置、tokenizer、架构家族上的差异。
4. **可降级回退**：当翻译表示无法满足质量或效率需求时，系统可回退至常规原生 prefill；跨模型复用的收益条件为：
   \[
   C_{\text{trans}} + C_{\text{overhead}} < C_{\text{prefill}}
   \]
5. **翻译粒度灵活**：可跨单个层、层组、KV 头、共享中间表示、压缩 KV 表示或低维潜在适配器进行操作，从而在保真度、运行时开销、内存占用和可扩展性之间取得平衡。

### 推理流程

- 源模型 prefill 产生原生 KV 缓存 → 学习好的翻译模块将缓存映射到目标模型 KV 空间 → **冻结的目标模型直接基于翻译状态解码**，无需自行 re-prefill 完整输入。

## 六、主要结论与发现

1. **家族内 KV 翻译有效**：Qwen2.5-7B → Qwen2.5-1.5B 将目标模型 LongBench2 准确率从 27.59% 提升至 34.48%（+6.89 个百分点），恢复 1.5B 与 7B 之间 38.1% 的准确率差距；且该增益完全来自翻译 KV 携带的信息（目标模型权重保持不变）。
2. **长上下文下仍有信息保持、但精度递归**：8K–16K 下准确率 40.74%，16K–32K 降至 32.58%（下降 8.16 个百分点），说明长上下文对齐仍是挑战。
3. **家族内 handoff 效率优势显著**：相对 1.5B prefill 减少 4.6×–5.4× 增量延迟；相对 7B prefill 减少 14.5×–16.7×。
4. **跨家族分享可行且保持质量**：Qwen2.5-1.5B → Gemma-2-2B 在 4K 上下文下减少 67.04% 目标侧延迟；解码困惑度与原生基线接近，H=1 时甚至取得最优值（14.086）。
5. **极大跨家族差距下依然有效**：Llama3.1-70B → Qwen2.5-7B 保持 44.0% 准确率（为原生 Qwen2.5-7B 45.7% 的 96.3%），同时延迟从 899ms 降至 138ms（6.5× 加速），相对 Llama3.1-70B 自推理则加速 53.1×。
6. **总体立论**：KV 状态可被视为**可迁移的计算表示**而非纯模型私有缓存，上下文移动性可作为异构 LLM 推理的系统抽象。

- **训练数据依赖**：翻译模块需要"源 KV + 目标 KV"配对的训练数据，这对新模型组合的实际部署构成额外数据收集负担。
- **准确率上限受限于小模型容量**：家族内实验显示 7B→1.5B 确实提升准确率，但因为目标参数量有限，始终无法达到大模型的完全能力——适用范围需更明确界定。
- **困惑度结果存在非单调现象**：Qwen→Gemma 的 H=16 与 H=512 处困惑度高于原生基线，说明翻译状态与后续解码步之间的交互存在未完全理解的不稳定因素。
