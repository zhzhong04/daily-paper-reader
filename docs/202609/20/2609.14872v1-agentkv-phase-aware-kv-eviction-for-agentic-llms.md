## 摘要
智能体式服务消耗的 token 可比聊天机器人工作负载高出数个数量级，给 KV 缓存容量和解码时带宽带来压力。大多数 KV 驱逐方法使用从最近 token 中抽取的代表性查询来为缓存键打分，假设未来注意力与近期注意力相似。我们表明，智能体式生成违背了这一假设：未来查询混合了 think、act、tool 和其他阶段，且主角度分析表明这些成分占据可测量的不同查询子空间，因此近期代表性查询会系统性地低估即将到来的阶段所需的键。我们提出 AGENTKV，它为每个阶段维护一个小型查询缓冲区，并基于这些缓冲区的并集为缓存键打分。我们进一步在持久化多轮服务路径中实现 AGENTKV，该路径跨轮次携带压缩的 KV 状态，并在线紧凑化保留的 KV 页。在两个模型、六个任务领域以及每个模型三种 KV 预算下，AGENTKV 相比 R-KV 平均提升任务得分 5.5 分，相比 Tri-attention 提升 5.3 分。相对于上游 full-KV SGLang，AGENTKV 将输出 token 吞吐量最多提升 1.80 倍。代码：https://github.com/LiuTaowen-Tony/agentkv。

## Abstract
Agentic serving can consume orders of magnitude more tokens than chatbot workloads, stressing both KV-cache capacity and decode-time bandwidth. Most KV-eviction methods score cached keys against representative queries drawn from the most recent tokens, assuming future attention resembles recent attention. We show that agentic generation violates this assumption: future queries form a mixture over think, act, tool, and others phases, and principal-angle analysis shows these components occupy measurably different query subspaces, so recency representatives systematically undervalue keys that upcoming phases will need. We propose AGENTKV, which maintains a small query buffer per phase and scores cached keys against their union. We further implement AGENTKV in a persistent multi-turn serving path that carries compressed KV state across turns and compacts retained KV pages online. Across two models, six task domains, and three KV budgets each, AGENTKV improves task score by 5.5 points on average over R-KV and 5.3 over Tri-attention. Relative to upstream full-KV SGLang, AGENTKV improves output-token throughput by up to 1.80x. Code: https://github.com/LiuTaowen-Tony/agentkv.

# AgentKV：面向智能体式 LLM 的阶段感知 KV 驱逐 — 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：智能体式（agentic）服务消耗的 token 可比传统单轮聊天负载高出数个数量级，序列长度与 KV 缓存压力剧增，KV 缓存**容量**与**解码时内存带宽**成为服务吞吐和延迟的主要瓶颈。
- **现有做法**：主流 KV 驱逐/压缩方法（H2O、StreamingLLM、SnapKV、R-KV 等）可统一为"查询中心"框架——用一小批**代表性查询**（通常取自最近的 token 窗口）估计缓存键的未来重要性，隐含假设"**未来注意力 ≈ 近期注意力**"。
- **核心问题**：智能体轨迹并非平稳分布。它由反复出现的语义阶段构成——`think`（推理）、`act`（工具调用参数）、`tool`（工具返回观察）、`others`（系统提示、工具描述、用户问题）。未来查询是这四个阶段的**混合分布**，而近期窗口只反映当前阶段。
- **关键发现**：作者用**主角度分析**证明不同阶段的查询占据可测量的不同子空间；用**效用覆盖率**诊断证明基于近期的代表性查询会系统性低估后续阶段（尤其 `tool`）所需的键，造成"**阶段诱导的估计器偏差**"。
- **整体含义**：这是首个显式建模智能体阶段混合查询分布的 KV 驱逐方法，并将策略与持久多轮服务路径结合，把"逻辑驱逐"转化为真实的显存/带宽收益与更高并发。

## 2. 方法论

### 2.1 核心思想
- 将未来查询分布 `p(q)` 建模为**阶段条件查询分布的混合**，用估计器 `p̂(q)` 替代"最近若干查询"的经验分布 `p_recent(q)`。
- 为每个阶段维护一个小型查询缓冲区，压缩事件时用**各阶段代表查询的并集**为所有候选键统一打分，保留 top-B。
- 打分方式与其他查询中心方法兼容（不按阶段划分键，也不设每阶段键配额）。

### 2.2 关键技术细节
- **阶段解析器（Algorithm 1）**：基于 tokenizer 可见的 chat-template 标记做确定性解析，使用滚动前缀以识别被拆分的标记；标记表如 `<|im_start|>system`/`<|im_start|>user` → `others`、`<think>` → `think`、`<tool_call>` → `act`、`<tool_response>` → `tool`。**无需模型侧分类器，也不引入新特殊 token**。
- **每阶段 FIFO 查询缓冲**：每阶段容量 `⌈q/4⌉`，总预算 `q=32`（即每阶段 8 个）；压缩事件 `e` 处形成 `Q(e) = Q_think ∪ Q_act ∪ Q_tool ∪ Q_others`，且 `|Q(e)| ≤ q`，与近期基线代表预算对齐。
- **重要性打分公式**：
  - `A_i^(e) = (1/|Q(e)|) · Σ_{q∈Q(e)} softmax(qᵀK^(e)/√d_h)_i`，softmax 沿键轴归一化，即每个代表查询在候选键上形成一个概率分布，取其平均注意力质量。
  - 保留 `A_i` 最高的 B 个候选，其余驱逐。
- **在线驱逐流程（Algorithm 2）**：每解码 `Δ=128` 个 token 触发一次；先更新阶段与缓冲，再收集代表查询与页表中的键，计算分数，将受保护位置（流式 attention sink，`ws=32`）置为 `-inf`，再对剩余预算取 top-k，最后执行压缩与页复用。
- **持久化服务路径（Algorithm 3）**：在 CUDA graph 重放之间做**物理 KV 紧凑化**——分配新槽位、用融合 gather–write 核把保留位置搬入、重定向请求页表、立即释放旧槽位给分配器；并**分离物理长度与单调递增的逻辑长度**以保持 RoPE 偏移和后续前缀扩展正确，同时兼容 chunked prefill 与常规解码路径。
- **阶段内采样规则**：主实验采用 `Staged-last`（各阶段压缩事件前最后 6 个位置）；消融显示多种可部署采样规则效用覆盖相近。

### 2.3 诊断性分析工具
- **主角度分析**：对每个阶段跨度 `s` 的查询矩阵做薄 SVD，取前 `k=5` 个右奇异向量构成正交基 `V_{s,k}`；用 `cos θ_i = σ_i(V_{s,k}ᵀV_{t,k})` 计算主角度，比较**跨阶段**（如 `think` vs `tool`）与**同阶段不同步**（如 `think₁` vs `think₂`）的对齐程度。
- **效用覆盖率**：`U_i = Σ_{j>i_comp} a_{j,i}`（离线 oracle，仅作诊断），`UC_φ = Σ_{i∈R_φ} U_i / Σ_{i∈K_φ} U_i`，衡量保留集覆盖某阶段未来注意力质量的比例。

## 6. 主要结论与发现

- **阶段结构真实存在**：跨阶段主角度显著大于同阶段不同步的主角度（图 3/4/8），说明各阶段查询占据可区分的主导子空间。
- **近期代表存在系统性偏差**：`tool` 阶段效用覆盖率在 B=512 时仅 0.042，多阶段代表提升至 0.175；B=1536 时由 0.117 提升至 0.416。
- **任务质量**：平均比 R-KV 高 **5.5 分**、比 Tri-attention 高 **5.3 分**；最大且一致的增益出现在 `multi_turn` 与 τ² 的 `retail`、Qwen3-32B `telecom` 等需要跨阶段保留状态的任务。
- **机制验证**：匹配近期查询消融平均 **+4.2 分**（12 设置）；剔除任一阶段都会掉分（drop others 掉最多，35.5 vs 40.0），说明四阶段互补；`q=32` 后继续增大代表预算不再稳定提升。
- **鲁棒性**：30% 阶段标签损坏仍优于匹配 R-KV（33.5 vs 27.0），退化是渐进的；四阶段划分在固定预算下优于更粗或更细的划分；跨家族 Nemotron 在较大两档预算上 +4.5 / +4.0（最小预算受容量限制 −1.0）。
- **吞吐**：相对上游 full-KV SGLang，输出 token 吞吐最高提升 **1.80×**（H100 NVL，Qwen3-32B，32k/1k），16k/1k 时 1.64×；RTX A6000 上 Qwen3-8B 为 1.37×/1.76×。统一服务路径下 AgentKV 在全部四个硬件/上下文场景中吞吐最高（1.10×–1.87× 于 full-KV SGLang）。
- **质量–吞吐权衡**：在固定模型/硬件/负载/批大小下，AgentKV 曲线在 6 组匹配设置中均处于"右上角"（质量与吞吐同时最高）。

## 7. 优点

- **问题识别有据可依**：不是直接提方法，而是先用主角度几何分析与效用覆盖率诊断量化"近期偏差"，把动机从直觉提升为可测量的现象。

- **实验对照设计严谨**：匹配近期基线实现单变量隔离；统一服务路径对比分离策略与工程贡献；配对 bootstrap + 3 次重复解码控制噪声；跨家族迁移检验泛化。
- **报告诚实**：明确区分"CI 支持"与"统计未解析"，不夸大未达显著的比较；专门设有失败区间（F.2）与局限讨论。
- **可复现**：代码开源，超参与基线配置（含 R-KV、Tri-attention 细节）完整列出。

## 8. 不足与局限

- **预算需人工指定**：KV 预算不能按任务级质量或延迟目标自动选择，需在小验证集上人工调参。
- **仅适用于中等压缩率**：预算过小时容量成为主导因素（如 τ² retail 平均 16.9k token，B=2048 约 8× 压缩下 AgentKV/R-KV/Tri 分别仅 8.8/6.1/7.9，而 Full KV 为 53.5）；压缩压力过弱时策略趋近 full-cache，执行方差主导差异。文中给出的是"工作负载特定"的操作点而非通用阈值。
- **外置状态任务收益有限**：`memory`（外部 KV/向量存储/递归摘要）与 τ² `airline`（工具响应已暴露当前环境状态）上，策略差异常统计未解析，甚至不如 sink+recency 的 StreamingLLM。
- **重复/退化推理轨迹问题**：阶段缓冲可能保留近重复上下文，需额外引入冗余惩罚（Nemotron 实验即叠加了 R-KV 的冗余项）；Qwen3-8B telecom B=4096 上 R-KV 点估计更高（18.4 vs 14.0，区间未解析）。
- **统计显著性有限**：36 次比较中约 20 次区间含零，部分结论依赖点估计而非显著差异。

- **解析器依赖 chat template**：阶段分配依赖标记可见性；对不暴露显式阶段标记、或阶段边界与模板强耦合的模型/框架，需要重写标记表并重新验证。跨家族迁移虽在 Nemotron 上验证了可行性，但解析器适配仍需人工介入，尚未实现自动模板推断。
- **工程侵入性较高**：持久服务路径涉及分配器、页表、CUDA graph 重放与 chunked prefill 的协同改造，并非纯算法层可插拔组件；实际部署需要推理引擎侧的深度集成与回归测试。
- **阶段划分的语义假设较强**：四阶段分类面向工具调用型 agent 设计，对纯长链推理（无工具）、多模态 agent、或阶段边界模糊/交叠的任务未必最优；文中粒度消融也仅覆盖了该设计空间内的粗化与细分。
- **诊断信号不可直接在线使用**：效用覆盖率依赖离线 oracle 的未来注意力，主角度分析需要事后按阶段切片；两者用于解释现象，不能直接转化为在线驱逐信号。
- **未与正交压缩维度组合**：未评估与 KV 量化、低秩压缩、前缀共享等方法的叠加效应，也未讨论在多租户、异构负载下的表现。
- **长轨迹下的缓冲管理开销未细化**：每阶段 FIFO 缓冲在超长轨迹、阶段频繁切换时的内存与更新成本，文中未给出细粒度 profiling。
- **评估家族覆盖有限**：主实验集中在 Qwen3 系列，跨家族仅一个 Nemotron 模型，结论向更多架构（如 MoE、非标准 RoPE 变体）的外推需谨慎。

## 9. 总体评价与启示

- **定位**：AgentKV 是一篇“诊断驱动”的系统论文——先用几何与效用工具把“近期注意力假设在 agentic 负载下失效”从直觉变成可测量事实，再给出一个极简、低开销、可部署的修正方案。
- **核心贡献**：将 KV 驱逐的查询分布从“近期经验分布”推广到“阶段条件混合分布”，并把策略改动与持久多轮服务路径打通，使逻辑上的驱逐转化为真实的显存、带宽与吞吐收益。
- **方法价值**：阶段解析器不引入模型侧分类器或新特殊 token，代表查询预算与基线对齐，保证了与现有查询中心方法的可比性与兼容性。
- **实证价值**：匹配近期基线、统一服务路径、配对 bootstrap 与重复解码的组合，在同类工作中属于较严谨的对照设计；对统计未解析结果的如实报告也提升了可信度。
- **适用边界**：该方法在中高压缩压力、跨阶段状态需要保留的工具调用型多轮任务上收益最明确；在压缩压力过低或状态已外置的场景中，收益可能被容量与执行方差淹没。
- **启示**：对 agentic 服务的 KV 管理而言，“未来查询是什么分布”比“保留多少 token”更关键；显式建模工作负载的阶段结构，可能比单纯改进打分函数或压缩率带来更稳定的收益。后续工作可探索阶段划分的自适应发现、与正交压缩技术的组合，以及面向任务级质量/延迟目标的预算自动选择。
