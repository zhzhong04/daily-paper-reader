## 摘要
最近的多智能体LLM系统越来越多地结合异构模型以承担专门的智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。重用发送方的键值（KV）缓存可以避免这种冗余，但跨模型族的无预填充传输必须处理分词、模型深度和KV表示方面的差异。为了解决这些问题，我们提出了 HeteroFold，一种无预填充的跨模型族KV缓存传输方法，该方法保持发送方和接收方均冻结。HeteroFold 对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold 在所有四个长上下文基准和大多数短上下文设置上取得了最佳的缓存传输性能。它还在多智能体基准上匹配了基于文本的通信。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B 传输比 Native Prefill 快 10.7×，比最先进的无预填充基线 Dense Latent 和 KV Ridge 快 1.18–1.47×。这些结果表明，HeteroFold 能够实现高效的跨模型族KV重用，而无需接收方预填充。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

- **研究动机**：异构多智能体 LLM 系统常把不同家族/规模的模型分配给不同角色，但基于文本的通信会让接收方重新预填充发送方已经处理过的共享上下文，造成重复计算与延迟。
- **核心障碍**：跨模型族直接复用 KV 缓存面临三类不匹配：
  - 分词器不同导致 token 无法一一对应；
  - 模型深度、层语义不同；
  - KV 表示、头数、特征分布不同。
- **现有方法不足**：
  - 文本通信 TextMas 需要接收方 native prefill；
  - C2C 仍要求接收方先生成 prompt cache；
  - Recursive MAS 传递隐表示但仍需接收方逐层处理；
  - Dense Latent、KV Ridge 等无预填充方法主要在同家族或兼容分词器设定下评估。
- **整体含义**：论文提出 HeteroFold，目标是在发送方和接收方均冻结的前提下，实现**跨模型族、接收方无需预填充**的 KV 缓存迁移，使异构多智能体之间可以直接复用 KV 计算。

## 2. 方法论：核心思想与关键技术

- **核心思想**：把发送方 KV 缓存经“token/层对齐 → KV 映射 → 接收方行为校准”后，转换成接收方可直接解码使用的 KV 状态；校准后的低秩修正折叠进固定仿射映射，不引入额外推理模块。
- **Token Alignment, TA**：
  - 通过共享字符结束边界建立发送方 token 与接收方 token 的对应关系。
  - 对未匹配的接收方边界，使用最近的前序共享边界对应的发送方状态；首个匹配前使用首个发送方 token。
  - 多对一情况下不平均发送方状态，而是取匹配字符边界处的发送方 token。
  - 映射后接收方仍使用自己的位置索引和 RoPE。
- **Layer Alignment, LA**：
  - 按相对深度对齐层：  
    \(\pi(\ell)=1+\text{round}((\ell-1)(L_S-1)/(L_R-1))\)。
  - 对每个接收方层，取发送方匹配层附近的偏移层集合 \(N(\ell)=\{\pi(\ell)-4,\pi(\ell),\pi(\ell)+4\}\)，并裁剪到有效层范围。
  - 将三层发送方 K/V 特征拼接，作为映射输入，以处理不同深度和信息分布。
- **KV 映射：Recolor**：
  - 对每层、K/V 分别收集对齐 token 对，构造发送方输入 \(X\) 和接收方目标 \(Y\)。
  - 先计算全局 RMS 缩放 \(r\)，令 \(Z=X/r\)。
  - 通过白化 + Procrustes 对齐 + 恢复接收方协方差/均值，得到仿射映射：
    - \(A=\Sigma_Z^{-1/2}R^\star\Sigma_Y^{1/2}\)
    - \(b=\mu_Y-\mu_Z A\)
    - \(y^{(0)}=(x/r)A+b\)
  - 每层、每个角色 K/V 各一个映射；跨头展平，允许发送方与接收方头数不同。
- **Output-aware Calibration**：
  - 在 Recolor 输出上加入低秩修正：  
    \(\hat y = y^{(0)}+(y^{(0)}B)G\)，其中 \(B\in\mathbb{R}^{d_R\times\rho_c}\)，\(G\in\mathbb{R}^{\rho_c\times d_R}\)，默认 \(\rho_c=16\)。
  - 只训练 \(B,G\)，映射和两个模型保持冻结，\(G\) 初始化为 0。
  - 将输出差分解为 key-induced 与 value-induced 两部分，分别设计损失：
    - Key 目标：匹配 native 注意力模式，并约束 key 修正经输出投影后的影响，使用 KL 与归一化平方误差。
    - Value 目标：固定映射后的注意力权重，优化 value 使最终输出接近 native 输出。
  - 校准仅使用接收方 native queries、attention、values、outputs，且限定在问题 span 的 query 位置，不使用 gold answer 或生成续
