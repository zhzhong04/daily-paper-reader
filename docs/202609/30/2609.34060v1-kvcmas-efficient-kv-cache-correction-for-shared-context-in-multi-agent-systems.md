## 摘要
提示词特化的多智能体系统使多个智能体能够共享一个模型，同时扮演互补角色以解决复杂任务。然而，智能体特定的前缀会改变为同一共享上下文生成的 KV 缓存，导致每个智能体都要重复预填充不断增长的上下文，并构建单独的缓存，从而带来高昂的计算和内存开销。选择性重计算减少了这种冗余，但仍保留了大量的模型执行；而现有的增量校正方法要么仅支持重复出现的上下文关系，要么需要为动态变化的上下文维护内存密集型的在线校正状态。对于首次出现的共享上下文，这些方法还会在智能体工作流之外构建参考缓存，并且首个智能体处的近似校正会影响传递给后续智能体的输出。我们提出 KVCMAS，一种在线 KV 缓存校正框架，它使用紧凑的低秩状态表示跨智能体的缓存偏差，并沿智能体工作流无缝串联校正，而无需额外的参考预填充。该设计支持动态变化的共享上下文，同时保持精确的首个智能体缓存。在多种语言和视觉-语言工作负载中，KVCMAS 在达到或提升先前 KV 缓存共享方法精度的同时，在高并发服务下实现了最低的 TTFT。在受控服务轨迹下，相较于不进行 KV 缓存共享的推理，它提供了 2.0 倍的 TTFT 加速，并且相对于先前的 KV 缓存校正方法，将峰值 GPU 内存最多降低至其 1/3.7。这些结果确立了 KVCMAS 是一种面向提示词特化多智能体服务的准确且可扩展的 KV 缓存共享方法。

## Abstract
Prompt-specialized multi-agent systems enable multiple agents to share a model while performing complementary roles to solve complex tasks. However, agent-specific prefixes change the KV cache generated for the same shared context, causing each agent to repeatedly prefill the growing context and construct a separate cache with high computation and memory overhead. Selective recomputation reduces this redundancy but still retains substantial model execution, while existing delta correction methods either support only recurring context relations or maintain memory-intensive online correction states for dynamically changing context. For first seen shared context, these methods also construct a reference cache outside the agent workflow, and an approximate correction at the first agent affects the outputs passed to subsequent agents. We present KVCMAS, an online KV cache correction framework that represents cross-agent cache deviations using compact low-rank states and seamlessly chains corrections along the agent workflow without an additional reference prefill. This design supports dynamically changing shared context while preserving an exact first-agent cache. Across multiple language and vision-language workloads, KVCMAS matches or improves the accuracy of prior KV cache sharing methods while achieving the lowest TTFT under highly concurrent serving. Under controlled serving traces, it provides a 2.0x TTFT speedup over inference without KV cache sharing and reduces peak GPU memory by up to 3.7x relative to a prior KV cache correction method. These results establish KVCMAS as an accurate and scalable KV cache sharing approach for prompt-specialized multi-agent serving.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：基于 LLM 的多智能体系统（MAS）通过规划、工具调用、批评、编排等互补角色提升复杂任务表现。其中"共享模型权重 + 不同角色提示词"（prompt-specialized）是最实用的服务形态，无需额外训练即可扩展新角色。
- **核心矛盾**：智能体轨迹由**智能体特定前缀段（PF，如 system prompt、glue prompt）**与**共享上下文段（PH，如用户查询、工具观测、其他智能体输出）**交替组成。PH 内容在不同智能体间相同，但由于其前置上下文（PF）不同，同一 PH 段在各智能体上生成的 KV cache 并不相同（Ci,seg ≠ Cj,seg），因此无法直接复用。
- **后果**：每个智能体都要重复 prefill 不断增长的共享上下文，并各自保留一份 KV cache，造成严重的计算与显存开销；直接复用他人 cache（FullShared）则精度大幅下降。
- **现有方法的不足**：
  - **选择性重计算**（DroidSpeak 按层、CacheBlend 按 token、RelayCaching 按 token+注意力）：只重建选定子集，子集之外的偏差仍被保留；要提升精度就需扩大重计算范围，精度—效率权衡受限（附录 A.1 显示至少一半复用误差无法被覆盖）。
  - **增量校正（delta correction）**：GraphFlow、Kamera 只针对**重复出现的上下文关系**构建校正，无法应对动态变化的新请求/新输出；KVComm 用在线 anchor pool 支持动态上下文，但以**全维**形式存储 base cache 与各智能体校正，内存随共享上下文长度、anchor 数、智能体数增长。
  - **非链式参考的额外开销**：现有方法相对"无上下文/位置无关的参考缓存"构建校正；对首次出现的共享上下文，这需要在真实工作流之外**额外做一次 prefill**；且首个智能体的近似校正误差会作为共享上下文传播给下游，放大整体误差。
- **整体含义**：论文提出 KVCMAS，一个面向动态共享上下文的**在线 KV 缓存校正框架**，目标是同时实现高精度、低 TTFT、低显存的可扩展多智能体服务。

## 二、方法论

### 2.1 两个核心观察

- **观察一（低秩性）**：跨智能体的 delta 校正在多个工作负载上层间**有效秩低于 32**（有效秩定义为保留 90% 奇异值能量所需的最小秩），远低于 KV 特征维度 D；base cache 也呈类似结构，但有效秩略高。因此在线校正状态可用低秩表示，而**实际参与注意力的 KV cache 仍保持全维**。
- **观察二（链式校正更优）**：用源智能体已产出的 cache 作参考（chained）比用无上下文参考（non-chained）**聚合校正误差更低**（图 3 在层维度与按执行顺序 A0→A1→A2→A3 的智能体维度上均验证）。

### 2.2 关键技术细节

- **低秩 anchor pool（对应式 7、8）**：
  - 对每个 key/value 矩阵 Z ∈ R^{L×D} 做截断 SVD：`Z ≈ U_{Z,r} Σ_{Z,r} R_{Z,r}^T = A_Z B_Z`，其中 `A_Z ∈ R^{L×r}`、`B_Z ∈ R^{r×D}`。
  - 每个 anchor v 存储其 base cache 与各消费智能体校正的低秩因子；估计校正时按相似度权重 wv 加权组合：`Δ̂_{j←i,seg} = Σ_v w_v A_{Δ,v} B_{Δ,v}`，Σ w_v = 1。
  - 内存由 `O(V·N·L·D)` 降为 `O(V·N·r·(L+D))`。示例：Llama-3.1-8B BF16、4K token 段、V=20、N=4 时，全维 anchor 状态约需 50 GiB。
- **链式校正（对应式 6）**：
  - 精确关系为 `Δ_{j←i} = C_j − C_i = Δ_{j←ref} − Δ_{i←ref}`；理论上与无上下文参考等价，但**经验校正的近似误差不同**。
  - KVCMAS **对首个智能体做密集 prefill 得到精确 cache**，之后每条工作流边都以上一条边物化出的共享 cache 为参考，无需回到 context-free reference，也无需额外 prefill；避免了首个智能体近似误差向下游传播。
- **在线 anchor 匹配与可靠性门控（对应式 9–11）**：
  - 对比较前缀长度 k，计算源 cache 与各 anchor 重建 value 状态的层间 Frobenius 距离 `d_v`，经温度 T=1 的 softmax 得门控权重 g_v，再算归一化熵 `H(g)`。
  - 熵低（分布尖锐）表示匹配明确，接受校正；熵高（分布平坦）则触发密集 prefill。接受条件为 `H(g) ≤ τ`，τ 越大复用率 ρ 越高；兼容 anchor 少于 2 个也走 dense prefill。
- **位置对齐与变长处理**：key 在比较前统一到同一规范位置坐标（消除 RoPE 带来的确定性差异），校正后 key 再对齐到目标位置，value 无需旋转；anchor 不做 padding，若没有 anchor 覆盖完整长度，则只校正最长可覆盖前缀，剩余行沿用位置对齐后的源 cache，避免外推。
- **缓存物化与池更新（对应式 12）**：接受的校正物化为全维目标 cache，并成为下一条边的源 cache；每条边独立做可靠性判断。密集回退后计算 `Δ_{j←i} = C_j − Align(C_i)`，对源 cache 与观测校正做秩 r 分解并插入为新 anchor；被接受的校正不重新插入，池满时在 5 个最旧条目中按 LFU 淘汰。
