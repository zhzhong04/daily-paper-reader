## 摘要
提示特化的多智能体系统使多个智能体能够共享一个模型，同时扮演互补角色以解决复杂任务。然而，各智能体特定的前缀会改变为同一共享上下文生成的 KV 缓存，导致每个智能体重复预填充不断增长的上下文，并构建独立缓存，从而带来高计算和内存开销。选择性重计算减少了这种冗余，但仍保留大量模型执行；而现有差分校正方法要么仅支持重复出现的上下文关系，要么为动态变化的上下文维护内存密集的在线校正状态。对于首次出现的共享上下文，这些方法还会在智能体工作流之外构建参考缓存，并且首个智能体处的近似校正会影响传递给后续智能体的输出。我们提出 KVCMAS，一种在线 KV 缓存校正框架，它使用紧凑的低秩状态表示跨智能体缓存偏差，并沿智能体工作流无缝串联校正，无需额外的参考预填充。该设计支持动态变化的共享上下文，同时保持首个智能体缓存的精确性。在多种语言和视觉-语言工作负载上，KVCMAS 匹配或提升了先前 KV 缓存共享方法的准确率，同时在高并发服务下实现最低的 TTFT。在受控服务轨迹下，相较于未使用 KV 缓存共享的推理，它提供 2.0 倍的 TTFT 加速，并且相对于先前的 KV 缓存校正方法，将峰值 GPU 内存最多降低 3.7 倍。这些结果确立了 KVCMAS 是一种准确且可扩展的 KV 缓存共享方法，适用于提示特化的多智能体服务。

## Abstract
Prompt-specialized multi-agent systems enable multiple agents to share a model while performing complementary roles to solve complex tasks. However, agent-specific prefixes change the KV cache generated for the same shared context, causing each agent to repeatedly prefill the growing context and construct a separate cache with high computation and memory overhead. Selective recomputation reduces this redundancy but still retains substantial model execution, while existing delta correction methods either support only recurring context relations or maintain memory-intensive online correction states for dynamically changing context. For first seen shared context, these methods also construct a reference cache outside the agent workflow, and an approximate correction at the first agent affects the outputs passed to subsequent agents. We present KVCMAS, an online KV cache correction framework that represents cross-agent cache deviations using compact low-rank states and seamlessly chains corrections along the agent workflow without an additional reference prefill. This design supports dynamically changing shared context while preserving an exact first-agent cache. Across multiple language and vision-language workloads, KVCMAS matches or improves the accuracy of prior KV cache sharing methods while achieving the lowest TTFT under highly concurrent serving. Under controlled serving traces, it provides a 2.0x TTFT speedup over inference without KV cache sharing and reduces peak GPU memory by up to 3.7x relative to a prior KV cache correction method. These results establish KVCMAS as an accurate and scalable KV cache sharing approach for prompt-specialized multi-agent serving.

# KVCMAS 论文结构化总结

## 1. 核心问题与研究背景

- **背景**：基于提示特化（prompt-specialized）的多智能体系统（MAS）让多个智能体共享同一模型权重，仅通过角色提示区分（如规划、工具调用、批评、编排），无需额外训练，部署上很实用。执行过程中，用户查询、检索信息、工具观测与智能体输出在智能体之间传播，形成"智能体专属前缀（PF）+ 共享上下文（PH）"交替的轨迹。
- **核心矛盾**：尽管智能体共享权重，但不同 PF 会改变同一 PH 段落的隐藏状态与 KV 缓存，即 `C_{i,seg} ≠ C_{j,seg}`。这导致每个智能体都要重复预填充不断增长的共享上下文，并各自保留一份独立缓存，带来高计算与显存开销。
- **现有方法的局限**：
  - **直接复用（FullShared）**：精度大幅下降（如 MMLU 从 67.54% 掉到 36.45%）。
  - **选择性重计算**（DroidSpeak、CacheBlend、RelayCaching）：按层/按 token 重建部分缓存，但未选中部分的偏差仍残留；要提升精度就得扩大重算范围，陷入"精度—算力"权衡（附录 A.1 显示至少一半复用误差无法被覆盖）。
  - **差分校正**（GraphFlow、Kamera）：只针对**重复出现的上下文关系**构造校正，对动态变化的新请求/新智能体输出失效。
  - **KVComm**：用在线锚点池支持动态上下文，但以**全维度**存储基缓存与校正，内存随共享上下文长度、锚点数、智能体数增长（32K 场景需约 435.6 GB，直接 OOM）。
  - **非链式校正的额外缺陷**：参考缓存需在真实工作流之外单独预填充；且首个智能体的近似校正误差会作为共享上下文传播到下游，放大累计误差。
- **整体含义**：论文提出 KVCMAS——面向动态共享上下文的**在线 KV 缓存校正框架**，目标是在保持高精度的同时，实现低 TTFT、低显存的跨智能体缓存共享，为提示特化多智能体服务提供可扩展方案。

## 2. 方法论

### 2.1 核心思想（两条）
1. **低秩在线校正**：跨智能体 KV 缓存偏差集中在低维特征空间，可用紧凑低秩状态存储在线校正，而注意力使用的活跃缓存仍保持全维度。
2. **沿工作流链式校正**：以工作流中已产生的**源智能体缓存**作为参考，而非独立构造的"无上下文参考缓存"；首智能体稠密预填充以保证精确，之后逐边串联校正。

### 2.2 关键技术细节

- **低秩锚点池**：
  - 对基缓存 `C^(v)` 与校正 `Δ^(v)` 做截断 SVD：`Z = U_Z Σ_Z R_Z^T ≈ U_{Z,r} Σ_{Z,r} R_{Z,r}^T = A_Z B_Z`，其中 `A_Z ∈ R^{L×r}`、`B_Z ∈ R^{r×D}`。
  - 内存由 `O(V N L D)` 降至 `O(V N r (L + D))`。观测到校正的有效秩普遍低于 32（图 2），默认 `r = 32`、每槽最多 `V = 10` 个锚点。
- **链式校正（Chained Correction）**：
  - 精确关系为 `Δ_{j←i,seg} = C_{j,seg} − C_{i,seg} = Δ_{j←ref,seg} − Δ_{i←ref,seg}`；理论等价，但经验误差不同。链式结构在层与智能体维度上都降低了累计重建误差（图 3）。
  - 首个智能体稠密预填充得到精确缓存；每条边只做一次可靠性判断；被接受的校正物化为全维目标缓存，并成为下一条边的参考，无需回到无上下文参考。
- **校正流程（算法要点）**：
  1. 智能体专属 PF 单独处理；首智能体稠密预填充。
  2. 对 i→j 的共享段：对源缓存做键位置对齐（RoPE 确定性差异消除）→ 与在线锚点匹配（源缓存已由工作流产生，**无需额外前向**）。
  3. 锚点权重按相似度归一化，估计校正 `Δ̂ = Σ_v w_v A_{Δ,v} B_{Δ,v}`，且 `Σ w_v = 1`。
  4. **可靠性门控**：用锚点匹配距离的归一化熵判断（公式 9–11），`H(g) ≤ τ` 才接受，否则稠密预填充（提高 τ 会提高复用率 ρ）。
  5. 键/值分别计算 token 级插值权重（softmax，T=1）；键在统一位置坐标下比较后对齐到目标位置，值无需旋转；逐层执行，不额外拷贝全缓存。
  6. **变长段**：锚点不填充；若没有覆盖整段的锚点，只校正最长可覆盖前缀，其余行保留位置对齐后的源缓存，避免外推。
  7. **池更新**：仅稠密回退产生的精确目标缓存才用于计算 `Δ = C_j − Align(C_i)` 并插入低秩因子；接受的校正不回插；池满时在 5 个最旧条目中按最不常用淘汰。

## 6. 主要结论与发现

- **精度**：KVCMAS 在 5 个 benchmark 中的 3 个取得 KV 缓存共享方法中的最高精度，其余两个（GSM8K、HumanEval）仅次于 KVComm 且差距 ≤ 0.7 个百分点；整体位于"精度—延迟"帕累托前沿左上方。
- **延迟/效率**：在所有负载上取得差分校正方法中最低的端到端延迟与 TTFT；除 GSM8K 外延迟也低于选择性重计算方法，且是在**更低复用率**下实现的。
- **并发服务**：32K 共享 token、8 QPS、ρ=0.8 时，相对 NonShared 取得 **2.0× p50 / 2.1× p90 TTFT 加速**，相对 GraphFlow（次快）降低 **27%** TTFT；优势随上下文变长、QPS 升高而扩大。
- **链式 vs 非链式**：链式校正精度更高（MMLU +6.44 点，Video-MME +1.53 点），32K/8 QPS 下 p50/p90 TTFT 均降低 **34%**（省去独立参考预填充）。
