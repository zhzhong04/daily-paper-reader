## 摘要
近期的多智能体LLM系统越来越多地组合异构模型以承担专门的智能体角色。然而，基于文本的通信要求每个接收方对发送方已处理过的共享上下文进行预填充。复用发送方的键值（KV）缓存可避免这种冗余，但跨模型家族的免预填充传输必须处理分词、模型深度和KV表示方面的差异。为解决这些问题，我们提出 HeteroFold，一种免预填充的跨家族KV缓存传输方法，使发送方和接收方均保持冻结。HeteroFold 对齐模型结构，将发送方缓存映射到接收方空间，并对其进行校准以保持接收方行为。在六个传输方向上，HeteroFold 在所有四个长上下文基准和大多数短上下文设置上均取得了最佳的缓存传输性能。它在多智能体基准上也与基于文本的通信相匹配。在32K上下文长度下，Llama-3.1-8B→Ministral-3-14B 的传输比 Native Prefill 快 10.7 倍，比最先进的免预填充基线 Dense Latent 和 KV Ridge 快 1.18–1.47 倍。这些结果表明，HeteroFold 能够在无需接收方预填充的情况下实现高效的跨家族KV复用。

## Abstract
Recent multi-agent LLM systems increasingly combine heterogeneous models for specialized agent roles. However, text-based communication requires each receiver to prefill shared context already processed by the sender. Reusing the sender's key-value (KV) cache avoids this redundancy, but prefill-free transfer across model families must handle differences in tokenization, model depth, and KV representations. To address these issues, we propose \textit{HeteroFold}, a prefill-free cross-family KV cache transfer method that keeps both the sender and receiver frozen. HeteroFold aligns model structures, maps the sender cache into the receiver space, and calibrates it to preserve receiver behavior. Across six transfer directions, HeteroFold achieves the best cache-transfer performance on all four long-context benchmarks and most short-context settings. It also matches text-based communication on the multi-agent benchmark. At 32K context length, Llama-3.1-8B$\rightarrow$Ministral-3-14B transfer is $10.7\times$ faster than Native Prefill and $1.18$--$1.47\times$ faster than the state-of-the-art prefill-free baselines, Dense Latent and KV Ridge. These results show that HeteroFold enables efficient cross-family KV reuse without receiver prefill.

  - **模型深度差异**：层数不同，接收方某层无法直接对应发送方某层；
  - **KV 表示差异**：头数、隐藏维度、特征分布不同。

- **与已有工作的区别**：
  - TextMas（标准文本通信）：需接收方预填充；
  - C2C：支持跨模型缓存通信，但需要接收方先生成的 prompt cache，未消除预填充；
  - Recursive MAS：跨异构模型传隐状态，但信息仍需接收方各层处理，非 decode-ready 缓存；

## 2. 方法论：HeteroFold 的核心思想与关键技术

### 2.1 总体框架
设冻结的发送方 $\mathcal{S}$（$L_S$ 层）与接收方 $\mathcal{R}$（$L_R$ 层）。给定上下文 $x$，将发送方缓存 $C_S(x)$ 映射为接收方可直接解码的缓存 $\hat{C}_R(x)$，无需接收方预填充。三大组件：**Token 与 Layer 对齐 → Recolor KV 映射 → 输出感知校准**。映射在 **key 归一化与 RoPE 之前**、**value 投影之后**进行，接收方随后施加自己的原生 key 归一化与 RoPE。

### 2.2 Token Alignment（TA）——跨分词器对齐
- **核心机制**：通过**共享字符结束边界**建立发送方 token 与接收方 token 的对应。
  - 对接收方每个未匹配边界，使用**最近的前一个共享边界处的发送方状态**；首个匹配之前使用第一个发送方状态；
  - **多对一情形不对发送方状态取平均**，而是取匹配字符边界处的发送方 token（保持同一因果前缀端点）；
  - 映射后接收方使用**自己的位置索引**施加 RoPE。
- 论文用 "The unbelievable result." 举例：Qwen3 切为 `The | unbelievable | result | .`（结束于 3,16,23,24），Ministral-3 切为 `The | unbel | iev | able | result | .`（结束于 3,9,12,16,23,24）；Qwen3→Ministral-3 时，接收方字符 9、12 处的边界复用 Qwen 结束于字符 3 的状态。

### 2.3 Layer Alignment（LA）——跨深度对齐
- 采用**比例深度对齐**：$\pi(\ell) = 1 + \mathrm{round}\left(\frac{(\ell-1)(L_S-1)}{L_R-1}\right)$；
- 取匹配层附近偏移 $(-4, 0, +4)$ 的**三层**发送方特征：$N(\ell) = \mathrm{clip}_{[1,L_S]}[\pi(\ell)-4,\ \pi(\ell),\ \pi(\ell)+4]$；
- 图 4(a) 显示多层聚合比单层更能预测接收方原生 K/V（$R^2$ 更高）。

### 2.4 Recolor：矩匹配的 KV 映射
- 对每个接收方层和角色 $c \in \{K, V\}$，将三层发送方特征**拼接并展平**（允许跨头映射，即使头数不同）：
  $$x^{\ell,c}_n = [c^{S,t_1}_{i_n} \| c^{S,t_2}_{i_n} \| c^{S,t_3}_{i_n}], \quad y^{\ell,c}_n = c^{R,\ell}_{j_n}, \quad (t_1,t_2,t_3) = N(\ell)$$
- 计算全局标量 RMS $r$，做尺度归一 $Z = X/r$；随后**白化 → Procrustes 对齐配对特征 → 恢复接收方协方差与均值**：
  - 对 $\Sigma_Z^{-1/2}\Sigma_{ZY}\Sigma_Y^{-1/2} = U\Lambda Q^\top$ 做薄 SVD，得 $R^\star = UQ^\top$；
  - 初始化映射：$A = \Sigma_Z^{-1/2} R^\star \Sigma_Y^{1/2}$，$b = \mu_Y - \mu_Z A$，$y^{(0)} = (x/r)A + b$。
- **动机**：token 级重建目标（Dense Latent、KV Ridge）可能重建误差低却改变接收方注意力；Recolor 匹配接收方特征均值与协方差，图 4(b,c) 显示其分布更贴近原生 K/V。

### 2.5 输出感知校准（Output-Aware Calibration）
- **误差分解**：$\hat{O} - O^* = \underbrace{[(\hat{P}-P^*)V^*]W_O^\top}_{\text{key 引起}} + \underbrace{[\hat{P}(\hat{V}-V^*)]W_O^\top}_{\text{value 引起}}$，据此对 K、V 分别校准。
- **低秩修正**：$\hat{y}_{\ell,c} = y^{(0)}_{\ell,c} + (y^{(0)}_{\ell,c} B_{\ell,c})G_{\ell,c}$，秩 $\rho_c = 16$，$G$ 初始化为零，仅训练 $B, G$，模型与初始映射冻结。
- **损失函数**：
  - Key：$\mathcal{L}_{\ell,K} = \mathbb{E}_{x,h,p}\left[D_{KL}(P^*_{\ell,h,p} \| \hat{P}_{\ell,h,p}) + \frac{\|\Delta O_{K,\ell,h,p}\|_2^2}{d_{model}^R}\right]$（同时匹配注意力模式与其经输出投影后的影响）；
  - Value：$\mathcal{L}_{\ell,V} = \mathbb{E}_x\left[\frac{\|\hat{O}_\ell - O^*_\ell\|_F^2}{\max(\|O^*_\ell\|_F^2, \epsilon)}\right]$（固定 $\hat{P}$ 只优化 value）。
- 校准仅使用问题跨度内的原生接收方 query、注意力权重、value 与输出，**不使用金标答案或生成续写**。
- **折叠推理（Folding）**：校准后把修正折进仿射映射 $A_{final} = A(I+BG)$、$b_{final} = b(I+BG)$，推理时每层每角色仅一个固定仿射映射 $\Phi_{\ell,c}(x_j) = (x_j/r)A_{final} + b_{final}$，**无独立修正模块**。
