## 摘要
长程智能体越来越多地将其键值缓存复用为记忆：服务系统保留一部分缓存条目，丢弃其余。因此，驱逐与情景记忆方案依赖于一个很少直接验证的前提：一旦产生某事件的观测消失，被保留的事件仍具信息量。我们在其他方面完全相同的智能体历史中，通过从服务中省略一个早先观测来检验这一点。在对该观测敏感的项目中，答案压倒性地偏向于被省略的值，尽管所服务的片段中并无任何信息指明哪个值是正确的。我们将此称为语义物化：下游事件的缓存行充当了计算的一个可独立服务的视图，即便其输入已经消失。这一过程也可以被有意构造。在千问3-8B上，一句经过精心措辞、不含答案的事件能将捐赠者对齐的恢复率从6%提升至51%，且从未提及该值；而从长期对话中被动收集的自然提及则未显示出任何优势。这样的一个行所携带的信息是具体且有界的。紧凑的状态能够留存，更大的载荷则衰退趋近随机，而一个构造是否写入根本不取决于意义本身，而取决于措辞，以至于模型理解程度相同的两种措辞可能产生显著差异。结果便是为稀疏事件键值服务订立的一份记忆契约：写什么，落在何处，以及来源消失后什么能够留存。对于任何执行驱逐的人而言，推论是：丢弃一个源事件而未观察到准确率损失，并不能证明该源事件无关紧要。

## Abstract
Long-horizon agents increasingly reuse their KV cache as memory: a serving system keeps a subset of cached entries and drops the rest. Eviction and episodic-memory schemes therefore rest on a premise rarely tested directly, that a retained event is still informative once the observations that produced it are gone. We test it by omitting one earlier observation from what is served, across otherwise identical agent histories. Among items sensitive to that observation, the answer overwhelmingly follows the omitted value, though no served span says which value is correct. We call this semantic materialization: a downstream event's cached rows act as an independently servable view of computation whose inputs are gone. It can also be written on purpose. A deliberately phrased, answer-free event raises donor-aligned recovery from 6% to 51% on Qwen3-8B without ever naming the value, whereas passively harvesting natural mentions from long-term dialog yields no detected advantage. What such a row carries is specific and bounded. Compact state survives, larger payloads decay toward chance, and whether a construction writes at all turns on phrasing rather than on meaning alone, so two phrasings the model comprehends equally well can diverge sharply. The result is a memory contract for sparse event-KV serving: what to write, where it lands, and what survives once the source is gone. For anyone who evicts the corollary is that dropping a source event and observing no accuracy loss does not show the source was unnecessary.

    *   **读取**: 服务时，丢弃源事件，只服务根事件及其他固定的、捐赠者不变的支架（decoy）。此时，向模型询问M的状态。如果答案跟随了被丢弃源事件的价值，则说明根事件行发生了“语义物化”。

### 6. 论文的主要结论与发现

*   **语义物化现象普遍存在**: 在对捐赠者敏感的项目中，答案在99:0的显著比例上跟随了被省略的源事件价值，尽管服务的文本从未声明哪个价值是正确的。这表明一个源事件被省略的下游事件行已经“物化”了此前计算的结果。
*   **该原语是可编程的**: 一个有意编写的、不含答案的“计算载流子”事件能显著提升状态恢复率（例如从6%到51%），而被动地从自然对话中收集提及则不是一种可靠的端到端接口。显式的文本记录是最可靠的兜底方案。
*   **存在一份“记忆契约”**:
    *   **触发**: 取决于表面的措辞，而非仅仅是语义。不同的措辞在写入能力上差异巨大，且不存在跨模型的通用构造。
    *   **着陆**: 物化的价值主要着陆在“根”事件上，下游的“引用边”事件主要起路由作用，而非承载价值本身。
    *   **访问**: 通道是紧凑的。二进制状态能被有效恢复，但更大（四路、八路）或精确的数字载荷无法被原生恢复，其性能会衰退至随机水平。
*   **对键值缓存驱逐的启示**: 丢弃一个源事件而未观察到准确率损失，并不证明该源事件是多余的。它可能已经将必要的信息物化到了另一个仍被保留的事件行中。

### 7. 优点

*   **深刻的洞见性**: 揭示并形式化了“语义物化”这一贯穿键值缓存记忆复用的底层现象，而不仅仅是开发新的服务策略。研究从系统的角度对键值缓存管理提供了根本性指导。
*   **实验设计的极致严谨**: 捐赠者对的设计是方法论上的亮点，它干净地分离了上下文携带的因果效应，排除了文本、先验、干扰项等混淆因素。各种控制（字节等同、回显、孤立编码）和统计方法的运用堪称典范。
*   **系统性的契约定义**: 不仅仅报告一个现象，而是从触发、着陆、访问三个维度定义了其操作性契约，为工程师构建可靠系统提供了清晰的指南（校准写入构造、使用显式文本兜底）。
*   **现实指导意义**: 结论直接挑战了现有的键值缓存驱逐评估范式，指出仅凭下游准确率评估驱逐策略是不够的，必须考虑到状态可能已被物化到别处。

### 8. 不足与局限

*   **“不存在证明”的局限性**: 论文未能探测到被动收集自然提及的好处、或某些构造无法物化状态，这些结论仅限于特定的模型、读取协议和启发式选择。这只是证明在特定条件下没找到证据，不能推广为在所有条件下都无效。
*   **依赖界面，缺乏内部探针**: 所有可访问性结论均是基于输出层面（生成或对数几率探针）的测量。论文自身也承认，需要一个表示层级的探针来充当最终的裁决者，以判断“不可访问”是状态不存在还是解码被阻断。
*   **真实对话中的积极控制有限**: 在真实对话的被动收集测试中，主动注入载流子的积极控制虽在Gemma-4上部分有效，但总体上未能稳定触发一个强效、可理解的信号。这限制了研究在真实世界复杂场景下的直接适用性。
*   **范围限定于特定模型架构**: 研究主要在全注意力（full-attention）和滑动窗口注意力（sliding-window）模型上进行。对于最新的混合线性注意力模型，由于无法在每层暴露可标记寻址的键值缓存，其服务假设不直接适用。
