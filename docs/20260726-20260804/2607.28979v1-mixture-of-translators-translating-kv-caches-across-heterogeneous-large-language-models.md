## 摘要
异构大型语言模型系统日益依赖共享上下文、检索证据和多智能体对话历史，但其内部键值缓存仍是模型特定的，无法跨架构重用。因此，每个模型都必须为相同上下文重复预填充或存储缓存，限制了多模型推理和长上下文生成的可扩展性。我们提出混合转换器（MoT），一个缓存转换框架，将源LLM的上下文KV缓存映射到目标LLM的缓存空间中。与依赖单一投影路径或全局共享潜在空间的先前方法不同，MoT使用多个转换器模块来捕捉多样化的源-目标映射。为进一步减少残差转换误差，我们引入上下文校正损失，使重放的目标轨迹与原生目标轨迹对齐。我们揭示了缓存转换中的两种竞争性失败模式：早期注入导致的传播转换偏移和晚期注入导致的最后状态偏移。MoT通过转换器混合和目标端校正来解决这些问题。在Qwen2.5、GPT-2和OPT模型之间的同构和异构转换中，MoT保持了下游问答性能，包括Qwen2.5-7B规模转换中平均封闭式问答准确率51.0%和平均抽取式问答F1值0.43。在实际案例研究中，MoT为多智能体推理实现了质量保持的内存重用，并在长上下文缓存增强生成中保留了直接上下文质量的96.3%，展示了跨异构LLM的可扩展KV缓存重用。

## Abstract
Heterogeneous Large Language Model (LLM) systems increasingly rely on shared contexts, retrieved evidence, and multi-agent dialogue histories, yet their internal key-value (KV) caches remain model-specific and cannot be reused across architectures. Consequently, each model must repeatedly prefill or store caches for the same context, limiting the scalability of multi-model reasoning and long-context generation. We propose Mixture-of-Translators(MoT), a cache translation framework that maps context KV caches from a source LLM into the cache space of a target LLM. Unlike prior approaches that depend on a single projection path or global shared latent space, MoT uses multiple translator modules to capture diverse source--target mappings. To further reduce residual translation error, we introduce a Context Correction Loss that aligns the replayed target trajectory with the native target trajectory. We reveal two competing failure modes in cache translation: propagated translation shift from early injection and last-state shift from late injection. MoT addresses them through translator mixtures and target-side correction. Across homogeneous and heterogeneous translations among Qwen2.5, GPT-2, and OPT models, MoT preserves downstream QA performance, including Qwen2.5-7B-scale translation with 51.0% average closed-set QA accuracy and 0.43 average extractive QA F1. In practical case studies, MoT enables quality-preserving memory reuse for multi-agent reasoning and retains 96.3% of direct-context quality in long-context cache-augmented generation, demonstrating scalable KV cache reuse across heterogeneous LLMs.

## 1. 论文的核心问题与整体意义

- **背景与动机**：现代异构大型语言模型系统（如多智能体协作、长上下文检索增强生成）常共享相同的上下文、检索证据或对话历史。然而，各模型的内部键值（KV）缓存与模型架构严格绑定，无法直接跨模型复用，导致每个模型都需要重复进行代价高昂的预填充，严重限制多模型推理与长文本生成的可扩展性。
- **核心问题**：如何在架构异构（深度、隐藏维数、注意力头布局不同）的LLM之间实现高质量的KV缓存转换，使得源模型为某一上下文计算的内部状态能被目标模型直接使用，从而消除重复计算、降低内存与存储冗余。
- **整体含义**：提出“混合转换器”（Mixture-of-Translators, MoT）框架，将缓存转换建模为一种可学习的映射，并通过多专家架构和专门的轨迹对齐损失，解决转换过程中的两类竞争性误差，为大规模异构LLM的协作与高效推理铺平道路。

## 2. 方法论

- **问题形式化与误差分析**：
  - 缓存转换定义为学习一个映射 \(KV_{Src,Ctx} \mapsto \widehat{KV}_{Tgt,Ctx}\)，通过选定一组源–目标层对（通道集 \(C\)）注入转换后缓存。
  - 理论分析揭示两种竞争性失败模式（图3、图4）：
    - **传播转换偏移**（早期注入）：转换窗口位于低层时，误差沿残差层传播，最终偏移按指数上界 \((1+\delta)^{L-T_{\text{Start}}}\) 增长（命题2.3）。
    - **校正不足偏移**（晚期注入）：转换窗口靠近顶层时，上层可用的校正层数减少，导致剩余偏移（定义B.1中的校正不足系数 \(d_{T:L}\)）增大，极端情况下 \(d_{L:L}=1\)（命题2.4）。
  - 提出联合优化目标 \(\min(\|s_T\|,\|s_L\|)\)，同时控制窗口内的转换偏移和最终层偏移。

- **混合转换器架构**：
  - 每个转换器是一个基于交叉注意力的骨干模块，将源端KV缓存独立地映射到目标端。
  - MoT 使用 \(N_{Tr}\) 个这样的转换器，并通过**门控函数**为每个 token 产生权重，经 Top‑K 选择后取加权组合：
    \[
    \text{Tr}_{\text{MoT}}(z_u) = \sum_{m \in \mathcal{T}_{\text{Top‑K}}(u)} \tilde{g}_m(z_u)\, \text{Tr}_m(z_u)
    \]
  - 命题3.2证明，最优的混合转换器在转换偏移 \(\|s_T\|\) 上不劣于最优单转换器，且在能产生更优映射时可严格改进。

- **上下文校正损失**：
  - 在上述架构基础上，进一步引入损失项，直接让重放后的目标隐藏态轨迹 \(\hat{h}_{\ell}^{\text{Tgt}}\) 与原生预填充轨迹 \(h_{\ell}^{\text{Tgt}}\) 对齐：
    \[
    L_{\text{CC}}(C) = \sum_{\ell=T_{\text{Start}}+1}^{L} \|\hat{h}_{\ell}^{\text{Tgt}} - h_{\ell}^{\text{Tgt}}\|^2
    \]
  - 实践中使用 KV 缓存层面的一致性作为启发式实现，并证明其能够约束最终层偏移 \(\|s_L\|\) 的上界（命题C.1）。

- **通道选择与缓存重放**：
  - 默认采用**深度比例对齐**：将源、目标层按相对深度顺序连接，选取连续的通道窗口（以降低优化难度）。
  - 为降低重放长上下文的计算开销，提出**源引导稀疏注意力**：在目标重放时，只关注源注意力模式中 Top‑S 个最重要的上下文 token，将注意力复杂度从 \(O(N_{\text{Ctx}}^2)\) 降至 \(O(N_{\text{Ctx}}\cdot S_{\text{Sparse}})\)。

- **方法设计精巧**：MoT 的 token 级门控混合机制能够捕捉到单一投影路径难以覆盖的复杂源–目标映射；上下文校正损失直接以最终轨迹对齐为目标，直观且有效。
- **实验全面扎实**：跨模型家族、跨任务、跨规模的多维度评估，以及消融、可扩展性、实际系统的案例验证，使结论具有较强说服力。
- **实用价值显著**：在多智能体和长上下文场景中展示了低额外开销下的高质量缓存复用，为异构 LLM 协作提供了可落地方案。

## 8. 不足与局限

- **校正能力提升有限**：分析显示 MoT 主要降低转换偏移 \(s_T\) 和正交偏移，对校正不足系数 \(d_{T:L}\) 的改善不明显；未来仍需专门设计能增强目标模型自身校正能力的机制。
- **通道映射依赖启发式**：默认采用的深度比例对齐在训练数据分布或指令遵循差异极大的异构模型对上可能失效，缺少自适应通道匹配策略。
- **不支持跨分词器**：当前方法假设源/目标 token 位置一一对应，无法处理分词器不同的情况，限制了通用性。
- **内存开销**：MoT 因使用多个独立转换器而增加了额外的峰值内存占用（尤其在模型数多时），仅在相对大模型翻译时开销占比可接受；MoT‑h 能缓解此问题但可能轻微损失精度。
- **实验范围**：未探索极大规模（如 70B+）异构模型、未涵盖非 Transformer 架构或编码器‑解码器模型，也未测试更多样的多智能体协作协议。
