## 摘要
边缘LLM在用户在边缘节点之间切换时必须保持推理连续性，这要求将键值（KV）缓存迁移到目标节点。然而，同时发生的切换会使回程链路饱和，导致在移动性限定的迁移窗口内无法完成完整的缓存交付。我们并非像所有缓存条目都同等有价值那样分配带宽，而是按重要性对每个用户的KV缓存进行排序，仅传输其中信息量最大的部分，将令牌级稀疏性转化为通信节省。我们将迁移问题表述为一个多用户回程分配问题，该问题最大化所有用户的平均准确率。每个用户的部分缓存准确率作为其效用：一个S形函数，在RULER基准上拟合测量结果，跨模型和上下文长度R²>0.99。由于重要性排序优先加载高价值条目，准确率曲线的凹区域几乎覆盖整个缓存。我们提出的分配器使服务用户保持在该区域内，从而使每个时隙的分配问题成为凸问题。最优解通过闭式加权注水解法推导得出，该解法推广了信息论注水法，并支持在线调度。所提出的分配器在500ms迁移窗口内达到93.7%以上的平均准确率，与全缓存上限的差距在0.5个百分点以内，并达到理想上限的98.2%至99.5%。

## Abstract
Edge LLMs must preserve inference continuity when a user hands over between edge nodes, requiring key-value (KV) cache transfer to the target node. However, simultaneous handovers saturate the backhaul, preventing full cache delivery within the mobility-imposed transfer window. Rather than allocating bandwidth as if all cache entries were equally valuable, we order each user's KV cache by importance and transmit only its most informative fraction, turning token-level sparsity into communication savings. We cast the transfer as a multi-user backhaul allocation problem that maximizes average accuracy across users. Each user's partial-cache accuracy serves as its utility: a sigmoid that fits measurements on the RULER benchmark with $R^2>0.99$ across models and context lengths. Because importance ordering front-loads the high-value entries, the concave region of the accuracy curve spans nearly the entire cache. Our proposed allocator keeps served users within this region, making each per-slot allocation problem convex. The optimum is derived via a closed-form weighted water-filling solution that generalizes information-theoretic water-filling and enables online scheduling. The proposed allocator attains over 93.7% average accuracy in a 500ms transfer window, within 0.5pp of the full-cache ceiling, and reaches 98.2-99.5% of a clairvoyant upper bound.

## 1. 论文的核心问题与整体含义

### 研究背景
- 边缘 LLM（Edge LLM）部署在靠近用户的边缘节点上，以提供超低延迟的实时 AI 推理服务。
- 用户移动性导致其在不同边缘节点之间切换（handover），为保证推理连续性，需要将用户的 KV 缓存（key-value cache）从源节点迁移到目标节点。
- 与迁移整个模型权重（数十至数百 GB）相比，只迁移 KV 缓存更为可行，但 KV 缓存仍远大于原始文本，且并发切换会使回程链路（backhaul）饱和，无法在移动性限定的传输窗口内完整传送。

### 核心问题
- 在有限的回程带宽和迁移窗口约束下，如何在多个并发切换用户之间分配带宽，以最大化整体推理准确率？
- 关键洞察：并非所有 KV 缓存条目对推理同等重要，存在大量 token 级稀疏性可被利用。

### 整体含义
- 论文提出 ImpactHO（Importance-aware KV cache transfer for multi-user edge LLM handover）框架，将 token 级稀疏性转化为通信节省——按重要性排序传输缓存条目，只发送信息量最高的部分，在带宽受限条件下仍能保持高推理准确率。

## 2. 论文提出的方法论

### 核心思想
- **重要性感知排序传输**：为每个 KV 缓存条目（key-value pair）分配重要性分数，按分数降序传输。任意传输前缀都是该规模下最高排名的子集，确保在传输被截断时目标节点仍持有最有价值的缓存条目。
- **效用最大化调度**：将部分缓存准确率作为每用户效用函数，将多用户回程带宽分配建模为最大化平均准确率的效用最大化问题。

### 关键技术细节

1. **KV 缓存大小建模**：
   - 用户 i 的 KV 缓存大小为 $L_i = 2n_L n_H d_h q T_i$ 比特，其中 $n_L$ 为层数，$n_H$ 为 KV 头数，$d_h$ 为头维度，$q$ 为每标量比特数，$T_i$ 为上下文长度。

2. **效用函数刻画**：
   - 定义 $A_i(y)$ 为收到缓存比例 $y$ 时的推理准确率。
   - 通过 RULER 基准测量，发现准确率随缓存接收比例呈现 **代数 sigmoid** 形状：
     $$A_i(y) = \frac{M_i}{2}\left(1 + \frac{k_i(y - \tau_i)}{\sqrt{1 + k_i^2(y - \tau_i)^2}}\right)$$
   - 参数 $M_i$（准确率上渐近线）、$k_i$（跃迁陡峭度）、$\tau_i$（凹性锚点）可因用户上下文长度和任务特征而异。
   - 重要性排序将 $\tau_i$ 拉低至约 6.5% 的缓存比例，使凹区域几乎覆盖整个缓存范围，为凸优化奠定了基础。

3. **每时隙分配问题的形式化**：
   - 以 $\Delta t$ 为时隙，定义 $b_i$ 为用户 i 的归一化缓存交付速率，$y_i = x_i + b_i \Delta t$。
   - 优化问题：
     $$\max_{\{b_i\}} \sum_{i=1}^N [A_i(y_i) - A_i(x_i)]$$
     $$\text{s.t.} \sum_{i=1}^N L_i b_i \le B,\;\; b_i \ge 0,\;\; \tau_i \le y_i \le 1$$
   - 目标为凸目标函数，约束均为仿射，因此是凸优化问题。

4. **闭式最优解——加权注水**：
   - 通过 KKT 条件得到闭式解：$y_i^\star = \max\{x_i, W_i(\lambda^\star)\}$，其中 $W_i(\lambda)$ 为依赖于对偶变量 $\lambda$ 的用户特定水位。
   - 对代数 sigmoid，内部分支的反函数为：
     $$(A_i')^{-1}(s_i(\lambda)) = \tau_i + \frac{1}{k_i}\sqrt{\left(\frac{M_i k_i}{2s_i(\lambda)}\right)^{2/3} - 1}$$
   - 最优分配在所有内部用户之间**均衡每额外缓存比特带来的边际准确率增益**。
   - 当所有用户具有相同效用和缓存大小时，退化为经典注水解法，地面水平为当前进度 $x_i$，总功率为可交付缓存分数 $B\Delta t/L$。

5. **可行性条件与回退策略**：
   - 问题可行的充要条件为 $B \ge B_{\min} = \frac{1}{\Delta t}\sum_i L_i[\tau_i - x_i]^+$。
   - 当 $B < B_{\min}$ 时，启用 **等化字节（Equalized Bytes, EB）** 准入控制策略，在未到达锚点的用户间均分带宽，优先让用户进入凹性工作区域。

6. **算法复杂度**：
   - 通过二分搜索对偶价格 $\lambda^\star$，每时隙复杂度为 $O(|N_t| \log(\bar{\lambda}/\epsilon))$，即近线性时间。

## 3. 实验设计

### 数据集与基准
- **基准**：RULER，长上下文评估套件，覆盖多种任务和上下文长度。
- **上下文长度**：4K、8K、16K tokens。

### 模型
- Qwen3-8B（主模型，BF16 精度）。
- 额外验证：Qwen3-14B、Llama-3.1-8B-Instruct（验证跨模型架构和大小的鲁棒性）。

### 对比方法
- **EA（Equal Allocation）**：均匀分配带宽，不区分重要性与进度。
- **WTA（Winner-Take-All）**：贪心地将槽预算分配给单时隙边际准确率增益最大的用户（级联变体）。
- **PF（Proportional-Fair）**：最大化 $\sum_i \log(L_i y_i)$，对准确率曲线不可见。
- **Re-prefill**：直接在目标端从原始 token 重建上下文（计算基线）。
- **Hybrid**：同时传输 token 和 KV 缓存，修改自 ctHO [9]，FCFS 分配带宽。

### 仿真设置
- 默认参数：带宽 $B = 20$ Gbps、时隙 $\Delta t = 100$ ms、传输窗口 $T_{\max} = 500$ ms、切换到达率 $\rho = 4$ 用户/秒。
- 切换事件服从 Poisson 过程，上下文长度从 {4K, 8K, 16K} 均匀采样。
- 每点平均 100 秒仿真，100 次 Monte-Carlo 运行。

## 6. 论文的主要结论与发现

1. **部分缓存准确率遵循 sigmoid 规律**：在 RULER 基准上，跨模型和上下文长度，代数 sigmoid 拟合 R² > 0.99，重要性排序将凹陷锚点拉低至约 6.5%。
2. **加权注水为最优分配**：在可行性区域内，最优分配可通过闭式加权注水求解，复杂度近线性；当用户同质时退化为经典注水。
3. **性能优异**：默认设置下达到 93.7% 平均准确率，距全缓存上限仅 0.5 个百分点；达到理想上限的 98.2–99.5%。
4. **重要性排序是关键**：Fast KVzip 排序相比随机排序，在高负载下保持 90% 以上准确率，而随机排序在 ρ=8 时仅 20.2%。
5. **准入控制不可或缺**：在高负载下，EB 准入控制将 sub-τ 饥饿率从 20.8% 降至 0.65%，远优于 WTA 回退的 15.5%。
6. **延迟优势**：在上下文长度 ≥8K 时，本方法低于 Re-prefill 和 Hybrid；且支持 anytime 推理（收到任意前缀即可部分恢复推理），这是对比基线不具备的。

## 8. 不足与局限

### 实验覆盖层面
- **上下文长度覆盖有限**：仅采样 4K/8K/16K 三档，未验证更长上下文（32K、64K、128K）下的 sigmoid 参数稳定性。
- **任务多样性受限**：RULER 虽为综合基准，但对生成任务（如代码、对话）中的准确性衡量不够细致。
- **模型规模覆盖有限**：最大模型为 14B，未覆盖更大规模的 LLM（如 70B+），重要性稀疏性在大模型上是否成立仍需验证。

### 偏差风险
- **sigmoid 模型简化的偏差**：虽然拟合优度高，但在极端截断下（准确性急剧跌落至接近 0 的非凹区域）未纳入优化范围；在 B 极小、用户极多的场景下，实际效用可能偏离 sigmoid 假设。
- **Fast KVzip 依赖**：实验基于 Fast KVzip 的评分结果，转向其他评分方法（如 SnapKV、KVzip 等）后的性能需要额外验证；这些方法的重要性分布特征可能不同。
- **仿真依赖拟合效用**：主结果以拟合 sigmoid 为准，端到端测量仅验证了有限的采样点（每 4000 用户的均值），在大规模真实部署中的动态适应性仍需验证。

### 应用限制
- **带宽模型简化**：假设固定回程带宽 B 且为每时隙理想的调度，未考虑链路差错、重传、拥塞等实际网络行为。
- **单方向传输假设**：只考虑一个传输方向，实际移动可能双向同时发生，反向链路负载未见处理。
- **无计算调度整合**：与 ctHO [9] 相比，本方案实质上是纯通信带宽分配，未联合优化目标端 CPU/GPU 计算调度；对于计算资源紧张的边缘节点，计算时延可能成为新瓶颈。
- **理论保证的边际**：理想上界对比显示高负载下性能差距扩大（ρ=8 时差 1.77%），说明短视调度在大负载下仍有损失，需要更长期（multi-slot）调度策略。
