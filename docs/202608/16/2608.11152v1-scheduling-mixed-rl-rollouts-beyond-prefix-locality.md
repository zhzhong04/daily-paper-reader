## 摘要
现代大语言模型（LLM）的强化学习（RL）后训练流程日益将多个领域和反馈范式的回放工作负载结合在一起。前缀感知路由通过缓存复用和负载均衡提高了推理效率，但它并不控制异构回放会话如何竞争KV缓存容量。当带可验证奖励的强化学习（RLVR）、基于人类反馈的强化学习（RLHF）和智能体回放共享异步推理服务时，它们不同的序列结构、交互模式和KV驻留时间会产生截然不同的服务需求。回放调度必须考虑这种异构性，同时不能扭曲训练器指定的工作负载混合。我们提出了MISA-T，一种用于混合回放服务的路由层接纳策略。MISA-T结合了自适应会话接纳、工作负载感知的KV容量分配和驻留时间感知的KV核算。在Step3.7和Qwen3.6-35B-A3B上的仅回放消融实验中，与经过扫描调优的缓存感知vLLM路由器相比，MISA-T分别将回放吞吐量提高了53.3%和43.6%，同时保持了较高的前缀缓存命中率。在匹配的50次迭代Step3.7实验中，它将回放吞吐量提高了35.6%，平均迭代时间减少了22.8%，同时使消耗的工作负载混合接近训练器目标，并取得了相当的任务得分。

## Abstract
Modern reinforcement learning (RL) post-training pipelines for large language models (LLMs) increasingly combine rollout workloads across multiple domains and feedback paradigms. Prefix-aware routing improves inference efficiency through cache reuse and load balancing, but it does not control how heterogeneous rollout sessions compete for KV-cache capacity. When reinforcement learning with verifiable rewards (RLVR), reinforcement learning from human feedback (RLHF), and agentic rollouts share an asynchronous inference service, their distinct sequence structures, interaction patterns, and KV-residency times create substantially different serving demands. Rollout scheduling must account for this heterogeneity without distorting the workload mixture specified by the trainer. We present MISA-T, a routing-layer admission policy for mixed rollout serving. MISA-T combines adaptive session admission, workload-aware KV-capacity allocation, and residency-time-aware KV accounting. In rollout-only ablations on Step3.7 and Qwen3.6-35B-A3B, MISA-T improves rollout throughput over a sweep-tuned cache-aware vLLM Router by 53.3% and 43.6%, respectively, while maintaining high prefix-cache hit rates. In a matched 50-iteration Step3.7 experiment, it increases rollout throughput by 35.6% and reduces mean iteration time by 22.8%, while keeping the consumed workload mixture close to the trainer target and achieving comparable task scores.

## 1. 核心问题与研究动机

随着 LLM 强化学习（RL）后训练规模的扩大，回放（rollout）生成逐渐演变为一种分布式推理服务负载。现代 RL 训练管线往往同时混合多种回放工作负载：

- **RLVR**（可验证奖励强化学习）：短输入、长输出，解码（decode）主导；
- **RLHF**（人类反馈强化学习）：输入输出长度相对均衡，预填充与解码并重；
- **Agentic 回放**：多轮交互，长累积前缀在工具调用间隙长期驻留 KV 缓存。

已有**前缀感知路由**（Prefix-aware Routing，如 vLLM Router、SGLang、Preble 等）只解决请求放置和缓存复用问题，**并不控制新会话如何竞争有限的 KV 缓存容量**。在高并发下，过多新会话涌入会不断挤占 KV 缓存，导致可复用前缀被逐出、后续请求转为冷预填充，形成"预填充—逐出—队列延长—更多逐出"的正反馈崩溃循环。此外，不同工作负载的 KV 占用和驻留时长差异显著，简单全局并发限制无法合理划分各工作负载的受保护容量，且容易扭曲训练器指定的负载混合比例。因此，需要一种路由层的**准入控制（admission control）策略**来显式管理混合回放会话对 KV 缓存容量的竞争。

## 2. 方法论：MISA-T

### 核心思想

MISA-T（**Mix-aware Session Admission with Time factor**）作为路由层准入策略，将训练器的**负载混合契约**与路由器的**资源控制**分离：训练器决定目标分布，路由器负责会话级准入控制、按工作负载类别分配受保护 KV 容量，并考虑各类别的 KV 驻留时间。整体分为三个层次：

1. **自适应会话准入**（Adaptive Session Admission）
2. **工作负载感知的容量分配**（Workload-aware KV-capacity Allocation）
3. **驻留时间感知的 KV 核算**（Residency-time-aware KV Accounting）

### 关键技术细节与公式

**（1）自适应会话准入**

针对每个推理实例 \( w \)，设有受保护会话上限 \( K_w(t) \)（\( K_w(t) \le K^{base}_w(t) = \lfloor C_w / \bar{k}_w(t) \rfloor \)，其中 \( C_w \) 为受保护 KV 块预算，\( \bar{k}_w(t) \) 为滑动窗口内的会话参考长度），准入判定为：

\[
\text{ADMIT}(r,w) = 
\begin{cases}
1, & s_r \in O_w \cup P_w \\
1, & |O_w| + |P_w| < K_w(t) \\
0, & \text{otherwise}
\end{cases}
\]

- \( O_w \)：已在运行的受保护会话；
- \( P_w \)：已准入但尚未在最新缓存快照中可见的待定会话；
- 超出容量时的请求被 HOLD，周期性地重新评估。

当发生确认的前缀缓存命中率下降或排队积压时，控制器通过过载压力信号暂时收缩运行上限，待恢复后再逐步回升，避免依赖静态并发扫描调参。

**（2）工作负载感知的会话上限**

引入类别级软配额。设类别 \( b \) 的可见会话数 \( N_{w,b} \)、参考 KV 占用 \( \bar{k}_b \)，空间需求为：

\[
S_{w,b} = N_{w,b} \bar{k}_b
\]

按空间需求比例分配受保护 KV 预算并折回会话上限：

\[
M^{space}_{w,b} = C_w \frac{S_{w,b}}{\sum_{b'} S_{w,b'}}, \quad
K^{space}_{w,b} = \max\left(1, \left\lfloor M^{space}_{w,b} / \bar{k}_b \right\rfloor\right)
\]

新会话必须同时满足全局上限和类别上限才被准入。

**（3）驻留时间感知的 KV 核算**

仅看 KV 占用不足以区分"占用短时间"与"长时间驻留"的需求差异。MISA-T 引入类别级驻留时间估计 \( \hat{T}_b \)，将空间需求替换为**块时间需求**：

\[
R_{w,b} = S_{w,b} \hat{T}_b = N_{w,b} \bar{k}_b \hat{T}_b
\]

按块时间需求比例分配预算：

\[
M^{time}_{w,b} = C_w \frac{R_{w,b}}{\sum_{b'} R_{w,b'}}, \quad
K^{time}_{w,b} = \max\left(1, \left\lfloor M^{time}_{w,b} / \bar{k}_b \right\rfloor\right)
\]

对于 agentic 会话，驻留时间包含推理时间和工具执行间隔；单请求样本则覆盖从准入到完成的全过程。\( \hat{T}_b \) 基于类别内最近完成会话在线估计，早期用共享中性先验稳定配额。

**算法流程概要**：每个调度周期，控制器从各推理实例收集会话快照和前缀缓存状态 → 估计各类别的块时间需求 → 计算全局和各类别准入容量 → 对每个到达请求执行准入判定（已准入的续接请求放行，新会话按容量门控，超限会话进入 HOLD 等待重新评估）→ 在准入通过后，交给原有缓存感知放置策略选择实例。

## 6. 主要结论

1. **准入控制是必要的**：仅靠前缀感知放置无法防止 KV 缓存崩溃；高负载下 vLLM Router 前缀命中率从 92.4% 跌至 4.5%，请求、预填充、解码吞吐分别下降 52.5%、57.3%、38.5%；
2. **MISA-T 显著提升服务效率**：
   - 仅回放实验：Step3.7 回放吞吐提升 53.3%（相对 sweep-tuned vLLM Router），Qwen3.6-35B-A3B 提升 43.6%，前缀命中率分别达 97.8% 和 95.3%；
   - 端到端实验：回放吞吐提升 35.6%，平均迭代时间缩短 22.8%，请求/预填充/解码吞吐分别提升 32.5%/33.6%/38.0%，前缀命中率从 74.5% 升至 96.2%；
3. **负载混合偏差更小**：50 次迭代中 MISA-T 的消耗混合物 TV 距离为 2.71 个百分点，低于 vLLM Router 的 4.14 个百分点；
4. **任务质量不受损**：Pass@4 在 SWE-Pro、SWE-Verified、SWE-MTLG 上与基线差异低于 0.5 个百分点；
5. **与 CPU KV offloading 可组合**：offloading 启用后 GPU KV 使用率仍保持在 90% 以上，平均每副本 RPM 提升 35.6%，说明路由层准入与物理缓存分级可以协同工作。

## 7. 优点

1. **问题定位精准**：指出"放置（placement）≠准入（admission）"，KV 缓存竞争是前提感知路由未能覆盖的空白，具有明确的实际意义；
2. **系统设计分层清晰**：将训练器契约与资源配置解耦，不干预模型执行、物理 KV 分配和 agent 运行时，可插拔性强；
3. **方法链条完整**：从全局准入 → 类别配额 → 驻留时间加权逐步叠加改进，每一项贡献都能在消融中定量分离；
4. **形式化方案得体**：以块时间（block-time）刻画 KV 需求，将智能体工具执行间隔纳入驻留时间，抓住了混合回放的核心特征；
5. **实验设计全面且有层次**：端到端 + 仅回放 + 高负载诊断 + offloading 兼容性，分别验证了实际收益、机制归因、崩溃复原和互操作性；
6. **诚实报告任务得分差异**，验证了效率提升不以训练质量下降为代价；
7. **基线设置较公平**：静态基线经过扫描调优，且额外提供容量安全配置和高负载配置，避免只对比"被压垮的基线"。

## 8. 不足与局限

1. **对外部条件的依赖**：MISA-T 假设请求携带明确的工作负载标签，依赖推理实例及时上报会话快照和缓存状态；快照延迟或不完整会降低 KV 需求估计和准入上限的准确性；
2. **泛化性验证不足**：
   - 端到端仅 1 个模型、1 种混合比例、50 次迭代；
   - 未覆盖不同 token 上下文限制、不同并发压力、不同工作负载混合比例下的敏感度分析；
   - 未与 Preble、DLPM、k-LPM 等既有系统直接对比；
3. **统计报告不足**：3 次独立运行未报告标准差/置信区间，难以判断提升的统计显著性；
4. **资源消耗成本未量化**：未报告准入控制本身的计算/内存开销，以及部署复杂度；
5. **实现细节不透明**：过载压力触发/恢复阈值、中性先验参数、滑动窗口长度等超参数的设定和敏感性未展开说明；
6. **模型覆盖有限**：实验涉及稀疏 MoE（Step3.7）和 MoE（Qwen3.6-35B-A3B），未覆盖稠密模型或更大 batch 的并行推断场景；
