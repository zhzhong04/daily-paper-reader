## 摘要
长期记忆使语言智能体能够复用过去的事实、偏好和任务经验。然而，持久性也带来了一个核心的可证伪性问题：当世界发生变化时，过时的记忆可能仍可被检索，从而污染提示。我们将这种失效模式定义为记忆污染：即由已被更新的冲突证据所取代的活跃记忆引起的性能退化。我们提出了 TEPA，一种可撤销的证据-记忆机制，将有效性作为记忆的显式状态。TEPA 将观察表示为带键的先例，当同一键下的新证据与活跃先例相矛盾时，它会撤销这些活跃先例，从而允许检索从当前证据中获取信息，同时保留被撤销的历史以供审计。在受控的隐藏状态漂移、真实的基于文件的可执行漂移以及偏好更新流中，撤销机制防止了过时的活跃记忆在反转后仍保留在检索集中。在50个随机种子的受控漂移实验中，完全反转期间，仅追加和最后写入优先的记忆性能低于无记忆（仅追加和最后写入优先均为0.210，无记忆为0.309，TEPA为0.950），并且在真实文件执行下重现了相同模式（仅追加0.203，无记忆0.298，TEPA 0.950）。在干净的 MemoryAgentBench SH-6k 上，TEPA 与强大的最后写入优先缓存相匹配，证实了当前键替换是单跳事实整合的关键操作。对多跳和超长上下文 MemoryAgentBench 设置的边界测试揭示了超越事实级有效性跟踪的检索链和上下文选择瓶颈。总之，这些结果确立了生命周期撤销作为记忆操作的核心地位，这些操作适用于必须对不断演进的知识进行证伪、审计并随后重新提升的语言智能体。

## Abstract
Long-term memory enables language agents to reuse past facts, preferences, and task experience. Persistence also creates a central falsifiability problem: when the world changes, stale memories can remain retrievable and pollute the prompt. We characterize this failure mode as memory pollution: degradation caused by active memories that newer conflicting evidence has superseded. We introduce TEPA, a revocable evidence-memory mechanism that makes validity an explicit state of memory. TEPA represents observations as keyed precedents and revokes active precedents when fresh evidence contradicts them under the same key, allowing retrieval to draw from current evidence while preserving revoked history for audit. Across controlled hidden-regime drift, real file-backed executable drift, and preference-update streams, revocation prevents stale active memory from remaining in the retrieval set after reversal. In controlled drift over 50 seeds, append-only and last-write-wins memory fell below no memory during full reversal (append-only and last-write-wins both 0.210, no memory 0.309, TEPA 0.950), and the same pattern reproduced under real file execution (append-only 0.203, no memory 0.298, TEPA 0.950). On clean MemoryAgentBench SH-6k, TEPA matches a strong last-write-wins cache, confirming that current-key replacement is the decisive operation for single-hop fact consolidation. Boundary tests on multi-hop and very long-context MemoryAgentBench settings expose retrieval-chain and context-selection bottlenecks beyond fact-level validity tracking. Together, these results establish lifecycle revocation as a core memory operation for agents that must falsify, audit, and later re-promote evolving knowledge.

## 1. 论文的核心问题与整体含义

- **研究背景**：语言智能体（Language Agents）越来越依赖长期记忆来复用历史事实、用户偏好、反思结论与任务经验。然而，持久性记忆引入了一个可证伪性（falsifiability）问题：当世界发生变化（如用户偏好改变、实体属性更新、工具行为模式切换）时，旧的记忆仍保留在活跃集合中并可被检索，从而与新的、相互矛盾的证据一起被注入提示（prompt），导致模型输出不一致或错误。
- **核心问题定义**：论文将这一失效模式刻画为**记忆污染（memory pollution）** ——即由已被更新冲突证据所取代的活跃记忆引起的性能退化。该问题与概念漂移（concept drift）相关，但在操作层面有独特形态：被污染的"对象"是插入提示中的文本证据。
- **研究目标**：探究一个直接的系统性问题——当记忆自身的证据必须被证伪时，持久记忆是否仍能保持有用？TEPA 给出了肯定回答：需要将记忆有效性（validity）作为显式状态来追踪，并通过冲突键撤销（conflict-keyed revocation）来防止过时记忆污染当前交互。

## 2. 论文提出的方法论

- **核心思想**：TEPA 将记忆表示为带键先例（keyed precedents）的集合，每个先例携带显式的生命周期状态，新证据在相同冲突键下与旧先例矛盾时，旧先例被撤销（从活跃集合移至归档集合），检索仅获取活跃的当前证据，但被撤销的历史仍保留以供审计。

- **关键概念与组件**：
  - **先例（precedent）**：`p = (k, v, s, f, σ, τ)`，其中 `k` 为冲突键，`v` 为断言的值/动作模式，`s` 和 `f` 分别为支持计数与冲突计数，`σ` 为生命周期状态（Hypothesis / Active / Revoked），`τ` 为创建时间。
  - **冲突键（conflict key）**：两条证据冲突当且仅当它们共享键但值不兼容：`conflict(x_i, x_j) = 𝟙[κ(x_i)=κ(x_j) ∧ ν(x_i)≠ν(x_j)]`。
  - **有效性估计**：使用 Beta-Bernoulli 模型估计先例的后验均值 `q(p) = (s_p + α) / (s_p + f_p + α + β)`，其中 α=β=1，作为生命周期状态转换的透明状态变量。
  - **生命周期更新规则**：当证据支持活跃先例时 s 增加；证据矛盾时 f 增加。当后验均值低于撤销阈值 θ_rev（且观察数 ≥ n_min=5），或最近窗口内成功率低于 θ_rec=0.34（且观察数 ≥ n_rec=3）时，先例从 Active 移入 Revoked 归档。
  - **TEPA-Full（试验验证变体）**：在候选先例被提升为 Active 前，通过持有任务集 H 执行三项试验（支持任务、反事实任务、污染检查），≥60% 试验为正且至少一个支持试验成功时方可提升，提升阈值 θ_pro=0.6。

- **与基线方法的对比逻辑**：追加式（append-only）记忆保留所有证据为活跃；时间近因、滑动窗口等通过年龄/容量限制减少暴露但无法精准处理同键冲突；反应式遗忘为全局重置；TEPA 的更新粒度是"键控先例"，撤销仅影响共享冲突键的活跃先例，其他键不受干扰。

- **理论支撑**：论文给出三个命题——（1）单键超集场景下撤销旧证据的策略在期望 0-1 损失上弱支配保留全部证据的策略；（2）污染随暴露概率与跟随概率的乘积 qη 增长；（3）后验撤销在平稳段内具有一致性，经验均值以概率 1 收敛至真实均值。

- **R1（记忆污染存在性）**：追加式记忆在完全反转阶段确实比无记忆更差——受控漂移中追加式 0.210 vs. 无记忆 0.309（污染指数 0.318），可执行漂移中 0.203 vs. 0.298（污染指数 0.319），验证了陈旧活跃记忆是性能崩溃的驱动因素。
- **R2（撤销的有效性）**：TEPA 在受控与可执行漂移的完全反转阶段均达到 0.950 成功率，远超追加式（0.210/0.203）、无记忆（0.309/0.298）和反应式遗忘（0.796/0.771），且优于 Oracle 重置（0.812）。配对 TEPA-vs-追加式反转差异为 0.740（受控）与 0.748（可执行），均高度显著。
- **R3（试验验证的必要性）**：偏好更新流中追加式崩溃至 0.138，无记忆为 0.837；TEPA-Full 达到 0.910 与无记忆统计上不可区分，验证过滤候选提升与生命周期撤销是互补操作。
- **R4（外部基准迁移）**：MemoryAgentBench SH-6k 上 TEPA-Rev 子串精确匹配 0.890，与 Last-Write-Wins（0.890）持平，远超 TEPA-NoRev（0.630）与追加式（0.583），表明当前键替换是干净单跳事实更新的决定性操作。
- **边界条件**：TEPA 在 SH-32k 为 0.680，但 MH-6k 降至 0.040、SH-262k 降至 0.000，说明多跳关系检索与超长上下文选择是超越事实级有效性追踪的下一层瓶颈。
- **总体论断**：生命周期撤销应作为语言智能体记忆的核心操作——记忆项目可以相关、近期但仍然错误（值已被超越时），撤销机制将其从普通检索中移出，同时保留供验证、审计与后续重新提升。

## 8. 不足与局限

- **键提取假设较强**：TEPA 依赖从证据中可靠提取冲突键（偏好槽、实体属性、工具状态记录等结构化学科场景适用），但开放式记忆的冲突关系通常是隐式的，键提取失败将直接影响撤销正确性。论文自承认键噪声审计显示 TEPA 性能随噪声平滑下降（0.950→0.777 @20% 噪声）。
- **适用场景有限**：方法聚焦单跳陈旧冲突消解，对多跳关系组合、跨键合成与超长上下文选择是失效的（MH-6k 0.040、SH-262k 0.000），论文将"检索链构建"与"上下文选择"明确视为后续瓶颈，但未提供解决方案。
- **理论范围窄**：命题仅保证单键超集场景下 0-1 损失的弱优势，不承诺多键、检索链组合或一般智能体任务下的全局最优性。
- **基准覆盖有限**：虽然涵盖了四类冲突场景，但未在更复杂的自主智能体记忆基准（如 LongMemEval、LoCoMo 多跳版本）上验证，偏好更新场景也未涉及更深层的长期记忆构造成熟度。
- **算力信息缺失**：未报告训练/推理的算力配置，削弱了可复现性的硬件条件说明。
- **Oracle 重置上界较低（0.812）**：即使拥有阶段边界特权信息，性能仍低于 TEPA（0.950），说明在基础执行器较弱的情况下机制比较可能存在天花板效应，不同后端下的相对优势待验证。
- **与无记忆无差异的结论需谨慎解读**：偏好更新中 TEPA-Full 与无记忆统计无差异（差 0.002，p=1.000），这既可解读为"撤销防止了伤害"，也可能是该方法在该场景下并未比无记忆增加额外价值，论文倾向前者但两种解读均成立。
