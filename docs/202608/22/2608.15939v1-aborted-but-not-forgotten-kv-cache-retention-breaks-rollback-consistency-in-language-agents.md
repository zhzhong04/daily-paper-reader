## 摘要
有状态语言代理假设被拒绝的分支可以通过从应用记录中清除来回退。我们表明，当服务会话在逻辑中止后保留键/值（KV）状态时，这一假设会被打破：模型可以继续关注应用认为已丢弃的内容。我们将缺失的保证形式化为回滚一致性：完整中止必须恢复模型所关注的状态，而不仅仅是记录。关键失败是跨层的：正确的逻辑回滚不一定会与保留的推理状态组合，且这一差距可能对应用不可见。为了将缓存效应与文本效应分离，我们引入了一种同令牌/不同缓存审计，保持决策步骤令牌不变，仅变化缓存前缀是过期的还是从已提交状态重建的。在七个开放权重系列（3.8B-36B）中，仅保留的KV就在63个被审计单元中的25个翻转了类型化受保护效应，而攻击者令牌在所有63个中均未出现在所服务请求中；重建缓存则封闭了所有单元。该通道在端到端会话应用、默认的Hugging Face Transformers缓存重用路径以及LangGraph时间旅行下均可复现，后者中经过验证的逻辑回滚仍可能留下被关注的陈旧KV。易感性因模型而异，但底层的被关注状态完整性违反是结构性的。我们排除了位置和长度混淆，在受保护效应、策略结构以及缓存隔离的混合专家模型上进行了泛化，并表明事务本地缓存恢复可以封闭该通道，而无需全局缓存刷新。所有主要结果都是确定性的，并可从发布的工件中复现。

## Abstract
Stateful language agents assume a rejected branch can be taken back by clearing it from the application transcript. We show this breaks when the serving session retains key/value (KV) state across the logical abort: the model can continue attending to content the application believes it discarded. We formalize the missing guarantee as rollback consistency: a complete abort must restore the state the model attends, not just the transcript. The key failure is cross-layer: a correct logical rollback need not compose with retained inference state, and the gap can remain invisible to the application. To isolate cache effects from text effects, we introduce a same-token/different-cache audit that holds decision-step tokens identical while varying only whether the cached prefix is stale or rebuilt from committed state. Across seven open-weight families (3.8B-36B), retained KV alone flips a typed protected effect in 25 of 63 audited cells, while attacker tokens are absent from the served request in all 63; rebuilding the cache closes every cell. The channel reproduces in an end-to-end session application, on the default Hugging Face Transformers cache-reuse path, and under LangGraph time-travel, where verified logical rollback can still leave attended KV stale. Susceptibility varies across models, but the underlying attended-state integrity violation is structural. We rule out position and length confounds, generalize across protected effects, policy structures, and a cache-isolated Mixture-of-Experts model, and show that transaction-local cache restoration closes the channel without requiring a global cache flush. All headline results are deterministic and reproducible from released artifacts.

## 一、核心问题与整体含义（研究动机与背景）

- **核心问题**：有状态语言智能体假设"被拒绝的分支可以回退"——应用层清除transcript后，就好像分支从未发生过。但论文发现，当服务会话在逻辑中止后仍然保留**键/值（KV）缓存**时，模型实际"注意"到的状态仍包含被拒绝的分支内容。这导致**回滚一致性（rollback consistency）**被打破：逻辑视图是干净的，物理KV却是陈旧的。
- **本质含义**：这是一个**跨层组合性失败**——应用层的逻辑回滚与推理层的保留状态之间缺少一致性契约。应用查看日志时一切正常，但模型实际上仍被已"删除"内容影响。
- **安全后果**：攻击者只要在被拒绝或废弃的分支中放置内容（例如通过检索文档、工具返回等正常途径），就可能在后续安全敏感决策中**无感知地翻转受保护效果**（如将敏感工件发送给未经授权端点），且攻击者不需要触发、控制甚至观察回滚过程——这比传统间接提示注入（indirect prompt injection）更弱、更容易发生。
- **类比与定位**：与"LLM提取训练数据/缓存时序侧信道"等不同，本文是**控制流通道**——被拒绝分支通过保留KV影响后续的受保护类型化效果。

## 二、论文提出的方法论

### 2.1 方法论核心思想
- **同token/不同缓存（same-token / different-cache）成对审计**：通过保持决策步骤的喂入令牌**逐token相同**，仅仅改变缓存前缀的来源，将"缓存效应"与"文本效应"分离——这是论文因果识别的核心。
- 形式化为**两层属性**（附录A）：
  - **Layer 1——注意力状态回滚完整性（attended-state rollback integrity）**：事后中止状态 K′ ≡state κ(L⋆)，即模型注意的状态必须等于从提交transcript冷启动重推导的状态。这是**模型无关的结构不变量**，每个模型都违反。
  - **Layer 2——效果级回滚一致性（effect-level rollback consistency）**：f(K′, x) = f(κ(L⋆), x)，即中止后的类型化效应与冷重启相同。这是**模型相关的行为属性**（9/9到0/9不等）。
- **命题1/2**：Layer 1 ⇒ Layer 2（充分性）；而Layer 2在有限测试集D上的成立≠Layer 1成立（反例：抗性模型）。

### 2.2 关键技术细节
- 使用HuggingFace Transformers的**显式DynamicCache**作为测量显微镜（便于直接构造和检查KV状态）。
- **四臂构造**（Procedure 1）：
  - `stale`（缺陷）：KV预填充[system, task, vehicle]，只喂入finalize delta，载体只存于保留KV中；
  - `fresh`（修复）：KV仅从[system, task]重建，喂入相同的finalize delta；
  - `cold`（全冷重启）：单次冷遍[system, task, finalize]；
  - `text-present`（身份检查）：冷遍[system, task, vehicle, finalize]，载体出现在文本中。
- 逐单元验证：攻击者token不存在于喂入的决策token（63/63），stale/fresh决策delta token相同（63/63）。
- 解码全部为**贪心（temperature 0）**，确定性强。
- 后期重建了三种等价的**事务局部缓存恢复**机制：`fresh`（重建提交前缀）、`truncate`（DynamicCache.crop截断）、`checkpoint`（恢复KV快照）。

## 三、实验设计

### 3.1 基准（Benchmark）与场景
- **七种开放权重模型家族**（3.8B–36B）：Phi-3.5-mini、GLM-4-9B、Granite-3.3-8B、Qwen2.5-14B、DeepSeek-R1-Distill-Llama-8B、Phi-4、Seed-OSS-36B。另加缓存隔离的Qwen3-30B-A3B（MoE、3B激活）。
- **3×3网格**：3种注入载体（检索文档、工具返回、用户回合）× 3种残留强度（中性、暗示、命令式）= 9个攻击单元/模型，总计63个攻击单元及63个对照单元。
- **攻击链前置条件**（6条）：攻击者内容进入探索分支 → 分支被拒绝/回退 → 逻辑状态移除 → 推理层保留KV → 同一会话后续执行安全敏感效果。

### 3.2 对比方法（防御基线）
- **框架原生中止（buggy retain）**：仅丢弃transcript，不重建KV → 失败（25/63）。
- **提示级"不信任被拒绝内容"防护**：给系统提示增加安全指令 → 从25/45降至14/45，仍不关闭通道（GLM-4-9B完全不受影响，9/9）。
- **全量重启/全局缓存刷新**：关闭通道但代价高（破坏所有共租户）。
- **三种事务局部恢复**（rebuild/truncate/checkpoint）：全部关闭通道（0/36或0/63）。

### 3.3 多层面复现
- **Tensor级隔离**（显式DynamicCache）—主Census；
- **端到端会话应用**（begin/explore/abort/decide协议）—API边界复现，逐模型匹配；
- **框架默认快速路径**（仅用transformers文档化的multi-turn cache-reuse，无position ids/attention mask构造）；
- **第一类回滚API**（LangGraph checkpointer + time-travel，update_state fork）—验证逻辑回滚确实发生但KV仍陈旧。

### 3.4 消融与泛化实验
- **位置/长度匹配控制**：将攻击者token原位覆写为等长中性token → 翻转从25/25降至0/25 →排除位置/长度混淆；
- **多效果泛化**：5种受保护效果（消息/支付/邮件/文件删除/凭证上传）× 4种策略结构 = 45单元/模型，四易感家族总计128/180翻转；
- **MoE验证**（Qwen3-30B-A3B）：9/9翻转，fresh=cold=0/9；
- **随机配对评估**：temperature 0.3时stale 180/180外泄、fresh 0/180；temperature 0.7时stale 178/180、fresh 0/180；
- **前端规模行为补充**（vLLM服务、非缓存隔离）：7个家族中2个2026代前沿dense模型完全抵抗，MoE部分开放 → 行为谱系一致。

## 六、论文的主要结论与发现

1. **回滚一致性被打破**：应用认为"已完成"的逻辑回滚不一定恢复模型实际注意的推理状态——这是跨层组合性缺口，在日志中不可见。
2. **仅保留KV足以翻转受保护效果**：7个dense模型家族中，63个攻击单元有25个翻转外泄目标；攻击token在所有63个单元中均不在已提供服务请求中。
3. **易感性是行为谱系而非结构差异**：从9/9（Phi-3.5-mini、GLM-4-9B）到0/9（DeepSeek-R1-Distill-8B、Phi-4、Seed-OSS-36B），与参数规模无关——抗性只是可能随提示或微调而侵蚀的**行为冗余**。
4. **通道不依赖命令式覆盖**：即使中性残留（仅陈述收件人无指令）也触发7/21外泄；命令式措辞只是提高翻转率（10/21）。
5. **事务局部恢复是充分修复**：重建提交前缀、截断陈旧KV或恢复KV检查点，三种方式都能关闭所有观测单元，且相对全局刷新的成本优势在多租户场景中极大（101ms vs 6,481ms等）。
6. **内容寻址缓存是自愈的**：vLLM、SGLang等按请求前缀复用缓存，不会重新注入已删token，因此不受此通道影响；风险集中在**有状态会话句柄/保留句柄**这一暴露模式。
7. **现有防御均失败**：框架原生中止即缺陷本身（25/63），提示级防护只能降低不能关闭（14/45残余）。

## 七、优点

- **因果识别的严谨性**：同token/不同缓存审计让"缓存效应"从修辞变成可操作、可验证的因果归属；逐单元验证（carrier absent + tokens identical）从根本上排除了"文本注入"竞争解释。
- **两层形式化清晰**：将结构不变量（Layer 1，模型无关）与行为效果（Layer 2，模型相关）分离，为抗性模型提供了精确学术地位，不混淆系统缺陷与行为冗余。
- **多层复现闭环**：从显式tensor控制到真实框架默认路径到第一类回滚API，覆盖"机制→真实应用→正确抽象"三层，说服力强。
- **诚实披露与范围界定**：明确限定retained-handle的范围，将vLLM/SGLang标为自愈、商业隐藏缓存标为UNKNOWN；报告单长上下文SLA无法满足的区域而不隐藏——透明度高。
- **事务局部修复的成本模型**：用真实引擎prefill原语（t(n)=16.17+0.0127n ms）量化三种部署制度下的成本，论证局部修复相对全局刷新的必要性。
- **可复现性**：所有主要数据确定性、封存SHA-256、发布适配器和聚合器，工件可重新生成全部图表。

## 八、不足与局限

- **范围限制**：通道仅适用于retained-handle类KV重用（状态会话、continued generation、agent memory缓存）——内容寻址自动前缀缓存（vLLM、SGLang）不在范围内；**商业隐藏缓存**保持UNKNOWN状态。
- **架构覆盖不全**：混合Mamba、Mistral家族的tokenizer无HF chat template且不用纯DynamicCache，被排除在隔离审计外；混合注意力/线性注意力KV的通道行为未探索。
- **策略场景局限**：授权策略是简单的allowlist；RBAC、人工参与回路（human-in-the-loop）、能力门控等更强策略结构未测试。
- **防揭面不全**：提示级防护之外的结构化防御（如来源追踪的KV、分支作用域KV、能力门控）未展开；论文承认这是未来工作。
- **成本模型是单引擎外推**：cross-engine rewind-vs-re-prefill benchmark尚缺；prefill原语的线性外推是保守下界（真实呈超线性），单长上下文场景两者都达不到紧迫的SLA。
- **随机攻击率描述不完整**：完整的multi-model随机攻击率研究、多seed行为分布预留为未来工作；对"抗性来源于对齐"未作归因。
- **部分补充实验非缓存隔离**：vLLM前沿模型和MoE行为佐证是在"载体出现在上下文中"的变体下进行，与主审计机制不同，论文明确标注为suggestive而非因果。
