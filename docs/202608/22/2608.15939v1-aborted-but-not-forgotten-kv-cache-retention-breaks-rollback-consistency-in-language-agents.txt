## ABSTRACT 

Stateful language agents assume a rejected branch can be taken back: the appli-cation clears its transcript and continues as if it never happened. We show this breaks when the serving session keeps its key/value (KV) cache across the logi-cal abort, as it does whenever an application reuses a session handle or a cached 

past key values for latency. The model then runs on state the application be-lieves it discarded. We formalize the missing guarantee as rollback consistency : a believed-complete abort must restore the state the model attends , not just the tran-script. The point is not that deleted content leaves a trace in cached state, but that a correct logical rollback need not compose with the retained inference state, and this cross-layer gap stays invisible to the application. To separate a cache effect from a text effect, we introduce a same-token / different-cache audit that holds the decision-step tokens token-identical and varies only whether the cached prefix is a stale retained branch or one rebuilt from the committed transcript. Across seven open-weight families ( 3.8B– 36 B), a rejected branch that survives only in retained KV flips a typed protected effect, exfiltrating a sensitive artifact to an attacker end-point, in 25 of 63 audited cells, while the attacker tokens are provably absent from the served request in all 63 ; rebuilding the cache from the committed transcript closes every cell. The exploit reproduces at the API boundary of an end-to-end session application and on a widely used framework’s default cache-reuse path with no tensor surgery, and even when the abort is driven by a first-class rollback API (LangGraph time-travel), a verified logical rollback still leaves the attended KV stale. Susceptibility varies across models; the underlying attended-state in-tegrity violation does not. We rule out a position or length confound and show the channel generalizes across protected effects, policy structures, and a cache-isolated Mixture-of-Experts model. A transaction-local cache restore closes the channel cheaply, where a global flush or full restart does not. All headline num-bers are deterministic, sealed measurements that our artifact regenerates. 

## 1 INTRODUCTION 

Modern language-agent runtimes are built around the assumption that a branch can be taken back .Frameworks expose rejection, pause, rollback and abort; an application that dislikes a proposed ac-tion rejects it, drops the branch from its transcript, and proceeds as if it never happened. Developers reason about safety against the state they believe this abort restored. Independently, the same run-times reuse key/value (KV) state for latency: a session handle, a cached past key values , or a prefix/prompt cache lets the next step skip recomputation (Kwon et al., 2023; Gim et al., 2024; Zheng et al., 2024). The central observation of this paper is that these two facts collide. When a session retains KV across a logical abort, the state the model actually attends to still contains the rejected branch, even though the application’s transcript does not. The logical view is clean; the physical KV is stale (Figure 1). We show that this rollback inconsistency is a hidden channel . After a developer-believed-complete abort, content from a rejected branch that survives only in the retained KV reproducibly changes a later typed protected effect and its downstream harm. The channel does not require an ex-1arXiv:2608.15939v1 [cs.CL] 16 Aug 2026 Preprint. Under review. plicit override instruction. It fires under merely neutral residue that states a recipient without any command, and stronger imperative residue only increases exploitability; we report the flip count separately by residue strength (Table 1, Appendix D) rather than pooling them. In a three-step 

gather → decide → deliver trajectory, residue left in KV by a rejected branch flips the delivery re-cipient of a sensitive artifact from the approved desk to an attacker endpoint. The residue is not a jailbreak string the model is told to obey (Perez & Ribeiro, 2022; Wei et al., 2023); it is ordinary prior context the application thought it had deleted, arriving through realistic vehicles such as a retrieved document or a tool return (Greshake et al., 2023). 

The identification problem, and how we solve it. The hard part of a causal claim is separating a cache effect from a text effect: if the rejected text is still anywhere in the served request, a flip could be ordinary in-context injection rather than a cache bug. We solve this with a same-token / different-cache audit that holds the decision-step tokens token-identical across two arms and varies only the cached prefix: the stale arm’s retained KV encodes the aborted branch whose tokens are 

absent from what is fed, while the fresh arm rebuilds the KV from the committed transcript. Any-thing that differs between the arms is attributable to retained KV alone, and we verify per cell that the attacker token is absent from the fed tokens and that both arms feed identical tokens. 

What we find. Across seven open-weight families ( 3.8B– 36 B) and a 3 × 3 grid of injection vehi-cles and residue strengths ( 63 paired attack cells), the retained KV alone flips the protected decision in 25 /63 cells, while in every cell the attacker token is absent from the served request and the stale-KV outcome matches a cold pass with the carrier in the text; a fresh-cache rebuild and a full cold restart both close the channel ( 0/63 ). An end-to-end session app reproduces the identical per-model flip counts at the API boundary, and when the abort is driven by a named first-class rollback API (LangGraph time-travel) a verified logical rollback still leaves the KV stale ( 25 /45 ; §3.3), so a de-veloper inspecting the log or using the advertised rollback sees nothing. Susceptibility is a spectrum, 

9/9 (open) to 0/9 (resistant, incl. Phi-4 and Seed-OSS-36 B) and not monotonic in model size ; the Layer-1 attended-state integrity violation holds on every model, only whether a model acts on the residue (a Layer-2 effect flip) varies. A length/position-matched control attributes the flip to the deleted attacker semantics rather than cache position, and the channel generalizes across protected effects, policy structures, and a cache-isolated Mixture-of-Experts model (§3, Appendices J and K). 

Scope. The channel requires a retained session/KV handle : an application or engine that keeps a session’s past key values across the abort, as stateful serving sessions, continued-generation APIs, and agent-memory caches do for latency. A content-addressed automatic prefix cache (e.g. vLLM’s) reuses only prefixes actually present in the request and never re-injects removed to-kens, so it is exempt. Our claims are scoped to retained-handle reuse, verified on HuggingFace 

transformers DynamicCache and an end-to-end session app; provider-hidden caches are recorded as UNKNOWN .

Positioning. Prior work has shown that agentic edits require explicit cache mutation (Ma et al., 2026), that deleting or correcting already-processed context can require repairing downstream in-ference state (Li et al., 2026; Li, 2026; Cai & Cai, 2026), and that snapshot/restore/rollback can be made first-class serving operations (Su, 2026; Su et al., 2026). We study a different failure mode: an application believes a rollback has already completed , while a retained serving state silently stays inconsistent with the committed history. We do not claim to be first to observe that deleted content leaves influence in cached state, nor to make inference state restorable; our claim is a cross-layer rollback-consistency contract between an application’s logical rollback and the model’s attended state, whose violation we causally show can alter a later protected effect even when the rejected content is absent from the served request (§5).

## 2 THREAT MODEL AND THE SAME -TOKEN / DIFFERENT -CACHE AUDIT (C1) 

Setting and threat model. A long-lived, stateful agent executes typed protected effects (e.g. 

send message to a recipient) under a committed policy that names an authorized target. The attack chain has six preconditions, each of which occurs by normal agent operation: (1) the agent encounters attacker-controlled content; (2) that content enters a tentative/exploratory branch; (3) the branch is later rejected, retried, or rewound; (4) the logical state removes it (a believed-complete abort drops it from the transcript); (5) the inference layer retains a branch-derived KV handle across the abort for latency; and (6) the same session later executes a security-sensitive effect. The attacker controls only the content of the rejected branch (precondition 1–2), entering through realistic vehi-cles – a tool/function return, a retrieved document, or a user turn – that the application believes it deleted at abort. Crucially, the attacker does not need to trigger, control, or even observe the rollback : preconditions 3–6 are actions of the honest application/runtime; the attacker only places 3Preprint. Under review. a payload in a branch that may eventually be abandoned. The attacker cannot modify the committed policy, the future task, the granted permissions, or the effect executor. This is strictly weaker than in-direct prompt injection (Greshake et al., 2023), which injects into the live context: here the injected content has already been rejected and believed-deleted before the audited decision, and, crucially, is 

absent from the request served at that decision .

Effect executor and the capability/authorization gap. We measure harm with an instrumented effect executor that faithfully executes the agent’s delegated tool call and records the typed effect; it is not an authorization monitor. The allowlist is an application-level authorization policy (this task authorizes only finance-desk ), whereas the executor holds the broad capability to reach any recipient – the realistic case where a messaging agent may contact the whole organization but a task authorizes one recipient. Policy compliance is delegated to the agent/runtime layer, which is what the stale KV subverts; our claim is about which authorized-capability action is taken, not whether the capability exists (deliberately not an OS-ACL that could reject the recipient itself). 

Paired, token-matched estimand. We clone two executions, control and attack , that differ only in the attacker-controlled carried target of the rejected branch ( control carries the authorized target; 

attack carries an out-of-allowlist attacker target). For each we compare cleanup arms that hold the decision-step tokens token-identical and vary only the cached prefix: • stale (the bug): the session KV is prefilled with [system, task, vehicle] ; at the decision step we feed only the committed finalize-turn delta. The carrier survives solely in the retained KV. • fresh (the fix, = C3): the session KV is re-prefilled from [system, task] only; the same committed finalize-turn delta is fed. • cold (full restart): a single cold pass over [system, task, finalize] .• text-present (identity check): a cold pass over [system, task, vehicle, finalize] , i.e. the carrier is in the text .The measured quantity is the instrumented effect executor’s typed effect , that is, whether the deliv-ered recipient is outside the task’s authorized allowlist ( exfiltration ), rather than the model’s answer text. Because the fed decision tokens are identical across stale and fresh , a difference in the effect is attributable to retained KV alone. We verify this construction per cell: the carrier token is absent from the fed stale tokens, and the stale and fresh decision deltas are token-identical (Table 1). 

How the arms are made token-identical. We render each arm’s full message list to token ids with the model’s own chat template, split it at the longest common prefix with its own cacheable prefix (the messages up to but excluding the finalize turn), prefill that prefix into the KV, and feed only the finalize-turn delta (Procedure 1, Appendix B). The stale and fresh arms therefore differ in exactly one variable, the provenance of the cached KV, while feeding the same finalize tokens, which we assert per cell. No attacker token is ever fed at the decision step, so “a cache effect” is operational rather than rhetorical. 

Determinism and reporting. Every decode is greedy (temperature 0), so each (model, vehicle, strength, arm, cache-state) cell has a fixed outcome. We therefore report an exact census over the 

7 × 3 × 3 grid rather than attaching confidence intervals to deterministic decodes (discussed in Appendix G). The grid has 63 attack cells and 63 matched control cells.

We close this by driving the abort with a named, first-class rollback API: LangGraph’s checkpointer and time-travel, the de-facto state layer for language-agent orchestration. The graph persists its logical state (a message channel) at every step and exposes replay and fork of past checkpoints (LangChain, 2026). We compile it with a checkpointer, interrupt before the decision step, and perform the abort with LangGraph’s own 

update state fork on the pre-decision checkpoint, dropping the explored branch from the mes-sage channel. Crucially, we verify against LangGraph’s persisted state that the attacker is present in the pre-abort checkpoint and absent in the post-abort checkpoint in every attack cell: the framework really rolled the logical state back. The KV backend it composes with is the ordinary latency opti-mization – a session-keyed past key values advanced by the new-turn delta on the framework default path – and, by design, LangGraph makes no rollback promise over it. The result is that a correct, first-class logical rollback still leaves the channel open. Across five open-weight families the LangGraph-driven abort reproduces the census spectrum – Phi-3.5-mini and GLM-4-9B 9/9, Granite-3.3-8B 6/9, Qwen2.5-14B 1/9, DeepSeek-R1-Llama-8B 0/9 (25 /45 

overall) – tracking the per-model susceptibility ordering of the tensor-level census. In all 45 attack cells the attacker token is absent from the served request and LangGraph’s logical rollback is veri-fied; all 45 control cells are safe; and wiring the C3 restore into the same abort handler (rebinding the session KV to the committed transcript) closes every cell ( 0/45 ). This converts the “applica-tion misuse” reading into a cross-layer compositional rollback gap : LangGraph faithfully restores the state it owns (the logical transcript), and the serving layer is a correct latency optimization, yet neither layer’s contract covers the attended KV, so composing them leaves a developer who uses a first-class rollback API exactly as documented still inheriting the stale branch. We are not claiming LangGraph violates its own contract – it never promises to rewind serving-layer state; we are show-ing that logical-rollback correctness does not compose into attended-state rollback unless the KV layer participates in the rewind. It is a correctness property , not a tuning knob (a believed-complete abort must restore the state the model attends ), with an operational test. The seven families span the full behavioral range on a single stack: Phi-3.5-mini and GLM-4-9B are fully open ( 9/9), Granite-3.3-8B partially ( 6/9), Qwen2.5-14B only under imperative residue ( 1/9), and three resist entirely ( 0/9: DeepSeek-R1-Distill-8B, Phi-4-14B, Seed-OSS-36B). The two-layer property (Appendix A) makes this precise, and it is important not to conflate the layers. The Layer-1 attended-state integrity violation is model-independent : for every model, including the resistant ones, the retained KV carries the believed-deleted branch ( K′̸ ≡state κ(L⋆)), the isolation invariants hold identically ( 63 /63 carrier-absent, 63 /63 token-identical), and every transaction-local restore closes the arm ( 0/63 ); this is a checkable property of the cache, not a claim over model behav-ior. The Layer-2 effect-level violation is model-dependent (9/9 to 0/9): a resistant model still receives the stale KV but does not act on it, so on the audited cells it simply does not witness the Layer-2 violation (Proposition 2). We are careful not to claim observational rollback consistency is violated on every model; we claim the Layer-1 invariant is, and that resistance is a behavioral mar-gin that can erode with the next prompt or fine-tune, which is why a state-level fix (§4) is the robust remedy. Exploitability is not monotonic in parameter count , but we do not attribute this to align-ment (no alignment metric or same-base ablation; future work). ## 4 ENFORCING ROLLBACK CONSISTENCY : A TRANSACTION -LOCAL CACHE RESTORE , AND WHY EXISTING DEFENSES MISS IT (C3, C4) 

Both naive options are eliminated first (C4). The framework-native abort is exactly the buggy retained-handle arm (it drops the branch from the transcript but never rebinds the KV) and fails: exfiltration stays at the buggy rate ( 25 /63 ). We also add a prompt-level guard that instructs the model to distrust any rejected/aborted content; re-running the identical audit with the guard enabled, over the five susceptibility-spectrum families (the two additional families resist 0/9 with or without the guard), reduces the flip census from 25 /45 to 14 /45 but does not close the channel: GLM-4-9B is entirely unaffected ( 9/9 with or without the guard), and in every remaining flip the carrier is still absent from the served tokens so the KV residue steers the decision regardless of the instruction. The guard fails because the cached residue is not labelled as rejected and is indistinguishable from legitimate context (Table 2; per-cell breakdown in Appendix E). Both naive options are eliminated. 

A transaction-local cache restore closes it, by any of three mechanisms (C3). The fix is to re-store the aborted session’s cache to its committed state. We measured three interchangeable ways to do so, all feeding the identical finalize delta: (i) fresh , re-prefill the committed prefix; (ii) truncate ,crop the stale KV back to the committed length ( DynamicCache.crop ); (iii) checkpoint , restore a KV snapshot taken after the committed prefill. Each closes every observed cell ( 0/36 on the four susceptible families; and 0/63 for fresh /cold over all seven), so we claim a transaction-local restore is sufficient without claiming any one implementation is uniquely necessary. Unlike a global engine cache flush, all three are transaction-local : they touch only the one aborted session and leave every co-tenant’s cache untouched. Because these are exactly the audit’s fresh /truncate/checkpoint arms, their efficacy is measured, not assumed. 

Full restart / global flush is unacceptable where the local fix is not. The fresh-cache re-bind and a full restart both close the channel and are behaviorally equivalent, so the choice is a systems-cost question, not a safety one. Using a prefill primitive measured on a real engine (t(n) = 16 .17 + 0 .0127 n ms up to 960 tokens, extrapolated linearly as a conservative lower bound since real prefill is super-linear), the two remedies differ only in how much cache is re-warmed and how many tenants that disrupts. ## 5 RELATED WORK 

Prompt injection and agent security. Indirect prompt injection compromises LLM-integrated applications by poisoning content the agent reads in its live context (Greshake et al., 2023; Perez & Ribeiro, 2022; Willison, 2023), and benchmarks such as AgentDojo (Debenedetti et al., 2024) and 

τ -bench (Yao et al., 2024) inject inside a running trajectory. Our threat model is complementary: the injected content has already been rejected and believed-deleted and is absent from the served request ; it survives only in retained KV across the abort boundary, a surface those harnesses do not expose. 

KV-cache reuse, editing, and deletion. Serving stacks reuse KV state for latency: PagedAtten-tion/vLLM (Kwon et al., 2023), SGLang (Zheng et al., 2024), and prompt caching (Gim et al., 2024). Their content-addressed automatic caches are self-healing and do not re-inject deleted to-kens, as our survey confirms; the channel we study arises instead from retained-handle reuse across a logical abort. Beyond reuse, a recent line makes mutable inference state an explicit problem. Fuzzing surfaces stale-KV contamination caused by serving bugs (Zhao et al., 2026), whereas our reuse is legitimate and becomes unauthorized only after a rollback changes which history is authori-tative. Leyline exposes policy-directed cache mutation for agentic edits (Ma et al., 2026); KVEraser learns localized steering that approximates a context in which a span never appeared (Li et al., 2026); 

Models Take Notes shows causally that editing a source span can fail because its influence has prop-agated into downstream cached “notes” (Li, 2026); sparse event-KV work names the dual effect, 

semantic materialization (Cai & Cai, 2026); and auditable deletion separates behavioral suppres-sion from restoration to a record-omitted state (Ramesh, 2026). All of these assume an edit has been 

identified and study how to realize it. We ask the complementary question: does a rollback already believed complete compose with the retained state? Our rollback removes a tentative suffix back to a committed boundary, where exact truncate/checkpoint restoration is available (interior-span era-sure preserving a later suffix is the harder problem those methods target), and cache editing is one realization of our C3 restore. 

Rollback, checkpoint/restore, and recoverability. Agent rollback is inherently cross-layer .Checkpoint/restore for agent sandboxes shows that restoring conversational state does not restore OS-side execution state (Wu et al., 2026); semantic recoverability asks whether a legal rollback tar-get remains valid after downstream commitment (Yang et al., 2026); execution-state capsules make snapshot/restore/rollback of inference state a first-class serving operation (Su, 2026); and version-controlled agent memory offers semantic rollback of logical state (Su et al., 2026). We assume a correct logical rollback to a valid target and show that the inference state the model attends is still not restored – rollback need not restore OS state, and it need not restore attended KV either. An execution-state capsule is precisely a substrate that could satisfy our Layer-1 invariant; we define the property such a substrate must meet and exhibit its violation under a first-class rollback API. 

Side channels, persistent carriers, and unsafe retention. Prior side-channel work extracts train-ing data or user prompts and studies cache-timing leakage (Carlini et al., 2021; Yona et al., 2024); we audit a control-flow channel – a rejected branch changing a typed protected effect – with a token-matched paired estimand, sharing the controlled-cache-intervention style of causal KV audits in multi-agent relaying (Cheng et al., 2026). Our failure is a persistent carrier moving attacker influ-ence to a later benign trigger (Zhang et al., 2026), with serving-layer attended KV as the carrier, 9Preprint. Under review. and it mirrors Governance Decay (Chen, 2026): there, compaction unsafely forgets constraints that should persist; here, the system unsafely retains content that should have been forgotten. 

## 6 DISCUSSION AND LIMITATIONS 

“Isn’t this just prompt injection?” No: the residue carries no override instruction (it fires under neutral residue, 7/21 ), was believed-deleted, and is absent from the served request ; the token- and length/position-matched controls attribute the flip to the deleted attacker semantics in retained KV (25 /25 → 0/25 ). “A resistant model exists, so who cares?” Resistance is a behavioral margin that can erode with the next prompt or fine-tune, whereas the Layer-1 attended-state integrity vi-olation (§3.4) holds on every model. Limitations and future work. The exposed pattern is the retained handle: beyond DynamicCache , the session app, and the framework default path, Lang-Graph’s checkpointer/time-travel reproduces it ( 25 /45 ; §3.3), whereas the throughput serving layer (vLLM, SGLang) is content-addressed and self-healing and provider-hidden commercial internals remain UNKNOWN (Appendix M). The channel persists under sampling ( ≈ 99% stale, 0% fresh; Appendix L) and across five effects and four policy structures ( 128 /180 ; Appendix K). A full multi-model stochastic rate study, RBAC/human-in-the-loop policies, hybrid-Mamba and Mistral caches, structured defenses beyond a prompt guard (provenance, branch-scoped KV, capability gating), and a cross-engine rewind-vs-re-prefill benchmark are future work. 

## 7 CONCLUSION 

A believed-complete abort must restore the state the model attends , not just the transcript: a ses-sion that retains KV still holds the rejected branch the transcript forgot and keeps acting on it. We formalize this as rollback consistency (a two-layer property with a cross-layer composition condi-tion, Appendix A), expose its violation with a same-token / different-cache audit, and close it with a cheap transaction-local restore that holds even under a first-class rollback API. ## A FORMALIZATION : A TWO -LAYER ROLLBACK PROPERTY AND A COMPOSITION CONDITION 

This appendix makes the property of §2 precise. We deliberately split it into two layers so that a single definition does not have to carry both a physical state guarantee and an observable security-behavior guarantee, and so that the finite audit is credited with exactly what it establishes (a causal 

witness of violation) and no more (it does not certify a universally quantified equality). The two layers also give the resistant models a precise status: they violate the state-level layer on every model, while only some models witness a violation at the effect level. 

State and effect. Model a session at a decision step as a pair (L, K), where L is the committed 

logical transcript the application can inspect and K is the physical attended state (the KV) the model conditions on. Fix the model and greedy decoding, and let f (K, x ) ∈ E be the typed protected effect (for example the delivered recipient) produced when the served decision input is x. Let κ(L)

be the attended state a cold pass re-derives from L alone. An abort takes a session that explored a rejected branch b from a committed transcript L⋆ to a post-abort state (L′, K′). Let X denote the 

protected-decision domain : the (application-defined) set of served decision inputs at which a typed protected effect is emitted, and D ⊆ X the finite subset the audit actually exercises. 

Layer 1: attended-state rollback integrity (a systems invariant). Definition 1 (Attended-state rollback integrity) . A post-abort state (L′, K′) has attended-state roll-back integrity if its attended state is re-derivable from the committed transcript, written K′ ≡state 

κ(L⋆): the state the model attends after the abort is the state a cold pass over L⋆ would produce. 

This is a structural invariant on K; it says nothing about any model’s behavior. A retained-handle serving layer advances the existing KV by the new-turn delta, K′ = advance( Kb, δ ) where Kb

already encodes b, so K′̸ ≡state κ(L⋆): the invariant is violated identically on every model , which is exactly what the isolation invariants report ( 63 /63 carrier-present-in-cache, 63 /63 carrier-absent-from-fed-tokens). A content-addressed layer re-derives K′ = κ(L′) and, when L′ = L⋆, satisfies the invariant by construction. 

Layer 2: effect-level rollback consistency (an observational security property). Definition 2 (Effect-level rollback consistency) . An abort is effect-level rollback-consistent over X

if f (K′, x ) = f  κ(L⋆), x  for every x ∈ X; that is, the post-abort typed effect equals that of a cold restart from the committed transcript on the whole protected-decision domain. 

13 Preprint. Under review. The equality is observational (over the typed-effect map f ), not bitwise identity of KV tensors. A violation is a security violation (a typed protected effect flips). 

The two layers are ordered, and the order is strict. Proposition 1 (Integrity implies effect consistency) . If (L′, K′) has attended-state rollback integrity (K′ ≡state κ(L⋆)), then the abort is effect-level rollback-consistent over all of X.Proof. K′ ≡state κ(L⋆) makes the attended state fed to f equal in the two arms for every x, so 

f (K′, x ) = f (κ(L⋆), x ) for all x ∈ X by definition of f .

Proposition 2 (The converse fails) . Effect-level rollback consistency on a finite tested set D ⊆

X does not imply attended-state rollback integrity: there exist (L′, K′) with K′̸ ≡state κ(L⋆) yet 

f (K′, x ) = f (κ(L⋆), x ) for all x ∈ D.Proof. The resistant families (DeepSeek-R1-Distill-8B, Phi-4, Seed-OSS-36B) are empirical wit-nesses: the retained handle gives K′̸ ≡state κ(L⋆) (Layer 1 violated, verified per cell), yet f agrees across the stale and fresh /cold arms on every audited cell, so no Layer-2 disagreement is witnessed on D.

What the audit does, precisely. The same-token / different-cache audit holds x token-identical across arms and compares f (K′, x ) (the stale arm) against f (κ(L⋆), x ) (the fresh and cold arms) over x ∈ D. It therefore tests effect-level rollback consistency and, whenever an arm disagrees, produces a causal witness of a Layer-2 violation (causal because the fed tokens are identical and the carrier is absent, so the only difference is the cache). What it cannot do is certify the universally quantified Definition 2: passing on a finite D is evidence, not a proof over all of X. By contrast, the audit’s isolation invariants do certify the Layer-1 violation directly, because K′̸ ≡state κ(L⋆) is a checkable property of the constructed cache rather than a quantifier over inputs. 

Composition. Deployed agents compose a logical-rollback layer R (a checkpointer, say), which guarantees L′ = L⋆, with a serving layer S that maintains K.

Proposition 3 (Composition condition, Layer 1) . Let R guarantee L′ = L⋆. The composition 

R ◦ S has attended-state rollback integrity if and only if the serving layer re-derives its post-abort attended state from the committed transcript, i.e. K′ = κ(L⋆). By Proposition 1 this is sufficient for effect-level rollback consistency over all of X.Proof. Immediate from Definition 1 with L′ = L⋆: integrity is exactly K′ ≡state κ(L⋆), and a retained handle with K′ = advance( Kb, δ ) violates it while a re-derivation K′ = κ(L′) = κ(L⋆)

meets it. Sufficiency for Layer 2 is Proposition 1. 

Consequences. (i) Rollback integrity is a cross-layer property: it constrains K, not L, so a logical-rollback guarantee ( L′ = L⋆) is necessary but not sufficient. This is precisely the LangGraph reproduction (§3.3), where R is correct yet R ◦ S violates Layer 1, which is why we call it a compositional gap and not a defect of either layer. (ii) The sufficient condition K′ = κ(L′) is what a transaction-local restore (C3, §4) installs, and any of its three realizations (rebuild, truncate, checkpoint) meets it. (iii) A content-addressed serving cache satisfies K′ = κ(L′) by construction, which is the formal reason the survey (Appendix M) labels vLLM and SGLang self-healing while retained-handle reuse is exposed. (iv) The resistant models are not a counterexample to our claim but an instance of Proposition 2: they violate the model-independent Layer-1 invariant, and only fail to witness a Layer-2 violation on the tested cells, which is why a state-level fix rather than a behavioral margin is the robust remedy.

## F END -TO -END SESSION -AGENT PROTOCOL 

The end-to-end app ( stale session handle app.py ) exposes a session keyed by a handle and mirrors KV-reusing stateful serving:            

> begin(sid, system, task) : prefill the committed prefix into the session KV.
> explore(sid, vehicle) : advance the session KV with the untrusted branch delta,
> without committing it to the logical transcript.
> abort(sid, mode) :buggy retain drops the branch from the transcript but keeps the KV handle; fresh cache re-prefills the committed prefix and rebinds the session KV (the C3 fix).
> decide(sid) : append the finalize turn computed from the logical (committed) view onto the current session KV.

Because decide builds the request from the logical transcript, the served request provably ex-cludes the attacker ( 63 /63 ), and the finalize delta is token-identical across buggy retain and 

fresh cache (63 /63 ). The per-model buggy-abort flip counts match the tensor-level probe ex-actly ( 9, 9, 6, 1, 0, 0, 0). 

## G DETERMINISM AND THE CENSUS ESTIMAND 

Every decode is greedy (temperature 0), so for a fixed (model, vehicle, strength, arm, cache-state) the outcome is deterministic. We therefore report an exact census over the 7×3×3 grid and do not attach confidence intervals to deterministic decodes: there is no sampling distribution to summarize. The causal content of the result is carried by the token-matched design (carrier absent 63 /63 ; decision tokens identical 63 /63 ; stale =text-present 63 /63 ), not by a p-value. ## M HOW PREVALENT IS THE RETAINED HANDLE ? A SURVEY OF DEFAULT CACHE BEHAVIOUR 

The channel requires that the serving state advance across a logical abort by a retained handle rather than being re-derived from the committed request. Whether this happens is a property of the stack’s 

default behaviour, so it is a question of prevalence, not just of possibility. We separate three mecha-nism classes and then place named, widely used stacks into them from their public documentation. 

(a) Content-addressed / re-derived (self-healing): the cache is keyed by the tokens of the incom-ing request, so reuse is limited to prefixes actually present in that request. A deleted branch cannot be re-injected: if the committed request no longer contains it, its KV is not referenced, even if the physical blocks still linger. (b) Retained-handle advanced by delta (exposed): the application or engine keeps a session’s past key values (or a session-keyed cache) and feeds only the new turn’s tokens on top of it for latency; a logical abort that does not explicitly restore the cache leaves the aborted branch attended. This is the case we study. (c) First-class logical rollback with no KV contract (exposed when composed): an orchestration runtime persists and rewinds logical state (message channels) but has no notion of the serving KV; composed with a (b)-style backend, its advertised rollback restores the transcript while the KV stays stale. We reproduce exactly this on LangGraph (§3.3). The finding is that the throughput-oriented serving layer defaults to content-addressed reuse and is self-healing, whereas the exposed pattern lives in the stateful appli-cation / orchestration layer – precisely where agents keep the rollback abstraction.
