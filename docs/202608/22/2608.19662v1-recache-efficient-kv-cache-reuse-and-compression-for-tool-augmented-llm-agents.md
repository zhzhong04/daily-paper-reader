## 摘要
智能体语言模型会反复编码跨请求以不同组合和顺序出现的工具与技能模式，这阻碍了标准前缀缓存对其键值（KV）状态的重用。我们提出了ReCache框架，该框架可独立缓存资源表示，同时降低其推理时的计算和内存开销。资源级注意力消除了跨资源交互并分配资源局部位置，从而生成组合不变的KV块。随后，ReCache将资源可见性限制在贡献选择的层-KV头组路由上，并通过结构和语义剪枝仅保留调用关键字段。我们在由七个公共工具和技能使用数据集（包括资源不相交测试）组成的基准上评估了ReCache。资源级注意力在提供3.655倍首令牌时间加速的同时，与密集调用性能相匹配（82.3%对比82.4%的Inv-F1）。完整框架将分配的KV张量内存减少了92.43%，并将注意力加速了1.423倍。这些结果表明，将可重用模式编码与选择性资源访问分离，能在有限的有效性损失下大幅降低智能体推理成本。代码可在https://github.com/EIT-NLP/ReCache获取。

## Abstract
Agentic language models repeatedly encode tool and skill schemas that recur across requests in different combinations and orders, preventing standard prefix caching from reusing their key--value (KV) states. We introduce \textbf{ReCache}, a framework for independently caching resource representations while reducing their inference-time computational and memory overhead. Resource-wise attention removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks. ReCache then restricts resource visibility to contribution-selected layer--KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. We evaluate ReCache on a benchmark assembled from seven public tool- and skill-use datasets, including resource-disjoint tests. Resource-wise attention matches dense invocation performance (82.3\% versus 82.4\% Inv-F1) while providing a 3.655$\times$ time-to-first-token speedup. The complete framework reduces allocated KV-tensor memory by 92.43\% and accelerates attention by 1.423$\times$. These results show that separating reusable schema encoding from selective resource access substantially reduces agentic inference costs with limited effectiveness loss. The code is available at https://github.com/EIT-NLP/ReCache.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在工具增强的LLM智能体（Tool-Augmented LLM Agents）中，系统需要频繁调用外部工具和技能（论文中统称为“资源”）。这些资源模式（schemas）会以**不同的组合和顺序**反复出现在用户请求中，导致模型对相同信息进行**重复的 prefill 计算**，造成显著的推理延迟和内存开销。
- **现有方法的局限**：标准的 KV 缓存复用（如前缀缓存）要求内容形成**完全一致的前缀**，而这在动态组合资源的场景下几乎不成立。已有的位置无关缓存方法（如EPIC、CacheBlend、KVLink等）往往需要位置修正或选择性重算，开销较大且效果受限。
- **核心动机**：论文通过实证观察发现，模型在资源调用任务中**资源内部的自注意力显著强于跨资源的注意力**（见图1a），且后续对话token的注意力主要集中于资源的**后缀token**（见图1b）。这表明，在资源调用场景中，**保留资源内部语义比保留全局资源顺序更重要**，为解耦资源表示提供了基础。

## 二、论文提出的方法论

论文提出了 **ReCache** 框架，该框架由三个渐进式阶段组成，旨在实现资源的独立缓存、选择性访问与压缩：

1.  **资源级注意力（Resource-wise Attention）**
    - **核心思想**：消除不同资源块之间的注意力交互，并在每个资源内部**从零开始重置位置索引**（即 `pos(t_{i,j}) = j`）。
    - **作用**：这使得每个资源（Ri）的 KV 状态表示变得**与组合无关（composition-invariant）**，可以独立构建和缓存，不受其他资源或全局位置的影响。注意力计算复杂度从 O(D_R²) 降至 O(ΣD_i²)。
    - **实现**：通过修改注意力掩码（去除跨资源链接）和位置编码（资源局部位置）来实现，并通过轻量级微调使模型适应新模式。

2.  **结构性剪枝（Structural Pruning）**
    - **核心思想**：不同 Transformer 层和 KV 头组对资源调用的贡献不均。ReCache 将资源 KV 状态的可见性限制在少数“关键”的层-头组（Layer-KV-head-group）路由上。
    - **关键技术：贡献度选择（Contribution-based Selection）**：使用 **leave-one-in** 策略，而非逐层剪枝，来评估每个组件（层或头组）对**调用损失（Invocation Loss）**的边际贡献。具体地，定义 `ℓΩ(X, Y)` 为在路由配置 Ω 下目标响应 Y 的平均负对数似然，通过计算 `s_l = J(∅) - J(Ω_l)` 得到层贡献，同理得到头组贡献。然后归一化为权重 w_i，并据此选出最高权重的前 K 个层（L*）和头组（G*）。
    - **结果**：最终的路由配置为 Ω* = L* × G*。在推理时，仅有这些选中的路由可以访问资源 KV 状态（使用 M_resource 掩码），其余路由则使用 M_context 掩码彻底屏蔽资源 token。

3.  **语义性剪枝（Semantic Pruning）**
    - **核心思想**：工具和技能模式包含结构化的关键信息（如资源ID、参数名、约束条件），这些信息的准确性直接决定调用成败，而冗长的描述性文本贡献度低。
    - **关键技术：字段感知压缩（Field-aware Compression）**：对于每个资源，系统性地保留三类关键字段——**资源名（resource name）、参数名（argument name）和参数描述（argument description）**。此外，还保留资源的**最后一个token（suffix token）**，作为聚合了内部信息的自然语义锚点，与基于摘要的压缩方法（如Gist）类似，但无需额外学习摘要token。

## 六、论文的主要结论与发现

1.  **资源级注意力有效**：与 Dense 推理相比，资源级注意力（Ω_full）在 Inv-F1 上仅下降 0.1%（82.3% vs 82.4%），但 TTFT 实现了 **3.655倍** 加速。这表明跨资源交互和全局位置信息在工具调用任务中并非必需。
2.  **贡献度选择更优**：在匹配的结构预算下，基于贡献度的选择（Ω20,3）在 T_IND 和 T_OOD 上的 Inv-F1 均显著优于基于注意力的选择（SA20,3），且 OOD 上的幻觉率从 5.1% 大幅降至 0.5%。
3.  **字段感知剪枝的关键性**：通用摘要压缩（Gist）完全失效（Inv-F1 仅 39.2%），而字段感知的剪枝策略（保留名称、参数等）能保留大部分性能（81.6%），证明结构化信息对工具调用的不可替代性。
4.  **完整框架效果**：ReCache 在保持较高调用性能（T_IND 80.3%，T_OOD 60.8%）的同时，削减了 **92.43%** 的 KV 内存，并实现了 **1.423倍** 的注意力加速。
5.  **效率随规模扩展稳定**：随着资源长度（D_R）增长，ReCache 的 TTFT、TPOT 和注意力延迟几乎保持恒定，KV 内存占用被限制在 0.03 GiB 以下，而 Dense 方式接近 8 GiB。

## 七、优点

- **问题洞察深刻**：精准指出了前缀缓存在动态资源组合场景下的根本缺陷，并通过注意力分析提供了坚实的实证基础。
- **方法设计优雅**：三个阶段的剪枝（组合级→路由级→字段级）从粗到细，系统地解决了资源表示冗余的不同维度，逻辑清晰且相互配合。
- **贡献度量机制新颖有效**：采用 leave-one-in 的损失贡献度作为结构性剪枝依据，比常见的注意力质量或启发式规则更直接地服务于任务目标，且实验证明其泛化性更好。
- **数据集构建严谨**：针对多数据集拼接可能带来的数据污染、频率偏差等问题，设计了多样性优先采样和严谨的 OOD 划分，提升了评估的可靠性。
- **效率-效果权衡清晰**：通过在不同维度（TTFT, TPOT, Attn., Mem.）和不同资源规模下的详细评估，清晰地展示了方法的效率优势及其与效果之间的权衡关系。

## 八、不足与局限

- **模型和规模覆盖有限**：端到端实验仅在 Qwen3 家族的两个模型（4B和1.7B）上进行，特别是完整实验仅在 4B 模型上开展。对更大模型或不同架构（如非 GQA）的泛化性尚不明朗，这主要是因为全参数微调的计算成本过高。
- **需要微调（Trainable Setting）**：方法依赖对注意力掩码和位置布局的修改，因此不适用于冻结模型的零样本/少样本场景，适用范围受限。
- **场景假设约束**：方法假设系统指令和资源模式相对稳定，且资源顺序和跨资源依赖对任务重要性低。在高度动态、资源间存在关键依赖或顺序敏感的环境中，ReCache 的效果可能打折。
- **与最新基线对比不全面**：在语义剪枝部分，未与当前 SOTA 的一些长上下文压缩方法（如 LLMLingua 系列的后续工作或有学习的压缩方法）进行比较，可能会影响对语义性剪枝策略优越性的评估。
