## 摘要
记忆增强型智能体在长对话中维护紧凑的用户画像，从而无需处理全部对话历史即可生成个性化且一致的响应。这些用户画质的质量取决于底层记忆管理策略：在每一步，智能体必须决定保留、压缩或丢弃哪些内容。然而，现有方法通常采用训练前设定的静态、一刀切策略。实际上，最优的记忆决策本质上是用户特定的，并随着策略优化而动态演变。为解决这一问题，我们提出\textbf{HiPS}（\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy，层级个性化策略），一种将记忆管理解耦为全局共享基础与用户特定自适应层的框架。具体而言，HiPS采用\textbf{通用策略}从跨人格轨迹中提取共享原则，同时通过\textbf{人格差异蒸馏}为行为偏离一般模式的用户生成定制规则。\textbf{跨层级规则流}通过提升广泛验证的个性化规则和降级冲突的全局规则来动态校准其边界。该架构建立了一个协同进化循环，其中一种机制保证所有策略改进均锚定于任务结果。大量实验证明，相较于记忆增强基线，该方法取得了一致的性能提升。

## Abstract
Memory-augmented agents maintain compact user profiles throughout extended conversations, enabling personalized and consistent responses without the need to process the entire dialogue history. The quality of these user profiles relies on the underlying memory management strategy: at each step, the agent must determine what to retain, compress, or discard. However, existing methods typically employ a static, one-size-fits-all strategy established before training. In practice, the optimal memory decision is inherently user-specific and dynamically evolves alongside policy optimization. To address this, we propose \textbf{HiPS} (\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy), a framework that decouples memory management into a globally shared foundation and a user-specific adaptive tier. Specifically, HiPS employs \textbf{Universal Strategy} to extract shared principles from cross-persona trajectories, alongside \textbf{Persona Delta Distillation} to generate tailored rules for users whose behaviors diverge from general patterns. \textbf{Cross-Level Rule Flow} dynamically calibrates their boundary by promoting broadly validated personal rules and demoting contradicted global ones. The architecture establishes a co-evolution loop where a mechanism guarantees that all strategy refinements are anchored to task outcomes. Extensive experiments demonstrate consistent improvements over memory-augmented baselines.

- **现有方法的两个根本缺陷**：

## 2. 方法论：HiPS 框架

### 2.1 核心思想

将记忆管理策略解耦为两个层级，形式化表示为：

**Sₚ = Sᵤ ∪ ∆ₚ**

- **Sᵤ（Universal Strategy）**：全局共享的通用规则，适用于全体用户；
- **∆ₚ（Persona Delta）**：针对行为偏离总体规律的用户生成的个性化自适应规则。

该分解不是预先固定的，而是在训练过程中与策略协同进化。

### 2.2 三大核心机制

**（1）通用策略蒸馏（USD, Universal Strategy Distillation）**

- 在训练间隔中，采样"人物均衡"的 top-k 与 bottom-k 轨迹（按奖励排序），由 LLM 元优化器进行对比分析；
- 输出**结构化差异（structured diff）**：δ_USD = {V: 验证, H: 假设, R: 修订/淘汰}，而非自由文本反馈，从而支持逐规则的细粒度更新；
- 新规则必须遵循"[标签]：当[条件]时，[动作]"格式，且只描述管理行为；
- **证据追踪机制**：每条规则具有证据等级（tentative → supported → established），由验证信号迭代更新；并辅以数据驱动的自动升降级（预测增益超过 θ_val 自动晋升，低于 θ_rev 自动降级）。

**（2）人格差异蒸馏（PDD, Persona Delta Distillation）**

- **分歧门控（Divergence Gating）**：定义规则 r 的预测增益 PG(r) = P(Y=1|r⁺) − P(Y=1|r⁻)（r⁺/r⁻ 表示遵从/不遵从该规则的轨迹）；用户 p 的分歧度 Dₚ = Σ|PG(r|p) − PG(r)|。仅当 Dₚ ≥ θ_div 时才触发个性化，避免为已被通用规则充分覆盖的用户浪费计算资源，同时解决冷启动问题；
- **行为条件化蒸馏**：生成的个性化规则必须（a）是管理导向的"动作"而非事实陈述；（b）以可观测行为模式为条件而非用户身份或领域名，从而在推理时可泛化到未见用户。

**（3）跨层级规则流（Cross-Level Rule Flow）**

- **泛化（∆ₚ → Sᵤ）**：当某条个性化规则在 ≥ θ_flow 比例的有∆ₚ用户中被验证，则晋升为通用规则，并从个体中剪除（以语义相似度匹配近似规则）；
- **特化（Sᵤ → ∆ₚ）**：当通用规则被修订或降级时，PDD 为原本受益于该规则的用户生成本地化替代规则，防止一刀切修订损害少数用户。

### 2.3 策略注入与协同进化

- **子模选择**：在 token 预算 B 约束下，贪心最大化带冗余惩罚的覆盖率目标（公式 6），按预测增益分配两个层级的预算比例；
- **对齐奖励**：R_follow(τ,p) = Σ PG(r)·h(τ,r) / Σ PG(r)，与任务奖励组合为 GRPO 优化目标 R = R_ans + λ·R_follow；
- **防循环设计（Anti-circularity）**：策略蒸馏缓冲区仅按任务奖励 R_ans 排序，R_follow 仅用于 GRPO 优势计算，防止规则自我验证的确认偏误。

## 7. 局限性与未解决问题

尽管 HiPS 在实验上表现优异，论文仍存在以下值得注意的局限：

- **训练数据规模偏小**：全部训练仅依赖 423 条实例（采样自 PersonaMem 32K 子集的 70%）。虽然这不影响策略蒸馏的有效性验证，但对于记忆管理这类高度依赖多样性场景的任务，小样本训练的规则库能否覆盖真实世界中用户行为的全部分布，仍是一个开放问题；
- **规则遵从度估计依赖关键词匹配**：论文通过检查轨迹中是否出现规则中的动作关键词来估计 h(τ,r)，这一近似方法在语义等价表达（paraphrase）或隐式执行场景下可能产生误判。尽管作者论证了相对排序的鲁棒性，但在规则库规模扩大后，误判累积效应可能放大；
- **蒸馏 LLM 的隐形成本**：HiPS 依赖 LLM 元优化器进行对比分析、规则生成与修订。论文虽报告了推理端（4K 分块检索、MiniLM 嵌入）的开销，但未量化蒸馏过程的 token 消耗与 API 调用成本，这在工业部署中可能成为主要瓶颈；
- **基准的生态位偏窄**：四个基准均以英文对话与偏好追踪为主，缺乏对多语言、多模态或工具调用场景的覆盖；PersonaMem 的 20 个模拟人格本质上仍是合成数据，与真实用户画像之间存在差距；
- **GRPO 与规则奖励的耦合仍有手工痕迹**：虽然防循环设计避免了确认偏误，但 λ（规则奖励权重）、θ_val、θ_rev、θ_div、θ_flow 等多个阈值均需人工设定，系统的自适应程度仍有限。

## 8. 论文贡献总结与个人评价

### 8.1 主要贡献

1. **问题定义层面**：首次将 LLM 记忆管理策略建模为"通用规则 + 用户特定增量"的层级结构，并明确提出在线轨迹证据驱动的协同进化范式，突破了静态记忆工作流的局限；
2. **方法论层面**：设计了三个环环相扣的机制——USD 负责全局规则蒸馏与证据维护，PDD 负责基于分歧门控的个性化规则生成，Cross-Level Rule Flow 负责层级间的动态迁移，形成了一个自我修正、自我扩展的闭环系统；
3. **实证层面**：在 4 个基准、12 种设置中全面领先，并提供了 30 组消融、跨 4 骨干的迁移实验与 8 超参数扫描，证据链较为完整；
4. **工程层面**：规则以结构化文本"标签 + 条件 + 动作"形式存储，天然具备可解释性、可编辑性与跨模型可移植性，为记忆系统的安全审计与人工干预提供了便利。

### 8.2 总体评价

- **创新性（高）**：将策略蒸馏的粒度从"整段文本"细化到"逐条规则"，并引入证据等级与双向流动，在记忆管理领域属于较新颖的尝试；
- **严密性（较高）**：防循环设计、人物均衡采样、语义去重与门控触发条件等细节处理体现了方法设计的严谨性；
- **可复现性（中高）**：训练集规模小、开源基准与公开 checkpoint 使复现门槛相对较低，但蒸馏 LLM 的选择与多阈值设定仍需依赖论文补充细节；
- **实用性（中等）**：推理端效率可控，但训练端的蒸馏调用开销与多超参数调优在一定程度上限制了其开箱即用的程度。

整体而言，HiPS 在"记忆管理策略应当随交互动态演化"这一方向上给出了一个系统化、模块化且实验充分的解决方案，其"全局共享 + 个性化增量 + 跨层流动"的三元设计对于更广泛的 agent 记忆、工具使用策略乃至人格对齐问题都具有借鉴意义。
