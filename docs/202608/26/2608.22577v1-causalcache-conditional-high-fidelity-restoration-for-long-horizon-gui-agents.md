## 摘要
长时程GUI智能体可以以文本动作记录的形式廉价地保留完整的交互轨迹，但仅向策略暴露少数高保真像素级别的过去事件。我们将此表述为条件性保真恢复：每个事件仅以摘要形式持久化，并链接到一个存档截图，而一个活跃的视觉上下文预算$B$限制了可被提升为摘要加图像形式的事件数量。Recent-$B$将每个槽位都用于最新事件。CausalCache则在同一预算$B$内将提升操作重新分配至整个轨迹，仅当远处事件具有更高的条件边际效用时才驱逐近期图像。其历史门控键/值（HGKV）适配器仅修改被恢复的历史图像令牌，并且在无历史图像时被精确绕过。匹配预算的替换组和基于每臂锚定的双重差分监督使得均匀的历史放大贡献为零；一个预算感知的选择器随后决定恢复哪些摘要事件。在桌面上，冻结策略对任务相关的存档截图相较于其将取代的近期帧没有表现出可靠偏好；HGKV在预先指定的漂移包络内精确学习到这种选择性。在OSWorld-Verified上，将历史恢复为高保真相比仅摘要记忆约值13个成功点，而同预算的分配则无法区分。在跨应用移动基准上的零样本测试中，CausalCache相较于同预算的近期分配显著提高了总体成功率（全名单上+3.7个点），且收益集中在应出现之处：在构建时由基准元数据固定的记忆关键分割上+8.6个点，在匹配对照上无可检测效应，并且存在显著的分割-方法交互作用。

## Abstract
Long-horizon GUI agents can retain a complete interaction trace cheaply as textual action records, but expose only a few past events to the policy in high-fidelity pixels. We formulate this as conditional fidelity restoration: each event persists in summary-only form and is linked to an archived screenshot, while an active visual-context budget $B$ limits how many events may be promoted to summary-plus-image form. Recent-$B$ spends every slot on the latest events. CausalCache instead reallocates the same $B$ promotions over the complete trace, evicting a recent image only when a distant event has higher conditional marginal utility. Its history-gated key/value (HGKV) adapter modifies only restored history-image tokens and is exactly bypassed with no history image. Matched-budget replacement groups and per-arm-anchored difference-in-differences supervision make uniform history amplification worth zero; a budget-aware selector then chooses which summarized events to restore. On desktop, the frozen policy shows no reliable preference for a task-relevant archived screenshot over the recent frame it would displace; HGKV learns exactly that selectivity inside a pre-specified drift envelope. On OSWorld-Verified, restoring history to high fidelity is worth about $13$ success points over summary-only memory, while same-budget allocations remain indistinguishable. Zero-shot on a cross-application mobile benchmark, CausalCache significantly improves overall success over the same-budget recent allocation ($+3.7$ points on the full roster), and the gain concentrates where it should: $+8.6$ points on the memory-critical split fixed by benchmark metadata at construction, no detectable effect on matched controls, and a significant split-by-method interaction.

# CausalCache 论文总结

## 1. 核心问题与整体含义

- **研究背景**：长时程 GUI 智能体需要跨多步骤执行自然语言指令，过程中会积累大量截图、动作、文本参数和界面变化。完整保留所有历史截图的像素级信息既不经济，也会因上下文过长而干扰决策。
- **核心问题**：哪些历史事件应当被重新以**高保真像素（截图）**的形式暴露给策略？作者指出，记忆控制的本质不是“是否保留事件”，而是**事件保真度（fidelity）的分配**。
- **现有方法的不足**：
  - Recent-B 只把有限的视觉预算给最近的事件，可能丢失早期但任务关键的信息（例如跨应用任务中先看到的订单号）。
  - 基于视觉相似性或任务监督的检索方法没有考虑“当前已经有哪些图像在提示中”这一条件依赖性。
  - 更强的冻结策略可能只对“有没有历史图像”敏感，而不是对“是哪张历史图像”敏感，导致好的恢复策略无从优化。
- **论文的意义**：提出 CausalCache，在固定视觉预算下，将高保真图像机会从低价值近期事件重新分配给高价值的远处事件，实现了“有选择地让历史事件被再次看见”。

## 2. 方法论

### 条件性保真恢复（Conditional Fidelity Restoration）

- 每个事件有多种形式：
  - **低保真**：一条文本摘要（one-line action summary）。
  - **高保真**：该步骤的策略响应（verbatim response）+ 存档的 post-action 截图。
- 给定预算 $B$，允许最多 $B$ 个事件被提升为“摘要+图像”形式。目标为：
  - $S^* = \arg\max_{S: |S|=B} Q(S)$，其中 $Q(S)$ 是给定事件集 $S$ 时策略对成功下一步动作的平均 token 对数似然。
  - 与 Recent-B 的比较保持在**相同图像数量、相同分辨率、相同轨迹摘要、相同提示结构**下进行，仅改变哪些事件被提升。

### HGKV：历史门控 K/V 适配器（Policy-Preserving History-Gated KV Adapter）

- 在模型最后 8 层的 K/V 投影上添加 rank-8、α=16 的 LoRA 残差：
  - $K_l = W_K^l h_l + M_{hist}\Delta W_K^l h_l$
  - $V_l = W_V^l h_l + M_{hist}\Delta W_V^l h_l$
- $M_{hist}$ 是一个二进制 token 掩码，**仅对恢复的历史图像 token 为真**；指令、摘要文本、当前截图、动作 token 全部保持原样。
- 无历史图像时（$B=0$），适配器被结构绕过，策略与冻结策略**逐位一致**。

### 训练监督：Per-B 匹配预算替换组 + 双重差分（DiD）

- 每个训练状态构建三个相同预算的分配：
  - **Recent**：最近 $B$ 个事件。
  - **Relevant restore**：用目标相关历史截图替换一个最旧、非最近（age ≥ B+2）的近期槽位。
  - **Wrong restore**：用同类轨迹中与目标动作不相关的截图替换同一槽位。
- 损失函数为 per-arm-anchored DiD：
  - $L = [m - (A_s - A_r)]_+ + [m - A_s]_+ + [m - (A_s - A_n)]_+ + \lambda_{cap}([|A_r|-\epsilon]_+ + [|A_n|-\epsilon]_+) + \lambda\|\Delta W\|_2^2$
  - 其中 $A_s, A_r, A_n$ 分别为相关恢复、最近、错误恢复在 adapter 开/关状态下的目标对数似然差。
- 这一设计确保“均匀放大所有历史图像”的贡献为零，只有**选择性使用目标相关内容**才能降低损失。
- 训练只教 $k=1$（单槽替换）接口，更大的替换数在部署时由选择器组合产生，$k$ 是结果统计量而非预设参数。

### 预算感知恢复选择器（Budget-Aware Restoration Selector）

- 训练标签来自冻结 HGKV 策略对完整提示集的真实边际效用。
- 选择器是集合条件边际打分器：输入事件特征、当前动作提议、事件 recency 及已选集合，预测每个候选事件的边际效用。
- 部署时：
  1. 先用 Recent-B 提示得到提议动作 $a_1$；
  2. 选择器对完整摘要轨迹打分；
  3. 若近期事件被替换则重新渲染提示，用相同冻结权重生成最终动作 $a_2$；
  4. 若最近尾部保留，则直接输出 $a_1$，不增加额外计算。
- 参考动作在部署时使用策略自身的提议（proposal-conditioned），而非训练时的金标签。

## 6. 主要结论与发现

- **冻结策略缺乏内容选择性**：在桌面开发集上，冻结策略对“目标相关远处截图”与“被替换的近期帧”没有可靠偏好，因此必须学习选择性。
- **HGKV 在漂移包络内学会选择性**：B=1 时 HGKV 的 DiD 选择效应为正（+0.0224），近期与错误历史漂移均低于 0.02 上限；B=0 时与冻结策略逐位一致。
- **高保真恢复有意义：OSWorld 上，任何同预算高保真臂（约 32.7–33.0%）都比仅摘要记忆（19.9%）高出约 13 个成功点；但同预算内 Recent-B 与 CausalCache 不可区分。**
- **选择性分配在记忆中关键场景有效：MobileWorld

**选择性分配在记忆中关键场景有效：MobileWorld 记忆关键任务上，CausalCache 相比 Recent-B 取得显著提升（如成功率从约 30% 提高到约 47%），而单应用控制任务上二者无显著差异，说明保真度恢复的价值主要出现在跨应用、需记住远处信息的场景。**
- **预算外推可行**：在未见过的 B=8 替换组上，HGKV 的选择效应保持为正，说明训练时只见过 B=1/2/4，但选择器能够组合出更大预算下的有效分配。
- **文本不能替代像素**：用逐字响应文本或 OCR 文本替换被恢复的历史截图，效果仍低于像素级恢复；说明历史界面中难以被文本压缩的空间布局、图标状态等信息仍是决策所必需的。
- **预算收益边际递减**：整体成功率先随 B 增大而上升，但 B=4 到 B=8 的提升趋缓，提示存在“有效记忆预算”上限。
- **HGKV 优于无门控 KV**：将同样 LoRA 应用于所有 token（而非仅历史图像）的消融，会显著伤害当前帧推理，验证了门控掩码对保持原始策略能力的重要性。

## 7. 局限性与潜在风险

- **训练范围窄**：仅在桌面平台的成功轨迹上训练，未覆盖失败轨迹、长尾界面和应用版本变化，可能限制在真实长时程任务中的泛化。
- **基准代表性有限**：闭环评估仅用 OSWorld-Verified 和 MobileWorld，未报告 WebArena、AndroidWorld 等流行 GUI 基准，跨环境可迁移性存疑。
- **选择器依赖单次提议**：部署时先用 Recent-B 得到提议再选恢复事件，若初始提议本身较差，选择质量可能被级联错误影响；论文未探讨迭代修复机制。
- **图像预算的粒度固定**：所有事件默认同代价，未考虑截图尺寸、token 长度差异；真实系统中的 token 预算通常随图像分辨率变化，该简化可能偏离实际。
- **缺失失败模式分析**：未系统分析“错误恢复”如何导致错误（是误导了策略，还是挤占了近期信息），因此对鲁棒性的理解仍不完整。
- **算力与复现信息不全**：未报告 GPU 数量、训练时长、选择器推理开销等关键复现数据，难以估计实际部署成本。

## 8. 总结评价

CausalCache 的核心贡献在于重新定义了长时程 GUI 智能体的记忆问题——从“保留哪些事件”转向“保留什么保真度”，并在不改变冻结策略权重的前提下，通过门控 LoRA 精确地教会策略“有选择地重新看见历史图像”。其双层架构（HGKV + 预算感知选择器）既保证了策略功能的零漂移（B=0 时逐位一致），又能在记忆关键场景中带来可观收益。尽管存在训练范围、基准覆盖和复现透明性等不足，它仍然是第一个系统性地从**保真度分配**角度处理 GUI 记忆控制的可靠工作，为后续结合更细粒度 token 预算、在线反馈和失败轨迹利用的研究提供了清晰范式。
