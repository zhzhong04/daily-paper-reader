Abstract 

Non-prefix KV cache reuse is a promising ap-proach for improving inference efficiency in multi-agent systems as agents share the same context blocks. However, when agents have conflicting tasks, directly reusing non-prefix KV caches across agents can severely degrade model performance, causing up to a 90% drop. Existing remedies, including selective recom-putation and offset-based calibration, recover a limited fraction of this loss. We argue that the problem lies not only in contaminated KV representations but also in the agent’s difficulty interpreting reused context under its own in-structions. To this end, we introduce Laten-tRemedy, which uses a few task-conditioned latent tokens to help the target agent leverage reused context without recomputing the shared block. Specifically, we use an MLP to map the last hidden state of the target prefix into a small number of latent tokens, which are placed after the reused KV block to interact with the shared context. To guide subsequent predictions toward the target task, we train the MLP through full-prefill distillation. Exper-iments show that LatentRemedy consistently outperforms existing reuse baselines on con-flicting tasks while maintaining TTFT close to direct reuse as cache size grows. Code and data are available at https://github. com/chenzhwsysu57/kvreuse .

1 Introduction 

KV-cache reuse is an effective way to reduce re-dundant prefill computation (Yao et al., 2025; Ye et al., 2025; Geng et al., 2026b; Ramesh and Li, 2025) in multi-agent systems where agents share the same context blocks. However, existing work largely focuses on cooperative agents with aligned objectives, leaving agents with conflicting objec-tives rarely explored. We find that existing position-independent cache repair methods, which rely on selective recompu-tation or offset-based calibration, recover only a limited fraction of the performance loss under con-flicting tasks. Our analysis suggests that previ-ous agent’s task in the reused KV cache can in-terfere with how the current agent interprets the shared context. Unlike full prefill, where the shared context is processed under the agent’s instruction, cross-agent KV reuse introduces representations computed under a different task. This suggests that an effective remedy should allow the instruction to interact with the reused context, while ensuring that this interaction guides subsequent generation towards current objective. Our preliminary study further shows that repeating the target instruction after the reused cache can substantially alleviate task interference. To this end, we introduce LatentRemedy , which addresses this problem with a small number of la-tent tokens. To encode the prefix instruction, we use an MLP to map the last hidden state of the pre-fix into these latent tokens. We place them after the reused block, allowing them to attend to both the prefix and the reused context. To guide consecutive reasoning towards the prefix instruction, we train the MLP through full-prefill distillation. Extensive 1arXiv:2610.18014v1 [cs.CL] 13 Oct 2026 experiments show that LatentRemedy substantially outperforms existing KV cache reuse methods in conflicting-task scenarios, while maintaining time-to-first-token (TTFT) latency close to direct reuse. In a nutshell, our contributions are threefold: • We identify conflicting KV-cache reuse sce-narios in multi-agent systems, where existing cache repair methods struggle to recover the performance loss. • We reveal that cross-agent KV cache reuse disrupts target-spefic contextualization, high-lighting the needs of prefix re-conditioning when reusing non-prefix KV cache. • We introduce LatentRemedy, a simple latent remedy that enables interaction with reused context to guide subsequent generation with-out recomputing the shared block. Experi-ments demonstrate its advantages in accuracy and TTFT across various tasks. 

2 Related Work 

Non-prefix KV-cache reuse. Methods such as CacheBlend, KVCOMM, RelayCaching, and EPIC repair cached states by selective recomputation or offset recalibration (Yao et al., 2025; Ye et al., 2025; Geng et al., 2026b; Hu et al., 2025), primar-ily address cache reuse in cooperative scenarios, whereas applications in non-cooperative scenarios have rarely been explored. 

Soft prompt tuning. By optimizing a small set of continuous embeddings prepended to the input, such methods offer an efficient way of full-model fine-tuning (Lester et al., 2021; Li and Liang, 2021; Liu et al., 2022). Unlike these methods that learn fixed task-level prompts for general adaptation, our remedy seeks to generate request-specific latent tokens from the target prefix to guide task-specific generation.

On ArgKP, full pre-fill achieves 85.91% accuracy, whereas direct KV reuse achieves only 2.27%. Existing repair meth-ods provide only marginal improvement: the best-performing methods, CacheBlend and EPIC, reach merely 6.82%. In the reasoning setting (Figure 2b), the gap between full prefill and reuse-based methods becomes substantially smaller, although it does not disappear. On ArgKP, full prefill achieves 90.00% accuracy, while RelayCaching, CacheBlend, and EPIC achieve approximately 70.00% accuracy on average. Direct reuse performs comparably to these repair methods, whereas KVCOMM reaches only 28.64%. The effect is even more pronounced on Deal or No Deal: full prefill achieves 100% ac-curacy, while direct reuse reaches 79.09%, match-ing RelayCaching; CacheBlend and EPIC achieve 92.73% and 89.09%, respectively. Therefore, rea-soning alone allows direct reuse to retain nearly 80% of full-prefill accuracy on this task, despite us-ing a cache produced under a conflicting objective. A similar trend is observed on Job Interview.

agent. We use the last hidden state of the target pre-fix as a representation of its task instruction and em-ploy a lightweight MLP to map it into a small num-ber of latent tokens. Let Hpref ix i denote the last hidden state of the target prefix. The latent tokens are generated as latent n = M LP (Hpref ix i ) ∈

Rn×d, where n is the number of latent tokens and 

d is the embedding dimension of the serving LLM. To enable interaction between the target instruction and the reused context, we place the latent tokens after the reused KV block. Through causal atten-tion, these tokens can incorporate information from both the target prefix and the reused context, while leaving the reused KV cache unchanged. Subse-quent tokens can then attend to these representa-tions, helping the model generate outputs aligned with the target task. 

Training Objective . However, the latent tokens may not naturally lead the agent to follow the target instruction, as previous task information may still occur in subsequent reasoning, which can break the correct task execution. To encour-age the model to use this interaction for target-aligned predictions, we train the latent mapping through distillation from full prefill. We denote the next token prediction of normal full prefill as 

qf ull = P r (·| pref ix i, shared ), and the next to-ken prediction of the latent remedy as qremedy =

P r (·| pref ix i, KV shared j , latent n). Using KL di-vergence to match the two distributions, the train-ing objective becomes minimizing 

L = KL (qf ull || qremedy ) (1) By aligning the student’s predictions with those of full prefill, we train the latent remedy to guide sub-sequent generation toward the target task despite interference from the reused cache. The overall process of our method is shown in Figure 4.

5.2 Results Overall accuracy. Tables 2 and 3 report the accu-racy on ConflictInstruct and ArgKP, Deal and Job tasks, respectively. Latent-16 ranks second only to Full in most settings and even surpasses Full on ConflictInstruct with Qwen3-8B, achieving 44.47% vs. 43.78% without reasoning and 66.58% vs. 65.93% with reasoning. The advantage of Latent-16 is particularly pronounced without reasoning and becomes more substantial as model size in-creases. On ConflictInstruct, Latent-16 outper-forms the strongest competing reuse-based method by 6.00, 20.83, and 21.14 percentage points on Qwen3-1.7B, Qwen3-4B, and Qwen3-8B, respec-tively, with the performance gap widening as model size increases. The improvement also generalizes to additional tasks, with Latent-16 achieving up to 53.64 percentage points higher accuracy than the strongest reuse-based baseline on Job Interview. 

Latent-16 maintains its competitive advantage even when reasoning enables competing methods to recover accuracy. Although reasoning improves competing methods and narrows the performance gap, Latent-16 remains the strongest reuse-based method across most settings. On ConflictInstruct, it achieves 66.58% accuracy with Qwen3-8B, com-pared with 44.91% for the strongest competing method. These results suggest that LatentRemedy effectively guides subsequent generation toward the task conditioning after reusing the non-prefix KV cache.

Direct KV cache reuse can introduce task-identity con-fusion, causing the current agent to reason from the previous agent’s perspective. While full prefill correctly identifies Agent A’s objective and selects the optimal allocation (E), reusing Agent B’s KV cache causes the target model to mistakenly treat Agent B’s allocation as its own, leading to an in-correct answer (C). 6 Conclusion 

In this work, we study the underexplored conflict-ing scenario for non-prefix KV cache reuse in multi-agent systems. We reveal why most existing meth-ods struggle to recover the performance under con-flicting objectives. We introduce a latent remedy method that learns to counteract task interference introduced by non-prefix KV cache reuse by re-mapping prefix hidden states into latent tokens. We introduce ConflictInstruct dataset that specifically tests agents when non-prefix KV cache serves con-flicting tasks. Extensive experiments show that our method is consistently better than other baselines on conflicting KV cache reuse scenarios while re-8maining close to direct reuse TTFT as the reused block grows. 

Limitations 

Our evaluation focuses on conflicting-task cache reuse with Qwen3 models at three scales. The generalibility of our LatentRemedy to other model families remains to be explored. It remains to be answered whether training the latent adapter on large corpus instead of conflicting tasks can serve the same goal. We only measure the latency us-ing a single RTX 5090 and shared blocks of up to 4,096 tokens, leaving more configurations of latency unexplored.

E Dataset Overview 

Design principles. As current KV cache reuse methods are evaluated mainly on cooperative tasks such as solving problems in MMLU, HumanEval, with RAG multi-turn discussion, we aim to de-velop a dataset that can be evaluated in multi-agent systems where agents are dispatched with differ-ent tasks with the same context provided. To this end, we introduce ConflictInstruct, a benchmark that evaluates agent performance when multi-agent systems are reusing the same context KV cache but with different goals. The dataset consists of various task families that can be dispatched in con-flicted ways such as selection criteria, data group-ing and logical induction. Specifically, agent A and agent B are given different instructions pA

and pB , continued with the same shared context s,and then required to produce different outputs yA

and yB . The dataset together with code is avail-able at https://anonymous.4open.science/r/kvreuse-F7E6/. 

Generation process. The dataset is mainly driven by EvolInstruct with seed tasks manually created, then expanded by LLMs (Zeng et al., 2024). It-eratively, we prompt LLM to propose either new operators on existing data forms, new scenarios in the same task form, or tasks and data that are different from existing examples. After generation, all tasks are going through full-prefill evaluation to make sure the correctness of the data with best effort. We discard those with inappropriate formats and incorrect answers, resulting in finally 240 task families with 30 pairs of instances per family. 

Dataset statistics. The balanced corpus contains 240 task families with 30 paired instances per fam-ily, giving 7,200 pairs in total.
