## ABSTRACT 

Long-horizon LLM agents face a fundamental allocation problem as interaction histories grow: which information to retain, how much context to devote to it, and at what granularity. Existing memory mechanisms largely focus on relevance, retrieval, or compression, leaving this allocation trade-off implicit. We introduce MEM PRICE , which treats active context as a shared resource and dynamically allocates it across memories and representation levels. M EM PRICE turns accumu-lated memory pressure into an adaptive price on context, encouraging detail only when its estimated retention value justifies the additional footprint. This pres-sure persists across memory refreshes, allowing the contents of memory to evolve while preserving long-run control over context usage. We show that irreversible compression can force linear worst-case regret against hindsight following its own memory trajectory, and introduce a same-state benchmark to evaluate allocation on M EM PRICE ’s realized memory states. M EM PRICE enforces the hard context budget at every round and regulates long-run occupancy through adaptive pric-ing, without prior knowledge of the interaction horizon. Under priced-frontier regularity, its average allocation-regret bound against this benchmark vanishes when accumulated estimation error is sublinear. We evaluate the framework un-der matched memory budgets on LongMemEval, LoCoMo, AppWorld, and Web-Shop across three foundation models, spanning both query-blind memory con-struction and goal-directed agent context management. The complete experimen-tal code and reproduction scripts are available in our anonymous repository at 

https://anonymous.4open.science/r/ICLR2027-MemPrice .

## 1 INTRODUCTION 

Foundation models are increasingly deployed as long-horizon agents that reason, act, and interact over extended trajectories (Yao et al., 2023; Shinn et al., 2023). As these interactions grow, the accumulated history can quickly exceed the active context available to the model, making memory management a central component of agent design. Existing systems address this challenge through persistent memory, hierarchical storage, retrieval, summarization, and adaptive context construction (Park et al., 2023; Packer et al., 2023; Xu et al., 2025). More recent methods further predict which past information will matter for upcoming decisions or dynamically compress interaction trajectories to control context growth (Wei et al., 2026; Ye et al., 2026). Together, these advances substantially improve an agent’s ability to operate beyond a fixed context window. However, most existing approaches formulate memory management primarily as a problem of re-trieval, relevance estimation, or compression , leaving the underlying allocation of context capacity largely implicit. Knowing that a memory is relevant does not determine whether it is worth the space it consumes: a detailed record may provide only slightly more value than a compact sum-mary while occupying substantially more context, and retaining one item necessarily reduces the capacity available to others. Similarity, importance, or predicted relevance scores therefore do not directly capture the opportunity cost of memory occupancy. Moreover, this trade-off changes over time as new information arrives and the user’s informational needs evolve. Once information has

We argue that these effects are better understood by treating active context explicitly as a limited resource: rather than only asking what information is relevant , an agent must decide which information deserves memory, at what granularity, and at what cost .To this end, we introduce M EM PRICE , a memory-allocation framework that makes the opportu-nity cost of active context explicit. Each memory can be retained at multiple levels of detail, while a persistent virtual queue turns accumulated occupancy pressure into a shared price on context. M EM -PRICE then jointly chooses representations under the hard context budget, retaining finer detail only when its estimated retention value warrants the additional footprint. Crucially, the queue persists across memory refreshes, so retrieval can change what is brought back into context without erasing the resource pressure accumulated over the interaction. Irreversible compression changes which rep-resentations remain available, so hindsight may benefit from having preserved different information, not just from better allocation. We therefore evaluate allocation on M EM PRICE ’s realized memory-state trajectory, while still allowing hindsight to redistribute occupancy across time. MEM PRICE 

always satisfies hard capacity and, under bounded utilities and estimation error, drives excess aver-age occupancy to zero without knowing the interaction horizon. Under priced-frontier regularity, its average-regret bound against this same-state benchmark also vanishes when estimation error accu-mulates sublinearly. We evaluate the framework under two complementary regimes: Query-Blind Memory , where the eventual question is revealed only after a long interaction, and Goal-Observable Memory , where the target is known from the outset and relevant evidence must be accumulated over time. Our main contributions are: • We formulate long-horizon agent memory management as an explicit online resource-allocation problem, and propose M EM PRICE , which combines capacity-feasible represen-tation selection with persistent memory pricing to adapt allocation over time while decou-pling semantic refresh from resource accounting. • We prove a linear worst-case regret lower bound against independent-state hindsight and introduce a same-state benchmark. Under stated assumptions, M EM PRICE admits regret bounds with explicit estimation-error and priced-frontier terms, and O(√T ) cumulative occupancy violation. • We evaluate memory allocation under two complementary settings: Query-Blind , where future information needs are unknown during memory construction, and Goal-Observable ,where the task goal is known from the outset and can guide evidence accumulation. Our method achieves strong results in both settings. 

Relation to prior work. Long-horizon agents often rely on persistent memory to preserve and re-cover useful information over time (Shinn et al., 2023; Park et al., 2023; Packer et al., 2023; Chhikara et al., 2025; Xu et al., 2025). Recent work further adapts the contents and granularity of working context through trajectory folding and relevance-aware context construction (Sun et al., 2025; Ye et al., 2026; Wei et al., 2026). We view active context as a shared resource and formulate memory management as an online allocation problem across competing memories and representation lev-els, connecting agent memory to online resource allocation and long-term constrained optimization (Devanur & Jain, 2012; Agrawal et al., 2014; Jenatton et al., 2016; Yu et al., 2017; Zong & Jiang, 2026). MemPrice realizes this view through adaptive pricing and persistent resource accounting across memory refreshes. A detailed discussion of related work is provided in Appendix A.

Memory refresh. The interaction is organized into consecutive refresh windows of L rounds, ex-cept possibly for the final window. Within each window, the resident set Rt consists of the context carried from the previous boundary together with newly observed interaction items. Motivated by persistent-memory designs that retain interaction history for later retrieval, we store raw transcripts in an external archive and use a fixed compression–retrieval pipeline at refresh boundaries to con-struct the carried context for the next window. Thus, compression is irreversible within a refresh window but archived information can be recovered at subsequent boundaries. Memory occupancy and retention utility are defined over the active context only. 

## 3 ALGORITHM 

MemPrice controls active-context allocation through a history-dependent memory price. At each round, accumulated occupancy pressure determines the current memory price. The allocator then jointly selects a representation for each resident memory, retaining additional detail only when its estimated value justifies the corresponding context cost. This pressure carries across memory re-freshes, allowing the agent to refresh its active context without forgetting how heavily context has been used. Algorithm 1 summarizes the full procedure. 

Adaptive memory pressure. Although the hard capacity B prevents context overflow, enforcing a fixed fraction of B at each round would be unnecessarily rigid: the active context at some rounds contains information that warrants substantially more detailed retention than at others. MemPrice therefore uses αB as a long-run occupancy target, allowing temporary increases in context usage when additional memory detail is valuable. A virtual queue Qt tracks accumulated occupancy pres-sure relative to this target and converts it into a memory price:

Occupancy above the target increases Qt, while lighter usage gradually releases this pressure. Finally, MemPrice still trails Full Context, showing that better allocation cannot fully recover information removed by a hard budget; instead, it narrows the performance loss by preserving a more useful subset of the history.

## 6 CONCLUSIONS 

We study long-term agent memory as a resource-allocation problem under limited memory budgets. Rather than treating memory management as only retention, deletion, or compression, we consider how an agent should allocate limited capacity across historical information with different utility and storage costs. We propose a budget-aware framework that combines adaptive memory pricing, multi-fidelity representations, and joint allocation. Experiments on long-context QA and interactive agent benchmarks show that explicitly managing memory pressure leads to more effective and robust use of limited memory. Our work has several limitations. The current framework relies on estimated utility signals and a predefined set of memory operations, and mainly focuses on memory capacity rather than jointly considering computation, retrieval, and latency.

## A RELATED WORKS 

Agent memory and long-horizon context management. A growing body of work equips lan-guage agents with persistent memory beyond the model’s immediate context window. Reflexion stores linguistic feedback from previous trials in an episodic memory buffer to improve subsequent decisions (Shinn et al., 2023), while Generative Agents maintain a stream of experiences and re-trieve memories according to factors such as relevance, recency, and importance, together with higher-level reflection (Park et al., 2023). MemoryBank further introduces selective reinforcement and forgetting for long-term conversational memory (Zhong et al., 2023). Other systems emphasize memory architecture and organization. MemGPT manages information across hierarchical memory tiers through an operating-system-inspired virtual context mechanism (Packer et al., 2023); Mem0 dynamically extracts, consolidates, and retrieves salient conversational information (Chhikara et al., 2025); and A-MEM organizes memories into an evolving network whose representations and as-sociations can change as new experiences arrive (Xu et al., 2025). These approaches substantially extend the temporal reach of LLM agents, but primarily focus on how memories are stored, orga-nized, updated, or retrieved. In contrast, our work isolates a complementary question: given the information currently available to an agent, how should scarce active-context capacity be allocated among competing memories and representation levels? 

Adaptive context selection and compression. Recent work has moved beyond static memory retrieval toward actively controlling the contents and granularity of an agent’s working context. Context-Folding allows an agent to branch into temporary sub-trajectories and subsequently fold in-termediate reasoning into compact summaries, thereby preventing context growth on long-horizon tasks (Sun et al., 2025). AgentFold similarly treats the context as a dynamic workspace and learns proactive folding operations at different granularities, explicitly addressing the tension between unbounded raw trajectories and irreversible information loss from fixed summarization (Ye et al., 2026). Most closely related to our setting, PACE formulates context construction as a Next Step Prediction problem and adjusts the representation granularity of historical information according to its predicted relevance for the agent’s upcoming action (Wei et al., 2026). These methods demon-strate the importance of selectively preserving detail rather than applying uniform truncation or summarization. Our perspective is complementary: rather than primarily predicting which history will be useful next or learning when to fold a trajectory, we explicitly model active context as a shared resource. Memory items with heterogeneous retention value and footprint compete for this resource, and allocation jointly determines both which items remain active and the granularity at which they are represented. This makes the opportunity cost of memory occupancy explicit and enables conversation-level resource control rather than treating context pressure only as a local se-lection or compression signal. 

Online Resource Allocation and Long-Term Constraints. Online resource allocation can be viewed as sequential optimization under intertemporal constraints, where current decisions affect both immediate rewards and future resource availability. A classical approach is to associate re-source constraints with dual prices that quantify the marginal value of capacity (Devanur & Jain, 2012). These prices can be updated dynamically as information accumulates (Agrawal et al., 2014; Li & Ye, 2022), and related models have been studied under stochastic resource consumption (Jiang & Zhang, 2020) and non-stationary input distributions (Jiang et al., 2025). Such constrained al-location problems are closely connected to online optimization with long-term constraints, where primal-dual mechanisms balance objective performance and cumulative feasibility. This perspective has been studied in OCO through regret and constraint-violation guarantees (Jenatton et al., 2016; 12 Preprint Yu et al., 2017; Ao et al., 2026; Zong & Jiang, 2026), and also arises in resource-constrained learning problems such as bandits with knapsacks (Liu et al., 2022).

## G IMPLEMENTATION DETAILS 

G.1 DETAILED EXPERIMENTAL SETTINGS 

Information regimes. Our experiments distinguish two memory-allocation regimes according to when the downstream information need becomes observable. In Setting I , memory is constructed without access to the terminal query. For a chronological history H, the allocator produces a bounded memory state before the target question is released. Target questions, answers, evidence annotations, question types, and evaluation feedback are therefore unavailable to both the allocator and its utility estimator during memory construction. This setting evaluates whether a memory pol-icy can preserve information that is useful for unknown future requests. In Setting II , the task goal is available from reset and may be used to determine which parts of the interaction history should be retained. Future observations, tool outputs, environment states, and evaluator-only information remain unavailable. This setting corresponds to long-horizon agents that know what they are trying to accomplish but must manage an increasing trajectory online. 

LongMemEval-S. LongMemEval (Wu et al., 2025) evaluates long-term interactive memory over histories containing multiple temporally separated sessions. We use the LongMemEval-S vari-ant as a primary query-blind benchmark. For each history, the complete chronological interaction stream is processed before its associated evaluation questions are released. All questions attached to the same history therefore reuse the same frozen terminal memory state rather than reconstruct-ing memory separately for each question. This prevents the allocator from specializing memory to individual queries. We report the benchmark’s official QA accuracy as the primary metric. The larger LongMemEval-M variant is reserved for long-context stress analysis rather than the primary comparison. 

LoCoMo. LoCoMo (Maharana et al., 2024) evaluates very long-term conversational memory across extended multi-session dialogues. Its questions cover several forms of retrieval and rea-soning, including single-hop factual recall, temporal reasoning, multi-hop questions, and cases re-quiring information to be integrated across distant portions of a conversation. We expose only the chronological conversation while memory is constructed; evaluation questions and their annotations are revealed after the memory state has been frozen. The complete conversation is treated as the evaluation unit, and all methods receive identical session segmentation and memory budgets. We use normalized partial-match F1 as the primary evaluation metric. 

AppWorld. AppWorld (Trivedi et al., 2024) is a stateful interactive benchmark in which an agent operates a collection of applications through structured APIs to satisfy a natural-language goal. Unlike Setting-I benchmarks, the goal is visible before the first action, so memory policies may condition retention decisions on task relevance. The agent does not observe future tool results, future application state, or the benchmark evaluator. Each completed action together with its resulting observation forms a historical interaction unit for memory management. We evaluate separately on the official Test-Normal and Test-Challenge splits. The primary metric is Task Goal Completion (TGC) , for which a task is successful only when its benchmark-native state-based tests are satisfied. Scenario Goal Completion and difficulty-based breakdowns are retained as secondary analyses. 

WebShop. WebShop (Yao et al., 2022) provides a reproducible simulated e-commerce environ-ment in which an agent must search, inspect, and select products satisfying a user-specified shopping goal. The complete goal is available from reset, while future search results, product pages, and envi-ronment transitions are revealed only through the agent’s own actions. WebShop therefore provides a second goal-observable setting with a different interaction structure from AppWorld. Histori-cal search and browsing observations are subject to the same bounded memory interface as other Setting-II tasks. We report Success Rate , the fraction of tasks receiving the maximum terminal reward, as the primary metric and average terminal reward as a secondary metric. 

Setting-I baselines. All Setting-I competitors obey the same query-blind information contract and hard historical-memory budget. Recent/FIFO retains history in reverse chronological order until the budget is exhausted and provides a pure recency control (cf. Park et al., 2023). Uniform Alloca-tion uses the same candidate representation levels as our method but distributes resources uniformly 21 Preprint across memory items, isolating the effect of adaptive allocation. Content Salience ranks memory using query-independent lexical salience, while Dense Salience uses a dense semantic represen-tation; both retain the highest-valued content under the common capacity. LRE-SelfSup (Lia & Mazumder, 2026) learns to predict the future usefulness of history units without observing the fu-ture query. Full Context is reported separately as an unbudgeted upper-reference condition and is not included in matched-resource comparisons. 

Setting-II baselines. ReAct/FIFO History (Yao et al., 2023) uses the standard iterative reasoning-and-action interface while retaining the most recent complete trajectory items under budget. Summary Agent periodically compresses accumulated trajectory history into a global summary, providing a conventional long-horizon context compression control. ZipAct-B is our resource-matched adaptation of ZipAct (Pan et al., 2026). It preserves ZipAct’s recurrent Goal– World–Constraint state update but requires the state visible to the actor to satisfy the same tokenizer-measured hard historical-memory budget B before every action. Thus, differences in task perfor-mance cannot be attributed simply to one method receiving a larger actor-visible context. 

Historical-memory budget. The resource budget B applies only to historical information made visible to the reader or agent at a decision point. The current query or task goal, current observation, system instructions, tool schemas, and reserved output tokens are handled separately when enforcing the physical context-window constraint. Dataset-specific budget grids are determined without using test outcomes from development-history length statistics and available physical-context headroom. We use four budget levels derived from the corresponding maximum feasible budget Bmax , and report the primary single-budget comparison at B⋆ = Bmax /2. All methods within a dataset use exactly the same budget values. 

Multi-fidelity allocation. Each memory item is represented by five ordered fidelity levels: raw ,

summary , abstraction , keywords , and delete . Candidate representations are generated only from the currently available text and cannot restore information already removed from an active repre-sentation. Successive compressed representations target 0.6 of their parent length. Given candidate utilities and tokenizer-measured sizes, our method jointly selects one representation per item through an exact multiple-choice knapsack problem subject to the hard capacity B.The utility estimator obeys the information contract of its setting. For Setting I it evaluates general-purpose future retention utility without access to the terminal query, whereas in Setting II it may condition utility on the task goal already visible to the agent. Utility scores are constrained to [0 , 1] ,delete has zero utility, and candidate utilities are monotonically repaired across decreasing fidelity levels when necessary.
