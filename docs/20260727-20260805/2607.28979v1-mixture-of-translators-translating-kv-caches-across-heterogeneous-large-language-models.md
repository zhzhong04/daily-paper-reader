## 摘要
异构大语言模型（LLM）系统日益依赖于共享上下文、检索到的证据和多智能体对话历史，然而其内部的键值（KV）缓存仍然具有模型特异性，无法跨架构重用。因此，每个模型必须为相同的上下文重复预填充或存储缓存，这限制了多模型推理和长上下文生成的可扩展性。我们提出了Mixture-of-Translators（MoT），一种缓存翻译框架，将上下文KV缓存从源LLM映射到目标LLM的缓存空间。与先前依赖于单一投影路径或全局共享潜在空间的方法不同，MoT使用多个翻译模块来捕获多样的源-目标映射。为了进一步减少残余翻译误差，我们引入了上下文校正损失，将重放的目标轨迹与原生目标轨迹对齐。我们揭示了缓存翻译中两种相互竞争的失败模式：早期注入导致的传播平移和晚期注入导致的最后状态平移。MoT通过翻译器混合和目标侧校正来解决这些问题。在Qwen2.5、GPT-2和OPT模型之间的同构和异构翻译中，MoT保持了下游QA性能，包括Qwen2.5-7B规模的翻译，平均闭集QA准确率为51.0%，平均抽取式QA F1为0.43。在实际案例研究中，MoT实现了多智能体推理的质量保持内存重用，并在长上下文缓存增强生成中保留了96.3%的直接上下文质量，展示了跨异构LLM的可扩展KV缓存重用。

## Abstract
Heterogeneous Large Language Model (LLM) systems increasingly rely on shared contexts, retrieved evidence, and multi-agent dialogue histories, yet their internal key-value (KV) caches remain model-specific and cannot be reused across architectures. Consequently, each model must repeatedly prefill or store caches for the same context, limiting the scalability of multi-model reasoning and long-context generation. We propose Mixture-of-Translators(MoT), a cache translation framework that maps context KV caches from a source LLM into the cache space of a target LLM. Unlike prior approaches that depend on a single projection path or global shared latent space, MoT uses multiple translator modules to capture diverse source--target mappings. To further reduce residual translation error, we introduce a Context Correction Loss that aligns the replayed target trajectory with the native target trajectory. We reveal two competing failure modes in cache translation: propagated translation shift from early injection and last-state shift from late injection. MoT addresses them through translator mixtures and target-side correction. Across homogeneous and heterogeneous translations among Qwen2.5, GPT-2, and OPT models, MoT preserves downstream QA performance, including Qwen2.5-7B-scale translation with 51.0% average closed-set QA accuracy and 0.43 average extractive QA F1. In practical case studies, MoT enables quality-preserving memory reuse for multi-agent reasoning and retains 96.3% of direct-context quality in long-context cache-augmented generation, demonstrating scalable KV cache reuse across heterogeneous LLMs.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：异构大语言模型（LLM）系统中的 KV 缓存具有模型特异性，无法跨架构重用。当多个模型共享相同上下文（如检索证据、多智能体对话历史）时，每个模型都必须重复预填充或存储自己的缓存，导致计算和内存的巨大冗余，严重限制了多模型推理、长上下文生成等工作流的可扩展性。
- **研究背景**：现有的提示缓存（Prompt Caching）和缓存增强生成（Cache-Augmented Generation）虽然验证了重复上下文重用的价值，但基本绑定于单一模型或统一缓存格式。已有跨模型通信方法（如 C2C-Projection、KVComm、Interlat、LSC）要么依赖单一投影路径，要么依赖全局共享潜在空间，难以应对模型在深度、隐藏维度、注意力布局、KV头结构等方面的异构性。
- **整体含义**：论文提出 Mixture-of-Translators（MoT）框架，将源模型的上下文 KV 缓存翻译为目标模型的缓存空间，实现异构模型间的缓存复用，从而将多模型系统中的内存冗余从 O(M)（M 为模型数）降低到 O(1)。该工作为可扩展的多模型 LLM 系统开辟了实用方向。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
MoT 的目标是学习源模型上下文缓存到目标模型缓存空间的映射：  
`KV_Src,Ctx → dKV_Tgt,Ctx`。其核心设计基于对两类竞争性误差的理论分析：

- **传播平移误差（Propagated Translation Shift）**：在过低层注入翻译缓存时，误差随残差循环传播放大，导致最终隐藏状态偏移。
- **校正不足误差（Correction-Deficit Error）**：在过高层次注入时，留给上层进行误差校正的层数不足，残差无法被有效修正。

论文通过理论推导（Proposition 2.3、2.4、2.5）证明：缓存翻译必须同时最小化翻译窗口内的平移 `||s_T||` 和最终隐藏状态偏移 `||s_L||`。仅优化单一目标不足以实现稳健的翻译。

#### 关键技术细节

1. **混合翻译器架构（Mixture-of-Translators）**：
   - 使用 N 个翻译模块（每个模块为基于交叉注意力的骨干翻译器），通过门控函数在**token 级别**进行路由选择，每个 token 可用不同的翻译器组合（Top-K 选择后归一化）。
   - 定义：`Tr_MoT(z_u) = Σ eg_m(z_u) · Tr_m(z_u)`，其中 `eg_m` 为 Top-K 选择后的归一化权重。
   - 理论证明（Proposition 3.2）：最优翻译器混合不会比最优单一翻译器产生更大的翻译平移，且在 token 级专业化能实现更优映射时严格更优。

2. **上下文校正损失（Context Correction Loss）**：
   - 将重放（replay）后目标模型的隐藏状态轨迹与原生预填充轨迹直接对齐：
     `L_CC = Σ ||ĥ_Tgt_ℓ − h_Tgt_ℓ||²`（从 T_Start+1 到 L）。
   - 实现中采用基于 KV 缓存比较的近似形式，直接监督最终层 KV 匹配误差，从而降低最后状态偏移 `||s_L||`。

3. **缓存翻译流水线**（五个阶段）：
   - ① 上下文预填充：计算源模型上下文缓存，选择翻译通道；
   - ② KV 翻译：MoT 将源缓存映射到目标缓存空间；
   - ③ 上下文重放：通过**Top-S 源引导稀疏注意力**（Source-Guided Sparse Attention）重建目标侧上下文缓存，从 O(N²) 降低到约 O(N·S) 的计算复杂度；
   - ④ 提示词预填充：基于重建缓存对目标模型进行条件设置；
   - ⑤ 完成输出：生成最终响应。

4. **通道映射策略**：默认采用 Depth-Ratio Mapping（深度比映射），将相对深度相近的源-目标层配对；通过滑动窗口在验证集上选取最优通道位置。

### 6. 论文的主要结论与发现

- **MoT 在异构缓存翻译中保持稳定的下游 QA 性能**：Qwen2.5-7B→0.5B 异构翻译中，闭集 QA 平均准确率 51.0%、抽取式 QA 平均 F1 为 0.43，接近 Native（52.0% / 0.45）；GPT-2 系列中达到最高余弦相似度 0.89、平均准确率 42.0%、平均 F1 0.22。
- **两类竞争性误差被有效抑制**：与基线相比，MoT + Context Correction Loss 同时大幅降低了翻译平移 `||s_T||` 和最后状态偏移 `||s_L||`；U 型损失曲线变为近直线下降形态。
- **上下文校正损失是核心驱动**：即使不使用混合翻译器，单独使用 CC 损失也能带来比 CR、PL 更强的性能提升；CC 与 PL 结合达到最佳效果。
- **多智能体内存复用**：Free 缓存策略（非枢纽智能体在完成后卸载并清除缓存）在 4 智能体时比 Retain 减少约 36% 峰值内存，10 智能体时内存保持在约 0.3GiB（基线超过 1GiB），且 F1 保持稳定，实现"规模不变"的内存管理。
- **长上下文 CAG 质量保持**：MoT 在 16K、24K 预算下 F1 接近 Native，平均保留 96.3% 的直接上下文质量；TTFT 略高于其他缓存方法，但低于 Native 的预填充成本。
- **局限性确认**：校正亏损系数 d_T:L 变化有限，说明 MoT 并非直接提升目标模型内在校正能力，而主要通过降低 `||s_T||` 和正交偏移 `β_T:L` 来改善翻译轨迹。

### 7. 优点（方法或实验设计上的亮点）

- **理论分析与实证发现深度结合**：论文识别并形式化了缓存翻译中两类竞争性误差（传播平移 vs 校正不足），并通过残差循环理论推导、U 型损失曲线、余弦相似度热力图等多角度验证，方法论具有强解释性。
- **"混合翻译器 + 上下文校正"联合设计**：目标明确地分别对应用类误差——MoT 负责降低翻译窗口内的 `||s_T||`，CC 损失负责降低最终 `||s_L||`，设计逻辑清晰且互补。
- **Token 级门控路由的引入**：允许不同 token 使用不同翻译器组合，突破了单一投影或单一翻译器的表达瓶颈，且通过理论证明（Proposition 3.2）保证其不劣于单一翻译器。
- **稀疏重放机制（Top-S Source-Guided Sparse Attention）**：将上下文重放成本从 O(N²) 降至近似 O(N·S)，兼顾了长上下文的实用效率和翻译质量。
- **实验体系完整**：涵盖多种模型家族、同构/异构、多个规模扩展轴、消融和实际案例研究，结论可信度较高。
- **应用导向强**：多智能体内存复用和长上下文 CAG 直接面向实际部署场景，展示了超越 QA 指标的系统级收益。

### 8. 不足与局限

- **校正能力未本质提升**：论文自己承认，校正亏损系数 d_T:L 的变化有限，MoT 主要降低 `||s_T||` 和正交偏移而非增强目标模型的固有校正能力，理论上仍存在更深层的误差注入风险。
- **通道映射依赖深度比假设**：Depth-Ratio Mapping 在模型间指令微调、训练分布或表征组织差异较大时可能失效（附录中已指出），自适应通道映射仍是未解决的问题。
- **未解决跨 tokenizer 的缓存翻译**：当源/目标模型使用不同 tokenizer 时，缓存位置无法直接对应，token 级翻译会失效；论文仅将其列为未来工作。
- **训练开销增长**：MoT 的峰值内存随参与模型数量增加而上升（在图 25 中高于 C2C 和 Interlat），虽然提供了 MoT-h 变体缓解，但仍存在扩展成本问题。
- **实验结果缺少方差报告**：所有指标均为单次运行结果，未报告多次运行的均值±标准差，对于模型和数据规模较小的实验（如 GPT-2、OPT），结果稳定性存在潜在质疑空间。
- **部分基线实现可能存在不公平比较**：C2C-Project、LSC 由作者自行实现，而非使用官方开源代码（KVComm、Interlat 使用公开实现）；虽按论文配置，但实现差异可能影响对比公平性。
- **评估范围有限**：未涉及真正的跨 tokenizer 翻译、多模态模型或更大的生产级模型（如 70B+），实际大规模部署中的表现仍有待验证。
