## 摘要
长时程LLM智能体会积累推理轨迹、动作和工具观测结果，最终可能超出模型的固定上下文窗口。现有的压缩方法通过丢弃、总结或检索早期信息来解决这一限制，但这些方法可能移除任务关键细节，或无法可靠地恢复这些信息。我们提出ARC（可寻址回忆压缩），一种将归档存储与活动上下文呈现分离的上下文管理框架。ARC将工具观测结果存储在仅追加的、ID可寻址日志中，并在需要压缩时用紧凑引用替换较旧的观测结果。智能体随后可以使用这些标识符请求存储的内容，而无需重新执行相应工具或仅依赖基于相似性的检索。我们使用具有16k上下文窗口的Qwen3-8B和具有32k上下文窗口的Qwen3-32B评估了ARC。在针在大海捞针（Needle-in-a-Haystack）评估中，ARC的平均精确答案准确率达到99.40%，而评估中表现最佳的基线为88.12%。ARC在我们的硬件成本模型下还减少了估计服务时间和HBM流量。在LongBench-v2 Hard子集上，ARC的平均准确率为29.97%，而表现最佳的基线为28.25%。这些结果表明，在被测设置下，相对于评估的上下文管理基线，显式、基于地址的回忆可以提高信息保留和服务效率。

## Abstract
Long-horizon LLM agents accumulate reasoning traces, actions, and tool observations that can eventually exceed a model's fixed context window. Existing compaction methods address this limitation by discarding, summarizing, or retrieving earlier information, but they may remove task-critical details or fail to recover them reliably. We propose ARC (Addressable Recall Compaction), a context-management framework that separates archival storage from active-context presentation. ARC stores tool observations in an append-only, ID-addressable log and replaces older observations with compact citations when compaction is required. The agent can subsequently use these identifiers to request stored content without re-executing the corresponding tools or depending solely on similarity-based retrieval. We evaluate ARC using Qwen3-8B with a 16k context window and Qwen3-32B with a 32k context window. On the Needle-in-a-Haystack evaluation, ARC achieves an average exact-answer accuracy of 99.40%, compared with 88.12% for the best-performing baseline in our evaluation. ARC also reduces estimated serving time and HBM traffic under our hardware-cost model. On the LongBench-v2 Hard subset, ARC obtains an average accuracy of 29.97%, compared with 28.25% for the best-performing baseline. These results indicate that explicit, address-based recall can improve information retention and serving efficiency relative to the evaluated context-management baselines under the tested settings.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：现代LLM智能体在执行长时程任务时，会在每次交互中持续累积推理轨迹、动作和工具观测结果，形成一个不断增长的统一转录（transcript）。由于自回归语言模型在独立调用间是无状态的，这个转录成为智能体唯一的工作记忆。
- **核心问题**：转录单调增长必然超出模型固定的上下文窗口（Context Window），导致"上下文溢出"（Context Overflow）的不可恢复故障。即使是现代超大上下文窗口也无法避免这个问题。
- **现有方案的不足**：当前主流压缩方法（朴素截断、分层总结、结构化状态折叠、RAG检索）均为**有损压缩**——一旦历史被修剪、改写或向量化，关键信息（如变量名、错误字符串、用户约束）就无法精确恢复，智能体只能重新推导或产生幻觉，错误会随轨迹叠加放大。
- **研究意义**：本文提出一个关键问题——**上下文压缩能否在保持活动提示有界的同时做到严格无损**？这直接关系到长时程AI智能体的可靠性、记忆能力和服务效率。

## 2. 方法论：ARC框架

### 2.1 核心设计思想

- **解耦两个决策**：现有方法将"保留什么"与"当前向模型展示什么"耦合在一起。ARC将它们分离——**"保留一切"**在内容寻址存储中；**"选择性展示"**由长度有界逻辑决定，且每次省略都留下显式可解引用的指针。
- **核心原则**：压缩只改变模型所见的内容，不改变系统所保留的内容。

### 2.2 关键技术细节

- **观测存储与引用（Observation Store & Citations）**：
  - 每个工具观测结果O以稳定ID存储，ID由 `SHA1(signature(A) || 0x1F || O)` 计算（签名加ASCII单元分隔符加观测内容）；
  - 可见ID取前8个十六进制字符，碰撞时以4字符递增扩展；
  - 存储为仅追加（append-only）模式，任务生命周期内永不删除；
  - 压实时保留引用 `§id`（含头部预览、尾部预览、元数据及 `_recall §id` 提示）；
  - 短于阈值ρ的观测保持原样不压缩。

- **回忆动作（Recall Action）**：
  - `_recall §id` 由框架拦截，从存储中精确恢复完整观测，**无需重新执行工具**；
  - 无效ID返回最近匹配建议而非静默失败；
  - 每步回忆次数上限r=2，有总素材化回忆预算和单次最大长度限制；
  - LRU（最近最少使用）策略在超预算时将实体化内容回收为引用桩。

- **确定性压缩例程**：不调用LLM，不产生额外模型调用或延迟；截断早期思考、保留短观测、将长观测替换为引用、最近轮次保留原文。

- **触发机制**：支持主动式（调用前估算并预压缩）和反应式（溢出后压缩）；两种模式使用同一确定性压缩例程。

- **系统级保证（Theorem 1/15）**：在满足四项假设的条件下，模型输入每轮至多K个token（与轮次无关），所有观测可精确重建，且重建通过 ⌈|O|/q⌉ 个非重叠分块完成。核心公式为活动视图预算：**K = B + M + R + P + Q + η ≤ L**（固定前缀+摘要+最近后缀+目录页+回忆缓冲+序列化开销的总和不超过可用输入预算）。

## 7. 优点

1. **理论创新**：首次将上下文压缩从"有损必然"重新定义为实现无损可恢复问题，系统级定理（有界视图+观测无损+精确回忆）有严格的数学证明框架。
2. **机制优雅**：仅追加存储+内容寻址ID+引用桩的设计简洁且完备；确定性压缩例程不引入额外LLM调用延迟。
3. **效率与效果双赢**：ARC不牺牲准确率换取效率，而是同时改善两者，打破了"记忆管理以延迟换准确率"的传统权衡。
4. **实验严谨性**：配对McNemar检验、多种子方差报告、跨平台验证、硬件成本模型分析，使结论具有较高的可信度。
5. **信息论视角**：附录证明线性外部存储增长是精确恢复的下界，ARC的追加型存储在一阶意义上渐进最优——为方法提供了理论正当性。
6. **消融深度**：三个维度（预算/调度/夹具）的系统消融，揭示了方法的适用边界与任务依赖行为。

## 8. 不足与局限

1. **实验覆盖有限**：仅Qwen3模型族（8B/32B两个规模），未验证在GPT、Llama、Mistral等其他架构上的泛化；不同tokenizer和推理风格可能影响 `_recall` 约定的遵从度。
2. **LongBench优势收窄**：在需要多步推理的任务上，ARC相对最强基线的优势降至1.6–2.3个百分点，说明回忆能力的边际收益受推理能力制约——完美回忆仍可能因推理错误导致错误答案。
3. **引用Token开销**：每个引用桩（头/尾预览+回忆提示）相对直接丢弃有固定token开销，论文仅在补充材料中提及量化，正文未充分分析其对有效上下文预算的影响。
4. **机制级而非端到端保证**：定理保证"有效地址→精确内容"，但不保证模型会选择正确地址或正确使用恢复的内容——存在"可用但未用"的失败模式。
5. **小预算下竞争力不足**：消融显示8k/4k等较小回忆预算下ARC并非最优（如32B上Sliding_window 31.19% > ARC 29.90%），说明方法存在最小有效预算需求。
6. **对话历史任务的未解之谜**：论文承认隐含检索在对话历史任务上仍占优，显式与隐式回忆的互补关系未深入分析。
7. **真实部署验证缺失**：所有实验基于离线轨迹回放和模拟溢出触发，缺少真实在线长时程Agent部署的端到端验证。
