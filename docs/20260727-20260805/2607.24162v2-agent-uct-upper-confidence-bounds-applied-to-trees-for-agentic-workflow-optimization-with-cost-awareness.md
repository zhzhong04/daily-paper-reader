## 摘要
优化智能体工作流（如检索增强生成（RAG）流水线）需要在紧凑的评估预算下在离散组件选择的组合空间中进行导航。现有方法——启发式搜索、黑箱优化和标准树搜索方法——并未显式利用这些工作流的组合结构，导致冗余计算和低效的预算分配。我们提出了Agent-UCT（基于智能体的成本感知上置信界应用于树），一种树搜索算法，通过从二分前缀重用图导出的重用感知正则化项扩展了UCT。Agent-UCT将选择偏向于利用先前物化配置前缀的分支，在保持有效探索的同时减少冗余执行。我们的框架RAGSpace将来自LongRAG、LightRAG和Self-RAG的异构RAG组件统一到一个五维配置空间中，支持跨框架的系统性重组。WTB（工作流测试台）提供确定性重放、内容寻址缓存和事务一致性，确保中间状态只物化一次并在搜索中被重用。在HotpotQA和UltraDomain上的实验表明，Agent-UCT在评估的固定框架预设中识别出具有最高样本外性能的配置。在全池评估下，相对于无前缀共享的成本上界，二分前缀重用将逻辑搜索成本降低了73.6%。与全池评估相比，基于采样的评估进一步实现了4.2倍的墙钟加速。Agent-UCT、RAGSpace和WTB共同提供了一个统一框架，用于成本感知、可复现且组合高效的智能体工作流优化。

## Abstract
Optimizing agentic workflows, such as retrieval-augmented generation (RAG) pipelines, requires navigating a combinatorial space of discrete component choices under tight evaluation budgets. Existing approaches - heuristic search, black-box optimization, and standard tree search methods - do not explicitly exploit the compositional structure of these workflows, leading to redundant computation and inefficient budget allocation. We introduce Agent-UCT (Agent-based Cost-Aware Upper Confidence Bounds Applied to Trees), a tree search algorithm that extends UCT with a reuse-aware regularization term derived from a bipartite prefix reuse graph. Agent-UCT biases selection toward branches that leverage previously materialized configuration prefixes, reducing redundant execution while maintaining effective exploration. Our framework, RAGSpace, unifies heterogeneous RAG components from LongRAG, LightRAG, and Self-RAG into a five-dimensional configuration space, enabling systematic cross-framework recombination. WTB (Workflow Test Bench) provides deterministic replay, content-addressable caching, and transactional consistency, ensuring that intermediate states are materialized once and reused across the search. Experiments on HotpotQA and UltraDomain demonstrate that Agent-UCT identifies configurations with the highest out-of-sample performance among the evaluated fixed framework presets. Under full-pool evaluation, bipartite prefix reuse reduces logical search cost by 73.6% relative to the no-prefix-sharing cost upper bound. Compared with full-pool evaluation, sampling-based evaluation further achieves a 4.2x wall-clock speedup. Agent-UCT, RAGSpace, and WTB together provide a unified framework for cost-aware, reproducible, and compositionally efficient agentic workflow optimization.

## 二、方法论

### 1. 核心思想

Agent-UCT 扩展了标准 UCT 算法，引入**基于二分前缀重用图的正则化项**，使搜索偏向于能复现先前物化前缀的分支，从而在保持探索能力的同时减少冗余计算。

### 2. 关键公式与技术细节

**搜索状态定义**：状态 s = (o₁, o₂, ..., o_d)，d 为深度；完整配置 x = (o₁, ..., o_L)。

**Agent-UCT 选择分数**：

$$\text{Agent-UCT}_t(s,a) = \hat{Q}_t(s,a) + c_{\text{UCT}} \sqrt{\frac{\log(N_t(s)+1)}{N_t(s,a)+1}} - \lambda_t \widehat{\Delta C}_t(s,a)$$

- $\hat{Q}_t(s,a)$：经验奖励估计（标准 UCT 的利用项）
- 第二项：标准 UCT 探索项（$c_{UCT}$ 为探索参数）
- 第三项：**成本正则化项**
  - $\lambda_t = \lambda_0 / \sqrt{t}$：随时间衰减的正则化系数（逐步让奖励估计主导决策）
  - $\widehat{\Delta C}_t(s,a)$：基于当前二分重用图估计的边际计算成本

**边际成本计算**：

$$\Delta C_t(s,a;z) = c_{d+1}(s,a,z) \cdot \mathbb{1}[\text{Child}(s,a), z) \notin E_t^Z]$$

即：若前缀已被物化，成本记为 0；否则记为完整执行成本。

**二分前缀重用图**：
- **簇级图** $G_t^Z = (\mathcal{S}, \mathcal{Z}, E_t^Z)$：连接配置前缀与 benchmark 簇
- **项级图** $G_t^Q = (\mathcal{S}, \mathcal{I}, E_t^Q)$：更细粒度，跟踪每个具体问题的前缀物化状态，支持采样模式下的精确成本估计

### 3. 算法流程（采样模式）

1. 初始化搜索树（根节点为空前缀）和空重用图
2. 对每次迭代 t = 1...T：
   - 从各 benchmark 簇抽取问题批次
   - 沿树使用 Agent-UCT 分数选择子节点（直到非终止且未完全展开的节点）
   - 扩展到未尝试的动作并补全为完整配置
   - 执行评估（采样模式计算批量奖励估计）
   - 更新项级重用图（登记新物化的前缀-问题对）
   - 沿搜索路径反向传播奖励
   - 更新最优配置

### 4. 三个框架组件的协同

- **RAGSpace**：将 LongRAG、LightRAG、Self-RAG 统一为五维配置空间（分块策略、查询策略、检索策略、后检索策略、生成策略），通过身份直通层处理框架间缺失的组件
- **WTB**：基于 AgentGit 构建，提供确定性重放、内容寻址缓存、事务一致性，确保中间状态只物化一次并被全搜索过程复用

## 六、主要结论与发现

### 1. 跨目标的最优配置不唯一

- **HQ-only 最优**：longrag 4k → identity → dense e5 → selfrag critique → simple llm（奖励 0.6936）
- **UD-only 最优**：kg extraction → lightrag keywords → lightrag graph → lightrag vector enrich → simple llm（奖励 0.4241）
- **HQ+UD 联合最优**：kg extraction → identity → bm25 → dense hybrid → selfrag critique → lightrag answers（奖励 0.5377）

→ 单一固定流水线在所有设置下都不是最优的，跨框架重组能带来收益。

### 2. 样本外泛化能力强

- **HotpotQA**：Agent-UCT 与 LongRAG 相当（F1 0.5758 vs. 0.5296，p=0.27），显著优于 Self-RAG（+0.2563, p<0.0001）和 LightRAG（+0.2578, p<0.0001）

- **HQ+UD 联合**：Combined F1 最高（0.4542），相对 LongRAG +0.0334（p=0.05），相对 LightRAG +0.1247（p<0.0001），相对 Self-RAG +0.1705（p<0.0001）

### 3. 效率收益显著

- 二分前缀重用减少 **73.6%** 逻辑搜索成本（10920 → 2878）
- 采样模式相对全池模式实现 **4.2 倍墙钟加速**、**5.73 倍 token 减少**、**7.86 倍 API 调用减少**

1. **问题定位准确**：精准诊断了现有方法忽视工作流组合结构的问题，抓住了智能体工作流优化中"前缀复用"这一核心特性

4. **系统完整性高**：Agent-UCT（算法）+ RAGSpace（配置空间）+ WTB（执行基础设施）三者构成闭环，从前端搜索到后端执行缓存一体化设计

## 八、不足与局限

### 实验覆盖层面

- **数据子集限制**：使用 HotpotQA 和 UltraDomain 的分层子集（350 搜索 + 150 测试）而非完整基准，结论的全面性有限
- **单一骨干模型**：所有实验仅使用一个模型（gpt-5.4-nano），未验证不同模型容量下的稳健性；未报告是否为最新模型可能影响时效性
- **搜索空间受限**：仅覆盖三个框架（LongRAG、LightRAG、Self-RAG）的组件，属于中型搜索空间（384 个原始配置点），未涵盖更广的 RAG 设计空间
- **缺乏方法间对比**：未与贝叶斯优化、遗传算法、标准 UCT 等其他优化策略做实验对比，难以定位 Agent-UCT 相对于其他优化范式的优势幅度

### 偏差风险

- **自动评估指标局限**：UltraDomain 使用 token 级 F1 作为奖励，对长文答案的长度和词汇重叠敏感，可能无法充分反映事实性（factuality）和完整性（completeness）
- **置换检验的统计功效**：某些对比（如与 LongRAG 的 p=0.27）可能因测试集较小而功效不足
- **归因分析的外部效度**：组件重要性分析仅反映了该搜索空间和奖励设定下的相对贡献，不应过度泛化为普遍结论

### 应用限制

- **前缀复用的粒度**：当前实验主要验证了问题级和工作流级复用，尚未充分展示 WTB 对文件系统级（文件夹、文件、工件、依赖节点）更细粒度复用的支持
- **领域扩展性**：方法虽以 RAG 为例，但更广泛智能体工作流（如代码生成、多智能体协作）中的适用性尚未验证
- **可复现性细节**：大量实现细节（并发设置、代理配置等）依赖补充材料，正文无法独立复现
