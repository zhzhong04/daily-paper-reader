## 摘要
语言模型智能体越来越多地运行在配备少量消费级 GPU 的工作站上，其中大型混合专家（MoE）模型将部分专家保留在主机内存中。使用现有的 CPU-GPU 引擎时，这些智能体只能获得快速预填充或快速解码，而无法两者兼得：llama.cpp 的专家缓存会跳过超过 32 个 token 的前向传播，以将解码所需的专家保留在缓存中，因此智能体在每次工具输出后需等待 2.1–2.8 秒；而其默认层放置虽能缩短这一等待时间，但解码速度慢 1.5–1.6 倍。我们的关键洞察是：短预填充会触及过多不同专家而难以全部上传，但其 84% 的专家激活（路由）会发送到一组可放入 GPU 内存的稳定专家上。我们提出 Ostinato，一种 CPU-GPU MoE 推理引擎，它在每次前向传播中于 GPU 上计算这些专家，且不改变模型所计算的内容。短预填充会拆分其路由，使每层每个 token 的六个路由专家中留给 CPU 的不足一个；长预填充会将每个不同的冷专家上传一次；每个解码步骤则作为每个 GPU 上的一个固定形状 CUDA 图运行。在四个 RTX 4090D GPU 上使用 DeepSeek-V4-Flash 的真实编程和客服智能体会话中，Ostinato 在两个阶段都是最快的引擎，并且比全部六个基线都更快完成每个会话。与 llama.cpp 和 KTransformers 相比，它将每次工具输出后的中位等待时间缩短 22–55%，并将会话完成时间缩短 1.4–2.5 倍。

## Abstract
Language-model agents increasingly run on workstations with a few consumer GPUs, where large mixture-of-experts (MoE) models keep part of their experts in host memory. With existing CPU-GPU engines, these agents get fast prefill or fast decode, not both: llama.cpp's expert cache skips forward passes of more than 32 tokens to keep the experts of decode cached, so an agent waits 2.1-2.8 s after each tool output, whereas its default layer placement shortens this wait but is 1.5-1.6$\times$ slower in decode. Our key insight is that a short prefill touches too many distinct experts to upload, yet sends 84% of its expert activations (routes) to a stable set of experts that fits in GPU memory. We present Ostinato, a CPU-GPU MoE inference engine that computes these experts on the GPUs in every forward pass without changing what the model computes. Short prefills split their routes, leaving fewer than one of a token's six routed experts per layer to the CPU; long prefills upload each distinct cold expert once; and each decode step runs as one fixed-shape CUDA graph per GPU. On real coding and customer-service agent sessions with DeepSeek-V4-Flash on four RTX 4090D GPUs, Ostinato is the fastest engine in both phases and finishes every session sooner than all six baselines. Against llama.cpp and KTransformers, it cuts the median wait after a tool output by 22-55% and finishes sessions 1.4-2.5$\times$ sooner.
